# Подготовка отчётов проекта

При написании новых отчётов соблюдать [общие правила научного изложения](Docs/ScientificReportRules.ru.md).
Они обобщают все33 комментария пользователя к пятой редакции Classic,
прочитанные26.11.2026 вместе с их контекстом. Требования относятся ко всему
тексту Classic, Branch и других будущих отчётов, а не только к отмеченным
фрагментам. Замечания должны менять способ объяснения; ответы рецензенту
не вставлять в научный текст. Уже выпущенные отчёты ради этих требований
не переделывать. Для TimeLearner дополнительно действуют профильные
[правила](Docs/StructTrain/TimeLearner/ScientificReportRules.ru.md).
