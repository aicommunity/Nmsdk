# Список файлов с прямым доступом к данным свойств

**Дата создания:** 2025-01-27  
**Версия:** 1.0

## Описание

Этот документ содержит полный список всех файлов в проекте, где используется прямой доступ к данным свойств через методы `SetDataDirect` или прямой доступ к внутреннему члену `v` класса `UProperty`.

### Что такое прямой доступ?

**Прямой доступ** - это способ установки или получения значения свойства, который обходит стандартные механизмы сеттеров/геттеров. В системе `UProperty` это используется в следующих случаях:

1. **SetDataDirect** - публичный метод для установки значения напрямую, минуя сеттер. Используется для предотвращения бесконечной рекурсии в сеттерах.
2. **Прямой доступ к `this->v`** - внутренние методы класса `UProperty`, которые имеют доступ к защищенному члену `v` для операций с контейнерными свойствами.

## Примечания

### Когда используется SetDataDirect?

Метод `SetDataDirect` используется в следующих случаях:

1. **Предотвращение бесконечной рекурсии в сеттерах**
   - Когда сеттер свойства пытается установить значение того же свойства через `operator=`
   - Пример: `SetName()` устанавливает `Name` через `SetDataDirect`, чтобы избежать вызова `SetName()` снова

2. **Установка значений в циклах**
   - Когда нужно установить значение для множества связанных свойств
   - Пример: `NPulseChannelCommon::SetType()` устанавливает тип для всех синапсов в цикле

3. **Условная установка значений**
   - Когда значение устанавливается на основе других условий без необходимости вызова сеттера
   - Пример: `SetUseFixedLTZThreshold()` устанавливает порог только при определенных условиях

### Когда используется прямой доступ к this->v?

Прямой доступ к `this->v` используется только внутри класса `UProperty` для:

1. **Операций с контейнерными свойствами**
   - Методы `resize()`, `assign()`, `push_back()`, `erase()` для векторов и массивов
   - Эти методы должны иметь прямой доступ для эффективной работы с контейнерами

2. **Оптимизации производительности**
   - Прямой доступ к `v` быстрее, чем через `GetData()` для операций изменения размера контейнера

### Важные замечания

- **SetDataDirect** - это публичный метод, который может использоваться извне класса, но только в специальных случаях (сеттеры)
- **Прямой доступ к this->v** - это внутренний механизм класса, который не должен использоваться вне класса `UProperty`
- Все использования `SetDataDirect` были добавлены для исправления проблемы бесконечной рекурсии в сеттерах
- Использование `SetDataDirect` в обычном коде (не в сеттерах) не рекомендуется и может привести к неправильному поведению
