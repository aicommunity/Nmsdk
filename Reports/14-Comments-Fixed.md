# Исправление комментариев после конвертации кодировки

## Проблема
После конвертации файлов из Windows CP1251 в Unicode комментарии на кириллице стали нечитаемыми (отображались как кракозябры).

## Решение
Все нечитаемые комментарии были переведены на английский язык для сохранения читаемости и совместимости.

## Исправленные файлы

### 1. Rdk/Core/Engine/UComponent.h
- **Строка 42-43**: Комментарий о комбинированных флагах для публичных типов свойств
- **Строка 45**: Комментарий об удалении ipComp как реликта

### 2. Rdk/Deploy/Include/rdk_init.h
- **Строка 74-75**: Комментарий о комбинированных флагах для публичных типов свойств
- **Строка 77**: Комментарий об удалении ipComp как реликта

### 3. Rdk/Core/Engine/UProperty.h
- **Строка 1075-1076**: Комментарии о deprecated алиасах, переведены на английский

### 4. Rdk/Core/Engine/UBasePropCreatorTempl.h
- **Строка 7**: Комментарий о базовом классе для создания свойств
- **Строка 18**: Комментарий о шаблонном методе создания свойств
- **Строка 23**: Комментарий о шаблонной функции создания свойств
- **Строка 31**: Комментарий о порядке обработки свойств
- **Строка 38**: Комментарий об обработке всех свойств типа
- **Строка 57, 78**: Комментарии о проверке запрещенных имен

## Результат
Все комментарии теперь читаемы и на английском языке, что обеспечивает:
- Совместимость с различными системами и редакторами
- Улучшенную читаемость для международной команды разработчиков
- Сохранение смысла оригинальных комментариев
