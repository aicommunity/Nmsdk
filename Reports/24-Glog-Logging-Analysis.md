# Анализ текущих обёрток и использования логирования

## Состояние макросов (`Rdk/Deploy/Include/rdk_logging.h`)

- Используются ленивые макросы `RLOG`, `VRLOG`, `RLOG_IF`, `RLOG_COUNTED`, построенные вокруг `DispatchLazy`.
- Каналы описываются структурой `ChannelDescriptor`; вывод формата `[S]`, `[G]` или `[<channel_number>]` (включая `[0]`), без имён.
- glog обязателен: fallback на `std::cout`/`std::cerr` удалён, подключение контролируется `RDK_USE_GLOG`.
- Проверки уровней (`FLAGS_minloglevel`, `FLAGS_v`) и фильтрация каналов (`ChannelFilterAllows`) выполняются до форматирования строки.
- Общие помощники `ChannelLog`, `SystemLog`, `GlobalLog` позволяют писать в новый API без прямого доступа к макросам.

## Использование API в коде

- Весь код ядра, GUI и библиотек переключён на `RLOG`/`VRLOG` или на тонкие обёртки `RDK::Logging::ChannelLog()`.
- `UExceptionLogger` направляет сообщения напрямую в канал через `ChannelLog`, сохраняя препроцессоры/постпроцессоры.
- Публичные функции `MLog_LogMessage()`/`Log_LogMessage()` сохранены для совместимости, но теперь выступают только как C-интерфейс поверх новых механизмов.
- Тесты (`Test_Logging_Sinks`) и GUI (`UGlogGuiSink`) читают лог-потоки из общего реестра sink'ов.

## Оставшиеся направления развития

1. **Повсеместное ленивое построение сообщений**: хотя макросы ленивые, отдельные места всё ещё собирают `std::stringstream` заранее — их можно заменить на лямбды.
2. **Расширяемые счётчики**: при необходимости добавить аналоги `LOG_FIRST_N`/`LOG_EVERY_N_SEC`, если такие сценарии всплывут.
3. **Трассировка вызовов**: рассмотреть добавление сведений о файле/строке в `LogItem`, чтобы sink'и могли хранить больше контекста.

## Итоги внедрения

- Все вызовы переведены на новый API: нет прямых ссылок на `RDK_LOG_*` или `MLog_LogMessage` внутри исходников.
- Канал «0» больше не существует; по умолчанию используется системный (`RDK_SYS_MESSAGE`), а глобальный (`RDK_GLOB_MESSAGE`) настраивается отдельно.
- Документация и тесты обновлены и ссылаются на `RLOG`/`VRLOG`, а не на устаревшие макросы.
