# Native loaded learner temporal evidence

Source and loaded soma potentials are overlaid with actual native input pulses. All32 conditions/68 case-soma pairs have full-sample overview and100-tick views at1920x960, with local amplitude detail when necessary. Automated QA verifies every PNG hash/size, complete window coverage and exact file inventory. Selected views are included here; the full derived cache stays on M40.

These are XML roundtrip characterization traces, not recognition trials. LT events were not recorded. Normal a3 primary traces are byte-identical to current a4 for all32 cases, as recorded in the separately published current normal primary. No additional training/classification claim follows from these plots. Manual visual review is pending and will be recorded separately.

The first renderer failed before output because system Python lacked Matplotlib; its receipt and the successful isolated-environment attempt are retained. Full PNG caches are not stored in Git.
