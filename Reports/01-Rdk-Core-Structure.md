# Структура Rdk Core

## Обзор

**Rdk (Core)** - это ядро системы Nmsdk, предоставляющее базовую инфраструктуру для компонентной архитектуры. Ядро реализует движок выполнения, систему компонентов, сериализацию, графику и прикладной уровень.

## Структура директорий Rdk/Core

### Engine/ - Движок и компонентная система

Ядро компонентной архитектуры, управление выполнением и жизненным циклом компонентов.

#### Ключевые классы:

- **UEngine** - главный класс движка, управляет окружением и хранилищем
- **UComponent** - базовый класс для всех компонентов
- **UEnvironment** - окружение выполнения компонентов
- **UStorage** - хранилище (реестр) компонентов и их описаний
- **UNet** - сеть компонентов (контейнер для соединения компонентов)
- **UContainer** - контейнер для группировки компонентов
- **UItem** - базовый элемент системы
- **UItemData** - данные элемента

#### Система свойств:

- **UProperty** - базовый класс свойства
- **UPropertyInput** - входное свойство
- **UPropertyOutput** - выходное свойство
- **UPropertyIO** - свойство ввода-вывода
- **UPropertyEndpoints** - точки подключения свойств

#### Фабрики и создание:

- **UComponentFactory** - фабрика компонентов
- **UComponentDescription** - описание компонента
- **UContainerDescription** - описание контейнера
- **UBasePropCreator** - базовый создатель свойств (различные варианты)

#### Соединения:

- **UConnector** - соединитель компонентов
- **UController** - контроллер компонента

#### Сериализация окружения:

- **UXMLEnvSerialize** - XML сериализация окружения
- **UBinaryEnvSerialize** - бинарная сериализация окружения

#### Другие компоненты:

- **ULibrary** - библиотека компонентов
- **UModule** - базовый модуль
- **UAModel** - модель
- **ULogger** / **ULoggerEnv** - логирование
- **UTime** - работа со временем
- **UEnvException** - исключения окружения
- **UEnvSupport** - поддержка окружения
- **UEPtr** - умный указатель окружения
- **UPointer** - указатель
- **ELockPtr** / **ELockVar** - блокирующие указатели/переменные
- **UShare** - общий ресурс
- **ULocalProperty** - локальное свойство

### Application/ - Прикладной уровень

Управление приложением, RPC, сервер, проекты.

#### Основные классы:

- **UApplication** - главный класс приложения
- **UAppCore** - ядро приложения (шаблонный класс)
- **UProject** - проект
- **UProjectDeployer** - развертывание проектов

#### RPC система:

- **URpcDispatcher** - диспетчер RPC команд
- **URpcDispatcherQueues** - очереди диспетчера
- **URpcDecoder** - декодер RPC команд
- **URpcDecoderCommon** - общий декодер
- **URpcDecoderInternal** - внутренний декодер
- **URpcCommand** - RPC команда
- **URpcCommandInternal** - внутренняя RPC команда

#### Управление движком:

- **UEngineControl** - управление движком
- **UEngineControlThread** - поток управления движком
- **UEngineStateThread** - поток состояния движка

#### Сервер:

- **UServerControl** - управление сервером
- **UServerTransport** - транспорт сервера
- **UServerTransportHttp** - HTTP транспорт
- **UServerTransportTcp** - TCP транспорт

#### Другие компоненты:

- **UBroadcasterInterface** - интерфейс вещания
- **UIVisualController** - визуальный контроллер
- **UChannelProfiler** - профилировщик каналов
- **UTestManager** - менеджер тестов

#### Платформенные реализации:

- **Bcb/** - Borland C++ Builder
- **Boost/** - Boost
- **Qt/** - Qt

### Graphics/ - Графика и визуализация

Система графики для визуализации компонентов и данных.

#### Основные классы:

- **UGraphics** - основной класс графики
- **UAGraphics** - абстрактная графика
- **UDrawEngine** - движок отрисовки
- **Kernel** - ядро графики
- **Gui** - графический интерфейс

#### Работа с изображениями:

- **UBitmap** - растровое изображение
- **UBitmapVector** - вектор растровых изображений
- **UFont** - шрифт

#### Сериализация графики:

- **UGraphicsXMLSerialize** - XML сериализация графики
- **UGraphicsBinarySerialize** - бинарная сериализация графики
- **UGraphicsIO** - ввод-вывод графики

### Math/ - Математические утилиты

Математические функции и структуры данных.

Содержит 30 файлов с математическими утилитами для работы с матрицами, векторами и математическими операциями.

### Serialize/ - Сериализация

Система сериализации данных и компонентов.

Содержит 16 файлов (8 .cpp, 8 .h) для сериализации в различных форматах (XML, Binary).

### System/ - Системные утилиты

Кроссплатформенные системные функции.

#### Компоненты:

- **UGenericMutex** - универсальный мьютекс
- **UDllLoader** - загрузчик DLL
- **USharedMemoryLoader** - загрузчик разделяемой памяти
- **rdk_system.h** - системные определения

#### Платформенные реализации:

- **ANSI/** - ANSI C
- **BCB/** - Borland C++ Builder
- **Gcc/** - GCC
- **Qt/** - Qt
- **Win/** - Windows

### Utilities/ - Вспомогательные утилиты

Вспомогательные классы и функции.

Содержит 22 файла (12 .h, 10 .cpp) с утилитами для работы с файлами, конфигурацией и другими вспомогательными задачами.

### Console/ - Консольный движок

- **UConsoleEngine** - консольный движок для выполнения без GUI

## Ключевые механизмы

### Компонентная система

Все функциональные единицы в системе реализованы как компоненты, наследующиеся от `UComponent`. Компоненты имеют:

- **Свойства (Properties)** - параметры, состояния, входы, выходы
- **Соединения (Connectors)** - связи между компонентами
- **Контейнеры (Containers)** - группировка компонентов
- **Сети (Nets)** - вычислительные сети из компонентов

### Система свойств

Свойства компонентов могут быть:

- **ptParameter** - параметр
- **ptState** - состояние
- **ptTemp** - временное
- **ptInput** - вход
- **ptOutput** - выход

Группы свойств:

- **pgPublic** - публичное
- **pgSystem** - системное
- **pgInput** - входная группа
- **pgOutput** - выходная группа

### Окружение выполнения

`UEnvironment` управляет:

- Выполнением компонентов
- Временем (TimeStep)
- Логированием
- Обработкой исключений

### Хранилище компонентов

`UStorage` предоставляет:

- Реестр классов компонентов
- Фабрики для создания компонентов
- Описания компонентов
- Управление библиотеками

### Сериализация

Поддерживаются два формата:

- **XML** - для человекочитаемого формата
- **Binary** - для эффективного хранения

## Зависимости

Rdk Core не зависит от других библиотек проекта, но использует:

- Qt5 (Core) - для базовой функциональности
- Стандартная библиотека C++
- Системные библиотеки (платформо-зависимые)
