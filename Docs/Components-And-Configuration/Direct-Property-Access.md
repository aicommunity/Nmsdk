# Прямой доступ к свойствам (Direct Property Access)

## RU

### Обзор

Оптимизация доступа к свойствам компонентов для повышения производительности.

### Проблема

Традиционный доступ к свойствам через систему поиска может быть медленным при частых обращениях.

### Решение

Прямой доступ к свойствам через указатели и кэширование для оптимизации производительности.

## EN

### Overview

Optimization of component property access for improved performance.

### Problem

Traditional property access through the search system can be slow with frequent access.

### Solution

Direct property access through pointers and caching for performance optimization.
