## Проверка исправлений

Для каждого замечания повторить исходное действие на одной сохранённой конфигурации, зафиксировать граф и реакции на исходный и контрольный паттерны, затем повторить после исправления. Для файлового ввода дополнительно использовать неполную последнюю строку и пустой файл. Для Watch проверить сохранение и повторное открытие настроенного вида, длинный интервал и один спайк на шаг расчёта.

Контрольный прогон Release в `ClassicTrainingRepro` подтвердил переобучение NL в одной сессии. Первый паттерн из Iris, объект № 22, потребовал 34 итераций. Второй паттерн потребовал 8. Длины дендритов изменились с `[18, 7, 20, 20, 1]` на `[15, 9, 21, 21, 1]`, число синапсов — с `[29, 15, 31, 31, 1]` на `[26, 18, 32, 32, 1]`. Это опорный результат проверки алгоритма для сценария без закрытия проекта.

На удалённой Windows-машине проверены загрузка сохранённой NL22, открытие редактора входа, запуск и пауза расчёта, ручное добавление ряда, отображение выходных импульсов, повторное открытие ряда Watch и файловый запуск NL. При возобновлении NL на том же объекте Iris № 22 длины дендритов изменились с `[2, 2, 2, 2, 1]` на `[18, 7, 20, 20, 1]`, числа синапсов — с `[1, 1, 1, 1, 1]` на `[29, 15, 31, 31, 1]`. `InputPattern` совпал по двум сохранённым файлам, `IsNeedToTrain` изменился с 1 на 0. Файловый режим оболочки `NSpikeClassifier`, внешний транзитный вход и восстановление полной динамики требуют отдельных проверок.

Прямая привязка `Model.<свойство>` к Watch зависит от поддержки корня механизмом чтения данных. Мастер показывает это ограничение. Источники в дочерних компонентах корня доступны через пресеты. Отдельной проверки требуют независимость истории ряда при повторной привязке и работа с несколькими каналами.

Исправление чтения последнего файлового паттерна, изменение семантики флага обучения и сохранение полной динамической точки продолжения требуют решений за пределами Qt GUI. Для них сохраняются самостоятельные сценарии диагностики.

### Проверка пакета

- Сборка Windows x64 Release с Qt 5.15.2. Четыре проверки в `WatchReliabilityTest` прошли в Qt offscreen. Проверены однотактные экстремумы на полном и увеличенном интервалах, пустая история, пропуск неизменённых полей формы и остановка применения при отказе сеттера.
- При запуске из `Bin/Platform/Win` копии `Prepared/trainer`, `Prepared/learner` и `STDP-Simple-01` завершились с кодом 0 при автоматическом запуске с пределом 0,667 с модельного времени. В каталоге Release присутствуют поставляемые темы и пресеты.
- Интерактивная приёмка включает масштабирование при разных DPI, положение окон, редактирование матриц, пересборку схемы, экспорт Watch и сопоставление результатов команды **Run N Steps** с Watch и без него.
