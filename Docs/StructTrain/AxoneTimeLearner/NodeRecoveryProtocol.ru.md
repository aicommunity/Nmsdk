# Восстановление одного аксонного узла

P1-node-recovery-v3 объявлен после анализа сохранённой серии 60 условий: краткая пачка меняется уже в первом NAxoneSegment. Это исследовательская факторная сетка, а не независимое подтверждение подобранного профиля. Исходники и конфиг подготовлены; исполнение ещё не выполнено. Объявление v1 сохранено и заменено до native-запуска: используется read-only GetNeuralPotential, записываются все максимальные временные возможности, несопоставленные события и однозначные пары общего механизма.

В каждом из 72 условий один NAxoneSegment получает четыре отдельные презентации со свежим Reset корня при времени ноль. Источник — одна NDatasetMatrix и обычный NPulseGeneratorTransit. Порядок: отсутствие событий, только первый спайк, только второй с сохранением его абсолютного времени, пара. Таким образом, одиночный контроль второго импульса не переносится к началу отсчёта. Нулевые ISI — штатное дополнение матрицы; фактический выход обязательно проверяется, включая отсутствие событий в пустом контроле. Амплитуда во всех фазах 1, ширина 1 мс, девиация 0, без цикла или смены sample. Первый номинальный момент 10 мс, второй 10 мс плюс ISI. Фактические фронты и интервал проверяются с допуском два такта, записываются и не заменяются номинальными.

| Фактор | Объявленные значения |
|---|---|
| Частота | 20000 и 40000 Гц |
| Ёмкость обоих каналов узла | 1 нФ; 0,25 нФ; 0,025 нФ |
| TimeConstant LT-зоны | 1,44 и 0,36 мс |
| Интервал пары | 2; 4; 8; 16; 32; 80 мс |
| LT-зона | NPLTZone, порог 0,02, выключение 0, амплитуда 1, интегрирование и стабилизатор включены |
| Окно каждой презентации | Полное 0–250 мс |

Остальные эффективные параметры узла сохраняются из штатного NPMembraneBio и компонентов NAxoneSegment. Записывается полная типизированная идентичность: сопротивления покоя/обратной связи, ResetAvailable, FeedbackGain, инерционное звено, генератор и проводка. Читаются реальные ёмкости и постоянная LT-зоны после Init. Физика не меняется между четырьмя фазами, и идентичность сверяется до/после каждой. Значения TimeConstant задаются после включения стабилизатора, чей setter сам меняет эту постоянную.

Для каждого такта сохраняются источник, выход инерционного звена, выходы обоих каналов, SumPotential мембраны, отдельно NeuralPotential входа LT-зоны, её PrePotential и Potential, аксонный выход, реальный сигнал обратной связи мембраны и текущие TimeConstant обоих каналов. Последние являются состояниями модели; их нельзя подменять постоянным R*C из параметров покоя. В наблюдатель не добавляются скрытый фильтр или принудительный сброс между спайками пары.

Общий AxoneConductionObservation извлекает все события порога 0,5 и временное сопоставление в пределах 0–200 мс. Гипотезы о причине оцениваются по четырём физическим контролям и временным рядам. Одно количество спайков или временная пара не устанавливает причинность. Для пустого контроля временная связь не оценивается: общий API требует непустой вход, поэтому сохраняются null и явная причина, а реальные спонтанные выходы остаются в записи. Входы общего алгоритма не подменяются фиктивным событием. Нулевая реакция на второй импульс остаётся содержательным результатом при достоверном входе и полной записи. Наблюдение двух выходов ещё не подтверждает передачу M=4/8/16 через длинную цепь или дерево.

Общий контракт в Bin/Configs/SpikeSamples/StructTrain/AxoneTimeLearner/protocols/P1-node-recovery-v3.json содержит 72 case ID и hashes исходника. Всего 288 физических презентаций, но это не 288 независимых случайных повторов. Native gate ограничен 7200 с и 2 ГиБ памяти, оценочный предел первичных файлов 1 ГиБ. Выходные записи и контрольные ряды находятся только на .15/E:. Assertions проверяют полноту, конечность, входы и сохранность модели; научно положительный ответ пары не требуется для capture PASS.

Изменения ёмкостей и постоянной интегратора — отдельные феноменологические вмешательства. Без морфологической калибровки они не считаются доказанной перестройкой миелина или геометрии узла. Профиль для дальнейшей проверки цепи выбирается с учётом одиночных контролей, сохранения пары, временной ошибки и шага, а затем подтверждается на полной пачке новым протоколом. Неудачные клетки сетки сохраняются.

## Независимая обработка

Analyze-Server15Recovery проверяет запечатанный native gate, фактическую карту DLL, закрытие Job и неизменный SDK. Общие функции чтения CSV, извлечения событий и проверки записанного временного сопоставления берутся из уже использованных анализаторов; второй оптимизатор соответствий не создаётся. Для каждой из четырёх фаз сравниваются CSV и JSON, полное окно, реальные входы, типизированные параметры, все частоты и исходная/конечная идентичности.

Для контроля факторного вмешательства из копии семантического графа исключаются только две изменяемые ёмкости, TimeConstant LT-зоны и имя соответствующего объявленного LT-образа. Остальная физика должна совпадать между всеми клетками одной частоты. Это сравнение не заменяет исходную полную идентичность, которая остаётся в данных.

Операционное условие чистой пары: пустой контроль не даёт выходных событий; оба одиночных контроля дают по одному; пара имеет полную однозначную временную связь двух событий; выходы не обрезаны окном. Это функциональный критерий данной пробы, не доказательство конкретной причинной пары и не оценка абсолютного физиологического рефрактерного периода. Разница фактического такта второго входа в отдельном контроле и в паре сохраняется отдельно. Нельзя молча считать их полностью одинаковыми по номинальному времени. Набор успешно проверенных ISI публикуется как набор; монотонность восстановления не предполагается.

Отказ нативного assertion или неполная запись не превращается в отрицательный научный ответ пары. Сохраняются причина и исходные файлы; исправление анализа получает отдельную попытку без повторного расчёта модели.
