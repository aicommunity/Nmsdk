# Сравнение формирования импульса в аксонных сегментах

## Модель и вопрос

Проверяли, сохраняется ли одиночный спайк при последовательном соединении существующих аксонных сегментов и изменении шага расчёта. Источник — обычный NPGenerator: один импульс амплитуды 1 и длительности 1 мс через 10 мс от начала наблюдения. Полное окно — 0–80 мс. Сравнивали отдельный сегмент, цепочку из трёх сегментов и три узла с двумя межузловыми задержками по 2 мс.

Для каждой конструкции выполнена сетка 2000/20000/40000 Гц, пороги 0,01/0,02/0,03 и два типа LT-зоны. Первый использует штатную пороговую модель. Второй использует существующий NPLTZone с интеграцией и стабилизацией импульса, TimeConstant=1,44 мс. Порог выключения равен нулю. Зарегистрированы отдельные образы классов; общие заводские образы не изменялись. Параметры мембраны, фильтра и обратной связи сегмента внутри соответствующей пары сохранялись.

Цель — измерить форму и количество импульсов. Отсутствие выходного спайка является допустимым отрицательным результатом записи. Успешное завершение всех 54 записей не означает пригодности всех вариантов для проведения.

## Измерения

Таблица показывает подмножество с порогом 0,03. Каждый источник выдал один импульс. Длительность — число тактов непрерывного превышения уровня 0,5, переведённое в миллисекунды.

В полной сетке стабилизированный профиль дал один конечный импульс во всех 27 условиях. При штатной LT-зоне обе цепочки не дали выхода на 20000 и 40000 Гц при всех трёх порогах. Снижение порога отдельного сегмента до 0,01 дало три выходных события на этих частотах; при 0,02 — два. Следовательно, простое снижение порога в проверенной сетке не восстановило требуемое однократное проведение цепочки.

Ширина штатного выхода отдельного сегмента при пороге 0,03 составила 0,2 мс на 20000 Гц и 0,125 мс для каждого из двух событий на 40000 Гц. Стабилизированный профиль существенно изменил форму импульса. Это вмешательство одновременно вводит интеграцию LT-зоны и её собственную обратную связь; отдельный причинный эффект только одного из этих механизмов здесь не выделен.

## Следующая проверка

Стабилизированный профиль принят как кандидат для расширенной P1-серии, без изменения заводских умолчаний компонентов. Нужно проверить пачки, рефрактерность, длинные пути, повторяемость, структурные изменения, сохранение/загрузку и дальнейшее уменьшение шага. Значения 1,5/1,05/1 мс показывают необходимость такой проверки. Короткая успешная цепочка ещё не устанавливает рабочий диапазон задержек или физиологическую точность модели.
