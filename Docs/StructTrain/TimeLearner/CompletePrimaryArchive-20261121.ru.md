# Полный архив завершённого длительного опыта M40

Проверка21.11.2026 относится к четырём явно перечисленным закрытым каталогам:
длительный Train M40, его контроллер, подготовленный baseline и сохранённая
неудачная подготовка. Она не означает завершённой архивации всех экспериментов
Elder, Windows или новой серии перестановок.

## 1 Состав и внешнее хранение

Архив сохраняет5045 логических файлов общим объёмом12647050963байт, включая
полные модели, историю обучения, исходные конфиги, первичные измерения и
отрицательные квитанции. Уникальные байты занимают7206584698байт. Повторяющееся
содержимое хранится однократно с явными ссылками в контейнере; ни одно поле
JSON и ни один исходный файл не удалены ради уменьшения объёма.

Контейнер XZ-LZMA2 занимает148792604байт. Сбор завершился за543.75с в отдельной
ограниченной группе, exit0, runtime подтверждён, группа закрыта. Исходные
каталоги и прежние статусы не переписывались.

## 2 Независимая проверка восстановления

Из центрального CAS заново прочитан контейнер, проверены его hash и размер,
затем восстановлены и проверены все5045 файлов. Проверка выполнялась отдельным
серверным заданием `s11-complete-long-primary-restore-m40-a1` с2ГиБ памяти,
конечным временем1800с и ограничением временных данных16ГиБ. Все записанные
регулярные aliases также сохранены; ни один член архива не пропущен.

Результат:1/1 реальная интеграционная проверка, без ошибок и пропусков;
126.61с на всю группу, exit0, runtime подтверждён, все процессы закрыты.
Ограничители не сработали. Источник CAS не изменился. Временный восстановленный
кэш удалён штатным механизмом временного каталога после проверки; оригиналы
на сервере сохранены.
