# Положение целевого паттерна и сброс динамики:128 реакций Classic

Для фиксированной модели Classic проверены восемь циклических порядков
предъявления одной матрицы. При сбросе перед каждым паттерном во всех
порядках получены TP1/FP1/FN0/TN6. При сохранении динамики ложных
срабатываний больше: FP2 либо FP3. Во всех условиях есть ответ после
четвёртого целевого импульса. Однако в семи непрерывных последовательностях
цель вызывает также ранний ответ; один TP по окну не доказывает
распознавание только полностью предъявленного паттерна.

## Условия и область вывода

Использована прежняя модель Classic Count8, без нового обучения или
подбора порога. Model revision:
`8d66abe56a9ce8468e3888834b32017f23fc724d70cd2cd7a33ffe678797d226`.
Порог зафиксирован:0,026100997379370133. Частота2000 Гц; M=4,
целевые времена относительно первого импульса —0/80/240/480 мс.
Модель получена из ограниченного поиска; сертификат Exact этим Test
не создаётся. Порог ранее выбран по той же исторической матрице.

Восемь строк исторической матрицы циклически сдвинуты. Поэтому цель
присутствует в каждой позиции, но проверены только восемь порядков,
а не все40320 перестановок. Каждый порядок проверен со сбросом перед
каждым паттерном и в непрерывном потоке. Первый паттерн непрерывной
серии начинается с объявленного исходного состояния. Интервал между
началами соседних предъявлений —690,5 мс; конечное окно включает
не менее2 с после последнего входного импульса.

Всего16 условий по8 завершённых наблюдений. Исходные72 сохранены;
недостающие56 рассчитаны один раз. Это исследование протокола одной
замороженной модели, а не128 независимых обучений, случайных повторов
или новых независимых тестовых паттернов.

## Классификация по полным окнам

Во всех строках таблицы TP=1 и FN=0. Позиция указана с единицы.

| Сдвиг | Позиция цели | FP со сбросом | TN со сбросом | FP без сброса | TN без сброса |
|---|---:|---:|---:|---:|---:|
| r0 |1|1|6|3|4|
| r1 |8|1|6|3|4|
| r2 |7|1|6|2|5|
| r3 |6|1|6|3|4|
| r4 |5|1|6|3|4|
| r5 |4|1|6|3|4|
| r6 |3|1|6|2|5|
| r7 |2|1|6|3|4|

Таким образом, в исследованной reset-per-trial постановке результат
с одним FP сохраняется при переносе цели в любую позицию. Для
непрерывного потока той же устойчивости не обнаружено. Состав матрицы,
интервал и модель здесь фиксированы; влияние иных ITI и произвольных
перестановок этим результатом не установлено.

## Время ответа на цель

Первичные timestamps независимо прочитаны на сервере. Во всех восьми
условиях со сбросом есть единственный целевой spike через483,5 мс
от первого входного импульса. Для непрерывного r0 ответ тот же.
В непрерывных r1–r7 зарегистрированы два ответа:241,5 и483,5 мс.
Последний целевой импульс подан через480 мс. Следовательно, второй
ответ появляется через3,5 мс после него, а первый возникает ещё до
завершения пачки.

Эти времена относятся к зарегистрированным выходным событиям.
Они не обозначают время глобального максимума потенциала сомы:
срабатывание порогового элемента само влияет на дальнейшую динамику.
Подсчёт TP по окну и оценку раннего ответа необходимо сохранять
раздельно. Причинную связь раннего ответа с конкретным прежним
паттерном ещё нужно проверять отдельным вмешательством.
