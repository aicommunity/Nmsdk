# Native-контроль запрета повторного использования одной вершины

## Проверяемый дефект

Одна измеренная вершина одного канала не должна подтверждать обучение двух
разных закреплённых импульсов. Совпадение времени пиков разных физических
каналов само по себе допустимо. Максимум всей пачки для Test не меняется.

Реальный Classic native fixture, 2000Hz, N=2, подаёт штатный источник
через scheduler. В этом отрицательном контроле два диагностических окна
явно направлены на Soma0. Получившаяся общая вершина раньше могла пройти
структурную проверку сертификата; теперь production capture отклоняет её
с `shared_measured_peak_between_stimuli`.

Это специально сформированный контроль границы сертификата, а не утверждение,
что обычный controller уже выдаёт Exact на таком случае. Он не решает
принадлежность произвольных двух разных вершин разным импульсам и не заменяет
штатное обучение пачкой одиночной характеристикой.

## Реальные сигналы

На рисунках сохранены все исходные отсчёты, без сглаживания/децимации.
Потенциал указан в native units: соответствие SI здесь не подтверждалось.
Вверху — записанная сома и фактический выход генератора; внизу — отдельный
масштаб входа с метками событий подачи. Розовый фон показывает два окна,
пунктир — одну используемую ими вершину Soma0.

В нижней панели видна существенная деталь: между близкими событиями pulse0
и pulse1 выход генератора не возвращается к нулю. Метки событий не следует
принимать за два раздельных наблюдённых передних фронта. Один непрерывный
входной участок и одна вершина не дают доказательства двух независимых
закреплённых откликов.

![Soma0: общая вершина двух окон и фактический вход](../../../Reports/StructTrain/TimeLearner/s07-assigned-vertex-temporal-m40-a1/selected/soma0-response.png)

Вторая сома записана независимо; её сигнал показан для проверки физического
контекста. В отрицательном контроле оба окна направлены именно на Soma0.

![Soma1: полное зарегистрированное окно и фактический вход](../../../Reports/StructTrain/TimeLearner/s07-assigned-vertex-temporal-m40-a1/selected/soma1-full.png)

Размер2240×1280, шрифт12pt. Для обеих сом построены full/response варианты;
в этом коротком зарегистрированном окне response целиком совпадает с full.
Дополнительное увеличение выполнено для входного участка. Изображения
проверены визуально: оси, легенды и метки читаются, обрезанных подписей нет.
Спайковый канал этим fixture не записан: spike response остаётся unknown,
а не «0 спайков». Классификация не оценивалась.
