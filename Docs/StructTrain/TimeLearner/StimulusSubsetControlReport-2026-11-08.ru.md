# Пробы подмножеств пачки: контроль импорта и временных данных

На двух сохранённых diagnostic/stopped состояниях проверены полная пачка,
удаление внутреннего импульса и поздний одиночный импульс. Все6 Console-проб
завершились с полными временными данными, неизменными моделью, исходным
InputPattern и controller history.6 проверок нового анализа и7 регрессионных
проверок reader прошли без skipped. Это адресная приёмка диагностического
контура, без повторного обучения и оценки классификации.

## Какие состояния показаны

Это состояния **с эффективным порогом LTZone0,0117** из
`Classic-threshold-low-retry32/session/1` и
`Branch-threshold-low-retry32/session/1`. Они отличаются от high-threshold
состояний с порогом100 и гладкими откликами из
[предыдущего научного отчёта](HighThresholdSinglePulseScientificReport-2026-11-07.ru.md).
Имена старых каталогов `...training100...baseline` сами по себе не подтверждают
физику источника. Здесь проверены поле Threshold эффективного графа, source
run ID и model revision; они явно указаны на новых рисунках и в cache manifest.

Полные значения индивидуальных сопротивлений, source-state hash и model

в manifest сохраняет значение базового fingerprint; поля `base_model_revision`
и `effective_model_revision` задают обе оси явно.
Номера импульсов и solo-входа здесь начинаются с0; подписи Soma — с1.

## Протокол

Для каждой топологии выполнены три независимых импорта одного состояния:

1. Full: исходные импульсы `[0,1,2,3]`.
2. Omit-interior: `[0,2,3]`.
3. Later-single: только `[3]`.

Dataset менялся временно, между измерениями, без retarget обучения. После
пробы штатно восстановлены полная пачка, физическая размерность и Dataset;
перенос проверен readback, модель — семантическим fingerprint. Controller
оставался idle. Политики определения пика и окно поиска пика в этих пробах
отсутствуют. История обучения не обрезалась для получения удобного результата.

Окно записи каждой пробы1,8с. CSV содержит фактическое время, выход генератора
и SumPotential каждой наблюдаемой сомы. Неполные, повреждённые или rehashed
подменённые данные не принимаются reader. Spike capture выключен: неизвестное
число spikes не считается нулём. По этим пробам не вычислялись accuracy,
target hit, FP/FN, margin или сертификат Exact.

## Ограничения и следующий эксперимент

Форма этих low-threshold откликов не используется для пересмотра прежних
high-threshold измерений. Для исследования слияния пиков из обсуждавшегося
графика нужны отдельные пробы сохранённых high-threshold состояний с
проверенными Threshold100 и конкретными source-state/model hashes.
[Постановка14 проб](HighThresholdSubsetStudyDesign.json) сохраняет исходный
selector Branch2 и selector Classic0; подготовка не означает выполнения проб.
Общий максимум full-пачки не подставляется вместо максимума закреплённого
импульса при Train. Контроль full/omit/single сам по себе также не доказывает
линейность, уникальную принадлежность вершины или сходимость обучения.

Этот набор не заменяет итоговые Test-отчёты с реакциями на **все** target/foil
паттерны, перестановками и ITI. Они остаются обязательной частью полного плана.
