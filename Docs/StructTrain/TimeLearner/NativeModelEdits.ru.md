# Native изменения L/Ns/Rs: рабочая ветка

Ветка stage07/native-structural-edits добавляет общий NativeModelEditor и методы
ReadNativeParameters/ApplyNativeParameters у обоих learner. Изменения разрешены
только после завершения и получения результата native-пробы. Learner не получает
вложенный Calculate, Build или Reset. Число входов и последний опорный вход задаёт
контроллер; editor читает эффективные банки, а не legacy requested Ns/Rs.

Кандидат сначала строится через штатный Save/Load в том же storage. Копируется
полный физический граф с явными stimulus-портами, а динамика инициализируется
заново. Это отдельная операция ClonePhysicalGraphForEdit, не Alloc/Copy и не
прозрачный checkpoint динамики. Она не выдаёт сертификат обучения. Образы в
storage остаются неизменными. После проверки кандидата живой нейрон изменяется
штатными structural setters/Build; whole-learner rebuild и wake-проходов нет.

Режим 2 нейрона задаёт вектор длин кабелей. Режим 1 сохраняет общее скалярное
выделение и при необходимости наращивает его; входы являются точками подключения.
Режим 0 сохраняет явный граф и разрешает только существующие точки. Общие
параметры физики должны принадлежать storage: UseElementDefaults=true отклоняется
до изменения живой модели. Сохранившиеся каналы обязаны сохранить реальные C,
R, RestingR, FBR, частоту и тип; fallback C не применяется. Возврат к меньшей
длине является новым явным изменением с новой пробой, не восстановлением динамики.

У learner StructureBuildMode=0 сохраняется заданное выделение кабеля: mode 2
нейрона может нарастить нужный участок, но не сокращает не принадлежащий входам
остаток; mode 0 нейрона не создаёт отсутствующие точки. Редактируются только
объявленные старые/новые input-банки и их тормозные точки. Прочие банки и их
внутренние подключения остаются частью исходной модели.

Нормализация N0 меняет целое число синапсов, дополнительные экземпляры создаются
из образа соответствующей роли. N1 требует один синапс в банке. Rs задаётся
индивидуально. Совпадающие точки Branch должны описывать один эффективный банк;
конфликт тормозных Rs в одной физической точке отклоняется явно. NextSeg и SegEI
создают реальные inhibitory targets; совпадение delta=1 сохраняет приоритет SegEI.
Освобождённые прежние input-банки удаляются как часть topology; остальные
excitation-банки сохраняются. Stimulus отсоединяется только от принадлежащих
контроллеру synapse.Input, сохраняя внешний fan-out и чужие входные связи.
Удаление узла, который является источником внешнего наблюдателя, отклоняется.

Read-only проверка учитывает конкретные уравнения NPulseChannel/NPulseSynapse,
все фактические synaptic slots, Weight, averaging, PSI и дискретную секрецию.
Для канала вычисляется локальный коэффициент K=(1+Gmax*R)^2/(C*R*f) для рабочих,
rest и feedback R. Это проверка локальных шагов, не доказательство спектральной
устойчивости всей связанной нелинейной сети. Неизвестный интегратор или источник
аналогового входа не получает автоматического подтверждения. N1 отдельно получает
свой фактический no-crossing интервал для каждого входа, с учётом фиксированных
проводимостей и configured floor; общего пересечения интервалов не требуется.

Отклонённый preview не должен менять fingerprint живой модели. Контроллер может
продолжить ограниченный поиск через DeclineEdit, только подтвердив неизменность.
Неожиданный сбой при применении живой модели помечает её Failed и блокирует
пробы/расчёт до исправления: такой сбой не маскируется успешным bool Build и не
является доказательством сходимости. Полная транзакция PostTune остаётся отдельным
этапом. Частота дерева остаётся единой. C-trim, удалённые segment-specific baselines,
полный trained-state export и configured ControllerVersion=2 ещё требуют работы.

Промежуточный snapshot root d06c51012d21141d12556e500db81c68e35804ce прошёл
33 адресных проверки на обоих серверах: Classic/Branch × N0/N1 при 2000 Гц,
контроллер/финальный gate, конкретные integration bounds и отрицательный контроль
слияния волн. При интервале 30 мс после роста до L=3 две реакции сливаются:
наблюдение корректно остаётся incomplete assignment, хотя окно исполнено целиком.
Для структурных roundtrip-проверок используется отдельный протокол 80 мс.
Он не заменяет научные условия и не подтверждает качество распознавания.
20000 Гц и M40 ASan ещё выполняются; последующее уточнение владения чужими
банками/выделенным кабелем и соответствующие fixtures пока не проверены.

Возможность перестроения сетки Rs по новым границам для каждого предложенного L,
продолжение поиска после всех физических ограничений, полная матрица inhibition,
конфигурационный dispatch и export состояния остаются частью общего плана.
