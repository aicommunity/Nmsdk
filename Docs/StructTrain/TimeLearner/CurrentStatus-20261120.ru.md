## Обучение и научные результаты

Продолжаются два cold N4/N1 Train с CapturedPerInput и прежними допусками.
Оба используют Root893b7344eb8794e5ef981eb133e669b6060e5aa3 и
Pulsec508392a8c963ceb639050d737717bff0d853b3a; runtime работающих заданий
не изменяется. Их итоговые модели, сертификаты и новая классификация
ещё не получены.

| Задание | Последняя проверка | Ограничение вывода |
|---|---|---|
| M40 Branch/On A2 | PID3865301 жив;434 записанные native-пробы | Повтор с24GiB native вместо8GiB; остальная постановка сохранена |
| Elder Classic/On A1 | PID2199106 жив;631 записанная native-проба | Исходный Train продолжается, перезапуска не было |

[Квитанции этих проверок](../../../Reports/StructTrain/TimeLearner/TerminalScienceAB-20261120/active-train-observations.json).
Число native-проб не является процентом готовности. Complete/valid в raw
packet подтверждает полное корректное наблюдение, а не синхронизацию или
сертификат. Внутренние composite-пробы могут иметь пустой список peaks:
назначение закреплённого отклика выполняется при сборке composite-измерения.

Первый Branch A1 остановлен ядром по OOM при8GiB. Финальной обученной модели
не записано; его первичные данные сохранены в external primary
a47c0d0d4279b21692ed90c0d22d85de765bbff6f5422b3f8df773a9aa8c503f.
Это ошибка исполнения, не отрицательный научный результат модели.

Для A2 выполнено сравнение заранее выбранных первых400 проб с A1:
все400 CSV и400 JSON побайтно совпали; совпали native job и initial state,
ID проб и признаки complete/valid. Следующее наблюдение того же PID/start
подтверждает продолжающуюся A2. [Полная квитанция и external proof](../../../Reports/StructTrain/TimeLearner/TerminalScienceAB-20261120/branch-memory-prefix400.json).
Это проверка воспроизводимости начального участка и отсутствия эффекта
смены memory cap на нём. Она не доказывает воспроизводимость полного Train,
сходимость, независимый seed-повтор или результат распознавания.

После закрытия Train первоочередная задача — actual retained model,
полный Test восьми паттернов, объявленная калибровка и реальный прогон
с выбранным порогом. Старые followups для неудавшегося Branch A1 не
используются для A2. Нужны новые controls, привязанные к его фактическому
состоянию. Незавершённое обучение остаётся диагностическим результатом.
