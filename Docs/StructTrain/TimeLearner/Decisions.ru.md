# Обязательные решения

1. Августовские визуально подтверждённые 4/8–6/8 являются рабочими результатами
   исходного fixed-order/fixed-ITI протокола. Новые критерии считаются отдельно.
2. CapturedPerInput остаётся исходной математической целью. Общая амплитуда A*
   требует отдельного научного A/B и не входит в исправление controller.
3. Build/Calculate/Reset возвращают true. Ошибки передаются через состояния и
   диагностику. Общий scheduler и штатный порядок вычислений сохраняются.
4. Uniform physics задаётся immutable storage-образами. Learned per-input overlay
   применяется на границе структурного изменения и сохраняется при growth/load.
5. Нельзя считать Alloc/Copy рекурсивным checkpoint динамики. Model export,
   parameter overlay и controller checkpoint — разные операции.
6. C-trim default off. Успех алгоритма не требует изменения C. Не допускается
   fallback 1 nF вместо отсутствующего эффективного значения.
7. CalculateMode 0/1 сохраняются. External stop не означает convergence.
   Learner StructureBuildMode 0/1 отличается от Neuron StructureBuildMode 0/1/2.
8. Done, execution success, validity, convergence, calibration и evaluation
   являются отдельными осями. Сертификат связан с hash конкретной модели.
9. Same-Matrix calibration допустима как исторический протокол; независимый Test
   фиксирует модель и порог до оценки. Порог подтверждается реальным прогоном.
10. Legacy ControllerVersion=1 загружается при отсутствии свойства. Version=2
    не объявляется доступной до реализации и проверки нового контроллера.
11. Все merge выполняются с --no-ff. Rebase, squash, cherry-pick, force push не
    используются. Завершённые этапы входят в develop: сабмодули, затем корень.
12. Основные сборки и эксперименты выполняются на 10.245.1.11 и 10.245.1.17 через
    10.245.1.12. **Уточнение пользователя при реализации:** логин везде `user`.
    Дополнительно разрешена Windows-машина `user@10.245.1.14`, SSH по ключу,
    в отдельном agent workspace; пользовательский `C:/Projects/Nmsdk` сохраняется.
    Это дополнительный worker, а не замена обязательной приёмки на двух Linux.
    Пароли не хранятся в репозитории. Источники и результаты синхронизируются Git.
13. Серия D остановлена пользователем. Старые очереди автоматически не запускаются.
14. Совпадение N0/N1 либо seed-результатов допустимо. Проверяется реальное
    применение фактора, а не искусственное требование разных исходов.
15. Neuron StructureBuildMode=0 сохраняет порядок явного графа. Native Build
    не должен частично переставлять Soma/LT, пропуская дендриты. Для serializer
    mask нужны type и visibility group; одна успешная SaveComponent не доказывает
    наличие параметров. Равное самоприсваивание может не вызывать setter.
16. Уточнение пользователя 07.11.2026: Train измеряет максимум отклика
    закреплённого импульса; Test оценивает реакцию модели на весь паттерн.
    Принадлежность отклика и выбор его наибольшего пика — отдельные проверки.
    Несколько меньших пиков не означают автоматическую неоднозначность.
    Глобальный максимум пачки не подставляется в индивидуальную цель Train;
    общая амплитуда Test не заменяет реальные spikes и late-response analysis.
    [Контракт и открытые исправления](PeakMeasurementContractReview-2026-11-07.ru.md).

17. Уточнение пользователя07.11.2026 о слившихся откликах: предпочтителен
    консервативный вариант — не использовать одну общую вершину сразу как
    два независимо установленных закреплённых пика. Пользователь отдельно
    отметил научную неопределённость вопроса; это рабочая политика, не
    доказанная физическая теорема. Пересекающиеся окна сами по себе не
    разрешают совместное назначение. Неоднозначность принадлежности не
    доказывает отсутствие физического отклика или PhysicalInfeasible.
    Несколько меньших пиков от одного фактически одиночного импульса не
    считаются таким слиянием. Старые receipts не переоцениваются автоматически.

18. Уточнение пользователя: раздельная ранняя вершина допустима как отклик
    закреплённого раннего импульса, даже если хвост раннего отклика усиливает
    позднюю вершину. Это не разрешает назначать одну неразличимо слившуюся
    вершину нескольким импульсам. Общий максимум Test и закреплённый максимум
    Train сохраняются разными измерениями.
19. Parameter-only model/image transport не является checkpoint динамики.
    Различие transient buffers образа само по себе не доказывает потерю
    обученной физики. Проверяются исходные checksum, полный живой graph и
    semantic image identity. Независимо от этого XML каждой поставляемой
    image definition обязан подтверждать её declared identity через native
    readback, в том числе при уже зарегистрированном классе. Наличие класса
    в storage не является доказательством корректности поставленного XML.
    [Воспроизведённые дефекты и кандидаты исправлений](NativeLoadXmlPreimage-20261110.ru.md).
