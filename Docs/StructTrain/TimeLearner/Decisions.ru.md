# Обязательные решения

1. Августовские визуально подтверждённые 4/8–6/8 являются рабочими результатами
   исходного fixed-order/fixed-ITI протокола. Новые критерии считаются отдельно.
2. CapturedPerInput остаётся исходной математической целью. Общая амплитуда A*
   требует отдельного научного A/B и не входит в исправление controller.
3. Build/Calculate/Reset возвращают true. Ошибки передаются через состояния и
   диагностику. Общий scheduler и штатный порядок вычислений сохраняются.
4. Uniform physics задаётся immutable storage-образами. Learned per-input overlay
   применяется на границе структурного изменения и сохраняется при growth/load.
5. Нельзя считать Alloc/Copy рекурсивным checkpoint динамики. Model export,
   parameter overlay и controller checkpoint — разные операции.
6. C-trim default off. Успех алгоритма не требует изменения C. Не допускается
   fallback 1 nF вместо отсутствующего эффективного значения.
7. CalculateMode 0/1 сохраняются. External stop не означает convergence.
   Learner StructureBuildMode 0/1 отличается от Neuron StructureBuildMode 0/1/2.
8. Done, execution success, validity, convergence, calibration и evaluation
   являются отдельными осями. Сертификат связан с hash конкретной модели.
9. Same-Matrix calibration допустима как исторический протокол; независимый Test
   фиксирует модель и порог до оценки. Порог подтверждается реальным прогоном.
10. Legacy ControllerVersion=1 загружается при отсутствии свойства. Version=2
    не объявляется доступной до реализации и проверки нового контроллера.
11. Все merge выполняются с --no-ff. Rebase, squash, cherry-pick, force push не
    используются. Завершённые этапы входят в develop: сабмодули, затем корень.
12. Сборки и эксперименты выполняются только на 10.245.1.11 и 10.245.1.17 через
    10.245.1.12. **Уточнение пользователя при реализации:** логин везде `user`.
    Пароли не хранятся в репозитории. Источники и результаты синхронизируются Git.
13. Серия D остановлена пользователем. Старые очереди автоматически не запускаются.
14. Совпадение N0/N1 либо seed-результатов допустимо. Проверяется реальное
    применение фактора, а не искусственное требование разных исходов.
