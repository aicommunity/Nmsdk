## Production path

Existing learned/stopped loaders и composite package dispatcher принимают
явную schema6 через отдельный `candidate_window_package_evidence`. Старые1–5
wire и тело package5 auditor сохранены. Нет конвертации archive2 в packet3,
certificate2 или protocol4 observation.

Package6 имеет ровно прежний package5 keyset, но требует cold7/protocol5,
runtime2/archive2/certificate3. Existing archive2 reader независимо проверяет
каждый N+2 raw CSV, actual native/events/context, geometry и reference-anchored
candidate proposal. Если задан external resolver, missing/corrupt mirror не
подменяется embedded bytes. Исходные и текущие native snapshots, storage images,
dataset full-source semantics, actual trained inputs и C0 проверяются общим
physical auditor. Package6 дополнительно проверяет точную saved metadata и
порог эффективного LT из semantic graph; это не native XML import attestation.

Original cold7 не заменяет текущий runtime2: actual warm bounds/tolerances/caps,
initial current-attempt model/epoch и normalization проверяются отдельно.
Первый фактический current record связывается с runtime initial boundary; при
пустой текущей попытке этот boundary обязан совпасть с текущей физической моделью.
Старые reference records сохраняют собственные attempts/caps/source family.

Certificate3 связывает complete original allN references с complete latest
OBSERVED current final sweep, включая более поздний rejected/partial record.
Проверяются topology order, положительные canonical trial serials, общий
candidate witness, current attempt/model/epoch, recipe/instance/proof IDs.
Arrival каждого full-before вычисляется от его фактического origin event.
Timing residual сохраняет знак, anchor — input N−1; self-residual anchor равен0
и при plateau. Допуски берутся буквально из runtime, без dt/1% замены.

## Stopped DATA и completion

Stopped package требует diagnostic/null certificate и явный terminal outcome.
Принятых final DATA может хватить для mathematical Exact даже после реального
stop: receipt различает `mathematical_exact` и публичный `exact=null`.
Статусы terminal_provenance_verified/native_execution_verified/native_import_verified
и live_authority_restored всегда false. Самодостаточный DATA auditor не доказывает
историю controller traversal или завершение producer при согласованной переписи
всех публичных metadata/hash. Будущая pipeline classification обязана связать
исходные execution.exported package bytes/SHA, artifact и source case. Нового
источника authority или научного PASS этот patch не создаёт.

Summary7/Console execution4 — следующий отдельный frozen-contract chunk.
До него переданный summary для6 отклоняется явно; package не синтезирует summary
и не использует старый summary6 codec для новой схемы.
