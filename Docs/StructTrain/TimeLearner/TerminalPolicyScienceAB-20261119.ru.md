# Холодное N4 обучение: парное сравнение terminal policy, 19 ноября

Цель — получить новые измеренные результаты Classic/Branch после исправления
завершения Train и переноса модели. Сравнивается включённое и выключенное
восстановление измеренной модели при остановке. Научные8/8 не являются приёмкой.

## Условия и четыре случая

Исходные cold-конфигурации взяты из опубликованного finite-train primary
`6a86940f1486ca6754a211bcf99f70f2d02a86312d6eb4fac432fbe5f49e74fd`.
Сохранённая обученная модель не используется как seed. Storage-профили,
физика, частота2000Гц, начальная структура и target остаются исходными.

| Поле | Одинаковое значение для обеих политик |
|---|---|
| Размерность / нормализация |N4 / N1|
| Амплитудная цель |CapturedPerInput; опорный вход3|
| Train peak |Максимум закреплённого импульса|
| Амплитудные допуски |Абсолютный1e−5, относительный0|
| Временной допуск |0.02с|
| Поиск |Один sweep, до24 кандидатов на управляемый вход,160 логических проб|
| Model time limit |10000с поиска|
| Внешний tick limit |20000002 в обоих случаях; два тика предназначены для завершения|
| Внешний wall limit |85200с на native процесс;84600с внутри Train|
| Optional modes |C-trim, PostTune, automatic threshold Off|

Четыре задания: `classic-off`, `classic-on`, `branch-off`, `branch-on`.
У On flat configuration9 содержит исходную базовую schema8 и explicit terminal
policy с30с wall allowance финализации. Off сохраняет schema8. Физическая
проекция и search budgets совпадают. Run ID различаются только как идентичности
попыток. Эти детерминированные прогоны не считаются независимыми seed-повторами.

Если восстановление фактически не потребовалось, одинаковые модели являются
допустимым результатом. Само включение политики не доказывает её действие.
Фиксируются terminal event, source/actual revision и epoch, все residuals,
причина остановки и наличие либо отсутствие сертификата.

## Следующая оценка

После Train выполняется полный Test восьми исходных паттернов с неизменной
моделью. Для кандидата порога используется максимум всего отклика; выбранный
порог обязательно проверяется реальным native Test. Same-Matrix calibration
маркируется отдельно от независимой frozen evaluation.

Для каждого паттерна публикуются target/foil response, TP/FN/FP/TN, полное окно,
времена спайков, модель/порог и их fingerprints. Временные графики показывают
мембранный потенциал сомы вместе с фактическими входными импульсами. Масштаб
должен позволять видеть отдельные вершины и отличать тишину от слабого ответа.
Новые отвлекающие паттерны оцениваются только после фиксации модели и порога.

Все первичные данные и полные отчёты хранятся во внешнем архиве M40.
Корневой Git содержит код, этот протокол и компактные проверяемые ссылки.
