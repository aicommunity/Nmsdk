# Временные графики полной серии перестановок

Команда `python -m Scripts.StructTrain.TimeLearner report <closed-study> --format frozen-order --output <new-report>` строит отчёт завершённого `frozen_stopped_order_native_result`. Каталог источника содержит `result.json`, `runs/baseline` и `runs/study` с полными native manifests и первичными данными. Незавершённая серия не получает этот отчёт.

Используется общий production renderer диагностического распознавания. Отображаются все паттерны во всех объявленных позициях, каждый записанный канал сомы и LT decision potential, фактические входные импульсы и спайки. Сохраняются полные временные диапазоны, отрицательная фаза сброса, увеличенные положительные отклики и временные детали с масштабом не менее восьми пикселей на native timestep. Отсчёты не прореживаются. HTML-индекс показывает TP/FP/FN/TN отдельно по каждой перестановке; нулевая нумерация позиции target указана явно.

Перед построением проверяются обе исходные серии, соответствие метрик manifest, неизменность модели и порога, полнота множества перестановок и проб. После построения метрики повторно сравниваются с исходными, проверяется сохранность исходных файлов. Результаты остаются диагностическими: это сохранённая остановленная модель, фиксированный порог, reset-per-trial, без нового обучения или независимого раздела данных. Полнота галереи не заменяет ручной визуальный просмотр.

Тяжёлые модели, первичные данные и галереи хранятся только во внешнем архиве на M40. В Git публикуются код, этот протокол и компактные ссылки на архивы/приёмки. Первая проверка на фактической серии baseline8 + study56 ещё ожидается; документ не утверждает её прохождение.
