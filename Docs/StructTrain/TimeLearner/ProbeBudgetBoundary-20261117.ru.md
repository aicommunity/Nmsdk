# Граница бюджета проб TimeLearner

Длинный cold Classic17 ноября выполнил792 native пробы, outcome
budget_exhausted/maximum_probes_exhausted. Фактически экспортированы
L=[51,1,1,1], Ns=1, Rs=86МОм; последняя CandidateEvidence относится к L50.
Это остановленная модель для diagnostic Test, не сертификат сходимости и
не утверждение о лучшем измеренном кандидате.

Подготовлен адресный перенос проверки исчерпания maximumProbes в начало
BoundedTrainingSession::NextAction, до выдачи очередного edit/domain action.
Отдельная regression использует настоящий контроллер и ProbeRecorder,
Classic/Branch × N0/N1, с derived-domain действиями N1. До серверного запуска
она не считается пройденной. Следующий runtime нельзя подменять в живом опыте.

Это устраняет лишнее неизмеримое изменение после последней пробы. Полный
откат к best, сбой во время пробы, восстановление динамики и разделение
физической модели с историей остаются отдельными задачами исходного плана.
