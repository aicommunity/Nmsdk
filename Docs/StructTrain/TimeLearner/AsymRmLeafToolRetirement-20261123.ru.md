В PulseLib и Rdk совпадений не найдено. Исполняемых буквальных callers в этой
области не обнаружено. Поиск имён не исключает внешних или динамических callers.

Проверка точных blob обнаружила отдельную старую копию
`Configs/SpikeSamples/StructTrain/SelectivityLtzCalibrate/scripts/verify_pattern_span.py`.

всех старых реализаций и завершение миграции здесь не заявляются.

Исходники извлекаются по полным commit/path/blob/размеру/SHA256 из
[manifest](script_migration.json). Основной пользовательский каталог и runtime
живых опытов не меняются. Для Bin создан отдельный clone

этого пакета. Чтение прежних blob из пользовательского object store было только
чтением, без fetch, изменения refs, файлов или Git-объектов.

## Приёмка и ограничения

Нужно проверить production `history verify-migration` для всех361 записей,
отрицательный контроль с возвращённым старым путём и точную область4D+5M.
Проверка выполняется на M40 и Elder без запуска моделей и без исполнения архивных
скриптов. Метаданные portable Git fixture не являются полным SDK checkout.
До положительных квитанций кандидат не считается принятым; после них общий
этап9 и его объединение в develop всё равно остаются открытыми.
