# Освобождение Elder: подтверждённые распакованные дубли

06.11.2026 удалены только распакованные копии `native-result/native` завершённой
проверки `s07-integrated-native304-normal-a1`. Удалено3907 файлов,
1489206262 bytes (около1.49GB). Свободное место выросло с1304485888
до2800640000 bytes по замеру самого задания.

Каждый файл сопоставлен по размеру и SHA256 с исходным Git manifest
`d3429a33209a9985a3d30164df69206713f8d724`. Перед unlink повторно проверены
путь, inode/mtime/link count и hash; операция записана в fsync-журнал.
Исходный `primary.tar.xz`11738976 bytes сохранён и повторно проверен:
`e95626641478c04131900bf17aebed1cca3264f8ad6e05499d4409d3e5a97414`.
28 критических файлов runtime остались неизменными. Сборки и модели не запускались.

A1 остановилась до создания reservation из-за попытки резервировать файл вместо
каталога. A2 остановилась до удаления на недоступном для чтения системном
ssh-agent. После отдельной проверки его родителя gnome-keyring-d в A3 добавлено
явное исключение только этой пары процессов. Невозможность просмотра fd/cwd
этих системных помощников записана; это не утверждение, что они были просмотрены.
Неизвестный защищённый процесс по-прежнему запрещает очистку.

Все три попытки сохранены в data commit
`8d627bed46df93a2e96e49647da7d56c03134f50`. Локальная проверка всех26 archive
members и3907 пар journal/исходный manifest отражена в
[ElderExpandedDuplicateCleanupVerification.json](ElderExpandedDuplicateCleanupVerification.json).
Крупные prepared-files.json и журнал хранятся внутри primary.tar.xz без повторной
распакованной копии в текущем дереве. Сведения об остановках и fresh closure
сохранены. A1 не имела lease: это отдельно отмечено, а не превращено в успешный job.

Для восстановления извлечь только `native-result/native/*` из исходного архива
или соответствующего Git bundle. Архив лежит на два уровня выше каталога native;
на месте оставлен CACHE_RESTORATION.md. Это обслуживание диска, не приёмка
алгоритма, не научный результат и не завершение исходного этапа2.
