# Summary7 / Console4: исходный код интеграции

Подготовлены явные пары package6/protocol5/archive2/summary7/execution4.
Прежний summary6 продолжает использовать runtime1; новый summary7 использует
runtime2 и допускается на завершённой принадлежащей сервису границе. Общая
сериализация полей не подменяет версию протокола и не превращает данные в
подтверждение фактического исполнения.

Console выбирает wrapper по явной версии configured declaration: cold6 →
execution3, cold7 → execution4. Публикация проверяет пары package5/archive1 и
package6/archive2 до создания файлов, сохраняет точные primary/sidecars/index.
Preflight имеет известные нулевые счётчики; до захвата источника неуспешный
Start сохраняет unknown/null для attempt/archive. Для protocol5 preflight
вызывает штатный ValidateCandidateWindowTrainingConfiguration, не старый
валидатор bounded protocol3/4.

Существующие transport и recognition функции уже вызывают общий
PrepareNativeLearnedState. Поэтому новый нативный package6 проходит через
родной import, без изменения conversion/evaluation job1 и recognition1.
Добавлены 14 исходных тестов: summary/group bindings, точный filesystem mirror,
повреждение primary и смешанные версии, известные/неизвестные счётчики и
реальные frozen whole-pattern пробы Classic/Branch/diagnostic. Они пока НЕ
запускались. Целевой максимум Test вычисляется по всему записанному сигналу,
без применения assigned Train окна; успех классификации не утверждается.

Native worker теперь собирает также NeuroModelerConsole: одни inline header
tests не компилируют TimeLearnerTrainingJob.cpp и transport entry points.
Новая версия worker должна быть одинаковой в SDK и Tool при следующем запуске.
Это изменение не подтверждено прежним запуском native48.

Остаются обязательными новая серверная сборка, все затронутые нативные проверки,
Python summary7/execution4 readers и сквозные реальные Console jobs. Локально
выполнялись только чтение исходников и Git-проверки; scientific admission нет.
