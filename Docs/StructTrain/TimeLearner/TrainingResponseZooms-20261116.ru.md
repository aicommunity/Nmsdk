# Вершины на сравнительных графиках обучения — 16 ноября 2026

Сравнительный production-сценарий `test_uniform_profile_training_report` включает существующий `native_response_zooms` renderer. Для каждой выбранной группы и каждого soma-канала добавляется участок ±50 native frames около первого записанного глобального максимума полного предъявления. Полный отклик, omission-контроли и повтор показываются в одних координатах, с фактическим входным сигналом, без прореживания и с масштабом не менее 8 px/tick. Обзор и прежние увеличения границ окна сохраняются. Неполные группы остаются CENSORED, отсутствующие пробы не достраиваются.

Это выбор масштаба рисунка. Он не меняет максимум закреплённого импульса, результаты его причинного сопоставления, tolerances или сертификат обучения. Вершина полного отклика может принадлежать другому импульсу. Для Test по-прежнему используются полный отклик и настоящие native spike events.

Адресная интеграционная проверка на реальных данных требует ровно один новый вид на каждый выбранный group/channel. Она заново читает исходный full-trial CSV, сверяет bytes/SHA256, вычисляет первую максимальную записанную точку и проверяет её источник, время, потенциал, границы масштаба и наличие файлов. Ручная визуальная приёмка выбранных оригинальных изображений выполняется отдельно. Запуск этого сценария не создаёт нового Train/Test.

Предыдущий выпуск сравнения Fast7200/21600 с 32 PNG остаётся исходным отчётом своего снимка: его native views показывали края полного окна. Новый выпуск с вершинами должен получить отдельные source commit, job, внешние refs и квитанцию адресной проверки; прежние файлы и научные выводы не перезаписываются.
