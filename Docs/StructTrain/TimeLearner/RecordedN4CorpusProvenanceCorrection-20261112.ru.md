# Исправление provenance корпуса recorded N4

Независимый reader выявил ошибку manifest: Root corpus `Reports/StructTrain/TimeLearner/RecordedN4RoundtripPrimary-M40-20261112` содержит правильные native2 модели/summary/response/JUnit/input данные и посторонний controller от SDK36. [Отказ A1](ValidationPlans/M40RecordedN4RoundtripIndependent4A1-20261112/RESULT.ru.md). Исходный вывод о полной согласованности этого189-member corpus отозван. Его compressed primary не удаляется и не дублируется новым тяжёлым архивом.

Actual native2 acceptance остаётся отдельным подтверждённым результатом: [собственные original proofs](ValidationPlans/M40RecordedN4NativeRoundtrip2A3-20261112/RESULT.ru.md) содержат правильные outer/child bindings и closed/released исход. В новом independent readback эти файлы должны быть отдельным явно заданным, зафиксированным Git fixture; посторонний controller должен обязательно отвергаться.

Production join `recorded_roundtrip_evidence.audit_roundtrip_controller` проверяет вид и job ID запроса, точный набор двух cases, JUnit, исходные абсолютные child directories и child binding каждого native leaf, outer binding/closure, released lease и неизменность source/data. Число закрытых групп само по себе недостаточно. Это DATA replay, без заявления о новом native execution.

Предотвращение ошибки при сборе: `closed_primary_bundle` поддерживает schema2 с обязательным `controller_join` вида `recorded-n4-roundtrip`, `native_prefix`, `controller_prefix`, `original_job_path`. Original job path должен совпадать с физическим native root; оба prefix должны явно присутствовать и различаться. Семантическая проверка выполняется до создания архива и после его записи, вместе с прежним полным byte inventory и kernel closure. Неизвестный вид join/лишние поля/подмена root отвергаются. Schema1 сохранена для исторических byte/closure-only manifests и не получает семантических гарантий задним числом. Адресные проверки сборщика и реальных двух child bindings объявлены в `ValidationPlans/M40ControllerJoin11A1-20261112`.

До успешного полного повторного readback исправление считается реализованным в коде, но не принятым runtime. Проверка исходных и экспортированных пакетов и temporal gallery также должны завершиться. Критерии обучения и физика не менялись; stopped outcomes invalid_observation/budget_exhausted сохраняются.
