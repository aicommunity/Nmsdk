# Production сравнение cold Stock/PSI и масштаб отклика

Команда python -m Scripts.StructTrain.TimeLearner.presynaptic_training_report STOCK_NATIVE PSI_NATIVE OUTPUT анализирует закрытые native Train через production audit_run_manifest, сравнивает полные effective initial graphs и неизменность остальной configuration/runtime. Разрешены только штатные Stock/PSI2.5 образы и производные reference-relative guards; фактическое окно каждой поисковой пробы обязано оставаться [0,3600]. Каждый guard проверяется по собственному заново захваченному reference seed. Исходный PSI A1 setup failure не является treatment этой пары.

Сохраняются все scalar candidates, references, rejection history, actual/accepted параметры, resistance domains и полнота групп. В галерею входят anchor reference, лучший действительно измеренный кандидат каждого входа, все rejected groups и последняя записанная группа. Ранг выбора графика — timing flag, amplitude flag, сумма нормированных остатков, первый tie; это не replay controller edit-cost ranking. Отсутствующая measurement не заменяется максимумом пачки.

Renderer composite_training_temporal получил opt-in --native-response-zooms. Он выбирает первую фактическую full-subset пробу по source_ordinals, находит её записанный глобальный максимум только для выбора оси и показывает ±50 native frames с теми же координатами для всех omission controls. Это диагностический масштаб, не новый assigned peak и не measurement learner. Источник максимума/time/value/hash отражён в figure metadata; исходный selection/outcome не меняются. Обычные --native-window-zooms сохраняют прежний смысл границ окна. По умолчанию новый масштаб выключен; прежние численные/графические данные не переписываются.

Новый report всегда включает overview, обе границы окна и response-maximum detail, без прореживания; минимум8px/native tick. Это устраняет ограничение старых full-window графиков, чьи увеличения показывали преимущественно тишину у границ0/1.8с. Навигационные index.html теперь создаются и в каждом каталоге composite renderer, чтобы родительский отчёт ссылался на существующую галерею. Исторические архивы сохраняются неизменными.

Адресная приёмка — production comparator на фактических Stock A1/PSI A2 данных, проверки полного отрицательного исхода и истории, фактических размеров PNG и источника читаемого масштаба. Её тест не управляет построением отчёта собственной копией алгоритма: он вызывает production compare. На момент постановки новая проверка ещё не выполнена. Тяжёлые PNG/SVG/PDF и primary остаются во внешнем M40 архиве; Git содержит код, этот контракт и компактную квитанцию.
