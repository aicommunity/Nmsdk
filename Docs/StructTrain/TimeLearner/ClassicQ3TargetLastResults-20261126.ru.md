## 3 Проверка и ограничения

Независимо восстановлены77 первичных членов и48 членов галереи.
Проверены модель, реальные времена входов, полнота окон, метрики и
соответствие восьми источников рисунков первичным наблюдениям. Просмотрены
все16 PNG: полный диапазон и положительный масштаб каждой пробы.

Для шести проб с одинаковой длительностью окна производственный
сравниватель подтвердил полное совпадение сигналов с прежним порядком:
максимальная разность0; входные и выходные события сохранены.
У прежней первой и последней проб длительности окон отличаются из-за
завершающего тихого участка. Эти окна не обрезались для сравнения,
полное совпадение их сигналов не утверждается. Классификация по sample ID
осталась прежней, включая оба FP.

Цель обнаружена и в последней позиции при данной политике сброса.
Сброс перед каждой пробой ограничивает вывод о влиянии предыстории;
парная проверка с сохранением динамики приведена ниже. Одно переставление
не доказывает устойчивость ко всем порядкам, интервалам или моделям.
Это повтор одной обученной модели, не независимое обучение.

## 4 Парная проверка сброса и следующая позиция цели

Для long-r1-preserve независимо восстановлены77 членов первичного архива.
Цель осталась в позиции7, порог и модель не менялись. Перед первой пробой
динамика сброшена; между следующими семью предъявлениями она сохранялась.
Получены прежние TP=1, FP=2, FN=0, TN=5, с теми же классификациями по ID
паттерна. Все окна полны, завершающий тихий участок сохранён.

Сравнение со случаем long-r1-reset охватывает все8 полных временных окон.
Первая проба при одинаковом сбросе совпала точно. В следующих семи
максимальная разность сигналов составила от5,3513·10⁻¹⁴ до5,3735·10⁻¹⁴
при допуске сравнения10⁻¹²; входные и выходные события совпали. Это
численная близость откликов при явно изменённом условии сброса, а не
тождество условий и не побитовое совпадение. Производственный сравниватель
сохраняет исходные политики сброса и отдельно указывает вмешательство;
флаг сохранения отклика при одинаковых условиях для этих7 пар остаётся false.
При большой паузе практически полное затухание предыстории согласуется
с наблюдением, но само это сравнение не доказывает ненужность сброса
при короткой паузе или другой модели.

Для long-r2-reset цель перемещена в позицию6. Независимо восстановлены
ещё77 членов первичного архива; получены TP=1, FP=2, FN=0, TN=5.
Шесть полных окон одинаковой длительности совпали с исходным порядком
с максимальной разностью0; два окна другой длительности не обрезались
