# Восстановление первичных данных на Windows

## Исправление распаковщика

Независимое восстановление полного предыдущего Classic-опыта на TimLenovo
сначала остановилось в `path.open("xb")`: путь к журналу имел264 символа.
Корень восстановления был короче240 символов, но вложенный файл выходил
за предел обычного Windows-пути. До распаковки архив и индекс прошли SHA256.

`external_archive._native_path` получил режим `long_descendants`.
Распаковщики `portable_primary` и `source_envelope_bundle` применяют его к
корню дерева до добавления дочерних имён. Для пакета с восстановлением
описаний package и выход приводятся к одному пространству путей; запрет
вложения выхода в пакет и наоборот сохраняется. Состав архива, байты,
контрольные суммы и политика регулярных копий glog aliases не меняются.

Адресные проверки передают обычный короткий выход и длинные логические имена.
Охвачены обе версии обычного архива, независимые копии повторяемых данных,
восстановление описания по исходному документу, буквальный резервный вариант
и отказ при вложенном выходе. Сетевой UNC-ввод/вывод здесь не проверялся.

## Исправление окружения fixture

Первый общий набор дал13 успешных случаев и ошибку до создания временного
Git-репозитория. Диагностический повтор установил причину:
`missing config value GIT_CONFIG_VALUE_0`. После `patch.dict('os.environ', ...)`
восстановление всего словаря теряло унаследованное пустое значение в нативном
окружении Windows; счётчик Git оставался. Fixture теперь меняет и возвращает
только собственную переменную корня архива. Производственный resolver
истории не менялся. Итог: **14/14, без ошибок, отказов и пропусков**.
Предыдущие отказы сохранены. Подтверждение изменения на POSIX ещё требуется.

Это проверки архивного ввода/вывода и данных. Численные расчёты модели
и её интеграционные проверки здесь не выполнялись.

## Полный предыдущий опыт восстановлен

Штатный распаковщик восстановил все5129 членов пакета
`classic-measured-count-m4-elder-k1` и его распознавания. Проверены
12 970 896 542 развёрнутых байта, точное множество файлов,11 разделов,
496 финальных пар `train_stopped_trial_<i>.json/.csv` и16 полных наблюдений
по4001 отсчёту штатным диагностическим reader. Временные имена raw-trial
не требовались. Развёрнутое дерево удалено после проверки.

Архив125 624 684байта получен из хранилища M40 через jump host.
SHA256 до и после восстановления:
`615cf8153358500a0646bc8ddbecbd91097ed32d7a76e478167a5a0298194ad0`.
В Git сохранены код и малые текстовые доказательства.

Исходные `budget_exhausted` и TP1/FP1/FN0/TN6 сохраняются.
Восстановление не создаёт новый научный результат или сертификат Exact.
Общая приёмка этапа2 остаётся шире этого пакета.
