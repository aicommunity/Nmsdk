У цели и обоих отвечающих отвлекающих паттернов спайки находятся после

доказывает, что модель использует все четыре импульса: для этого нужны
отдельные причинные контроли. Подобные контроли другой модели Classic
не переносятся на данный граф автоматически.

В исходном silent-прогоне максимум LT-потенциала цели был через 493,5 мс.
При выбранном пороге фактический спайк зарегистрирован через 481,5 мс.
Test рассматривает весь отклик; время порогового события не обязано
совпадать со временем глобального максимума. После спайка обратное
влияние на физическую динамику дополнительно ограничивает использование
одной кривой для предсказания результата при других порогах. Здесь
реакции нового порога получены настоящим расчётом.

## Выводы в пределах проверки

Модель обнаруживает цель и отклоняет пять из семи отвлекающих паттернов.
По исходной восьмёрке это не улучшение относительно ранее полученной
модели Classic с одним FP. Сравнение не выделяет причинный эффект
предела 8→24: отличаются фактически измеренная история, конечный граф,
исполнитель и остановка по wall-time.

Исход `budget_exhausted`, отсутствие свежей финальной solo-проверки и
непопадание измеренных амплитуд в допуск сохраняются. Научное качество
Test и факт сходимости обучения — разные результаты.
