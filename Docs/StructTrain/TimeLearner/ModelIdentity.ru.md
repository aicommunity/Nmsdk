# Идентичность фактической модели

`App/NeuroModelerConsole/ModelIdentity` — общий read-only контроль для этапа 5.
Это ещё не полный model export/import и не сертификат обучения. API
`IdentifyModel(model)` возвращает `semantic_model_identity`, schema_version=1.
Ошибки чтения, неполный граф или неподдерживаемое представление запрещают SHA256.

Идентичность содержит для каждого именованного узла:

- относительный путь от `$`, storage-класс и частоту;
- все параметры, включая individual Rs/C, кинетику, PSI, averaging, threshold,
  физические и структурные режимы; bound-параметр представлен связью;
- полный порядок детей штатного scheduler;
- действительные слоты property bindings, их источники и способ подключения;
- property aliases и разрешённые cached pointers мембран, каналов, LT и источников.

Имя и Id корня, Name/Id узлов как идентификаторы storage, Coord,
DebugSysEventsMask и CalculationDurationThreshold исключены. Имена дочерних
компонентов остаются частью топологии. MaxCalculationDuration включён: этот
бюджет может пропускать вычисление детей. Activity также включён.

Текущие потенциалы, секреция, edge detectors, выходы и счётчики не определяют
идентичность обученной модели. В частности, NPulseChannel::TimeConstant меняется
во время расчёта вместе с проводимостями и не является неизменяемым параметром
модели. Перенос такой динамики потребовал бы отдельного checkpoint.

Поддержаны bool, строка и пара строк (включая штатный AverageInput),
signed/unsigned integer, IEEE754 double, векторы double/int/string и MDMatrix
double/int. Неоднозначное преобразование невалидной UTF8 строки запрещено.
Значения double хранятся как 16 hex-цифр
IEEE754 binary64, `-0` канонизируется в `+0`; NaN/Inf запрещены. Integer хранится
десятичной строкой без потери uint64 через JSON double. Вектора сохраняют порядок,
матрицы — обе размерности и значения, в том числе для пустых размерностей.
RTTI/typeid имена и адреса памяти в fingerprint не попадают. Проверяются также
полнота и отсутствие дубликатов индексов мембран и каналов относительно детей.

SHA256 считается от канонического length-framed UTF8 представления. Оно кодирует
тип каждого JSON значения, число элементов, упорядоченные ключи и точные байты
строк. Поэтому форматирование JSON и различия печати чисел Qt5/Qt6 не должны
менять fingerprint. Результат сохраняет также саму сравниваемую модель;
одного hash без описания недостаточно для разбора расхождения.

`VerifyModelIdentity(expected, model)` сначала проверяет schema/kind/encoding,
валидность и полноту обязательных полей ожидаемого описания, затем повторно
вычисляет его hash. После этого независимо снимается actual identity. Результат
разделяет `valid` и `match`: валидная иная модель даёт model_mismatch с первым
отличающимся путём; повреждённый hash даёт expected_digest_mismatch, а
неподдерживаемая схема — invalid_expected_identity. Подстановка hash от другой
структуры не заменяет проверку данных. Native XML regression использует этот
production verifier после штатного Load/Init, а не тестовую копию алгоритма.

Узлы должны пройти native Init/Build до вызова. Сам IdentifyModel не вызывает
Build/Init/Reset/Calculate. Unknown parameter type, отсутствующий или внешний
источник связи, неготовый компонент и исключённое credential-свойство дают
диагностику и `valid=false`, без hash. Credential-значения не записываются.
`valid=true` означает полноту поддерживаемого описания, а не доказательство
численной устойчивости, сходимости или распознавания.

Console предоставляет отдельный режим:

```text
NeuroModelerConsole --app-ini <runtime.ini> --config <Project.ini> --model-identity <new-file.json>
```

Как и `--inspect-model`, режим открывает проект и выполняет штатный ModelInit,
затем снимает read-only описание без расчёта. Он несовместим с запуском расчёта,
сохранением проекта и другим inspection mode. Каждый канал имеет собственный
fingerprint; положительный итог требует валидности всех каналов. Существующий
выходной файл не перезаписывается. Пустое описание вместо неподдерживаемого
параметра не допускается.

Граница модели пока должна быть замкнутой. Необъявленный внешний stimulus
binding не отбрасывается ради получения hash. Для model export отдельного
нейрона предстоит ввести и проверить явные входные порты и ProbeSpec, передать
storage definitions, training targets/references, calibration provenance и
solo/recognition conversion state. Code/runtime fingerprints и scorer version
остаются отдельными составляющими RunManifest/ConditionSpec; этот hash не
утверждает идентичность разных реализаций одного storage-класса.

При первом native XML контроле выявлено расхождение индекса Membranes:
fresh build сохранял порядок создания, Load — порядок добавления из сохранённой
таблицы детей. PulseLib теперь завершает Build синхронизацией этого индекса с
таблицей детей. Порядок расчёта детей не меняется. Контроль сохраняет порядок
индексов и связей в identity; расхождение не замаскировано удалением этих полей.
Научное A/B и полная проверка всех старых моделей остаются отдельными этапами.

Серверная приёмка и границы завершённого подэтапа отражаются в
ImplementationStatus и Reports/StructTrain/TimeLearner. До такой приёмки новый
fingerprint нельзя использовать как основание для публикации результата Train.
