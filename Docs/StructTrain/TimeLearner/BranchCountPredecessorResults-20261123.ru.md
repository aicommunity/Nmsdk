# Branch: влияние предшествующего паттерна на распознавание

23 ноября2026. Завершены14 условий и28 наблюдений одной замороженной
модели: семь исходных отвлекающих паттернов по очереди предшествуют цели,
каждая пара проверена со сбросом динамики перед целью и без него.

## Основной результат

Цель обнаружена во всех14 условиях. Классы ответов при двух политиках
совпадают: два исходных отвлекающих паттерна дают ложный выход, пять
отклоняются. Однако после паттернов №5 и №7 без сброса цель даёт
**дополнительный выход до своего четвёртого импульса**. При сбросе
остаётся один выход после четвёртого импульса. Следовательно, одинаковые
TP/FP/FN/TN не означают одинаковой временной работы распознавателя.

Полная матрица принята как valid. Семь сравнений первого отвлекающего
отклика между парными условиями и шесть сравнений целевого отклика
со сбросом между разными предшественниками прошли: максимальная разность
всех отсчётов сигнала0, входные и выходные события совпали. Тем самым
контроль подтверждает воспроизводимость сброса в этой модели и протоколе.
Различие двух preserve-реакций возникает при изменении политики сохранения
предшествующей физической динамики. Конкретный канал, ёмкость или механизм
низкопороговой зоны отдельным вмешательством ещё не выделен.

## Все парные ответы

Каждая строка — две отдельные последовательности «отвлекающий → цель».
Номер соответствует `phasea-row-N` исходной матрицы; цель `phasea-row-0`.
Время — абсолютное модельное время отдельного процесса, в секундах.
Первый паттерн всегда начинается со штатного сброса.

В каждом reset/preserve наборе из7 последовательностей имеются7 предъявлений
одной цели,2 FP и5 TN по отвлекающим, без пропусков цели. Это не семь разных

TP1/TN1 при разном числе и времени целевых событий. Базовый критерий
считает попаданием выход в объявленном окне ответа; преждевременность
отмечена отдельно и не скрывается за этим положительным классом.
