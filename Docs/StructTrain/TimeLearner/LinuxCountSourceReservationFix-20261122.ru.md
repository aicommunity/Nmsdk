# Резервирование общего дерева контроллера и SDK

В задании Elder `classic-measured-count-m4-elder-i2` подготовка и начальные
контроли прошли, но сам новый Train не начался. Внешняя группа закрылась
с кодом1 до создания дочерних расчётов. Стек исключения указывает на
`Reservations.reserve → _resources → duplicate_reservation_resource`.
Контроллер перечислил один каталог дважды: как собственный SOURCE и SDK.
Это допустимая постановка, но недопустимый список ресурсов реестра.

В `linux_count_training._reservation_resources` одинаковые канонические
пути с одинаковым доступом объединяются перед резервированием. Попытка
совместить чтение исходников с записью результатов по тому же пути
завершается специализированной ошибкой. Реестр не меняется: его общая
проверка повторяющихся ресурсов по-прежнему обязательна.

Две проверки используют производственный построитель списка и реальный
парсер реестра: общий SOURCE/SDK с сохранением отдельных write-каталогов;
конфликт output/source. Дополнительно повторный ресурс передаётся самому
парсеру и должен быть отклонён. Запуск этих проверок выполняется на сервере;
локально проверен только синтаксис. До получения серверной квитанции
исправление не объявляется runtime-проверенным.

Исходный отказ и закрытие группы сохранены в
`Reports/StructTrain/TimeLearner/MeasuredCountM4-20261122/elder-Train-before-native-failure.json`.
Повтор разрешён только как новый job и после подтверждения отсутствия
живых процессов прежнего задания. SDK, физика, исходная модель, критерии
и бюджет поиска остаются прежними; меняется только код запуска.

Серверная проверка завершена на Elder:2/2, без пропусков и ошибок.
Новое задание `classic-measured-count-m4-elder-k1` прошло обе
производственные начальные проверки (44/45 узлов, фактор Nₛ=2), после чего
подтверждён реально работающий нативный Train, PID2617049.
Контроллер83f1369f и SDK e1c97ac2 размещены раздельно; исходный SDK не менялся.
Квитанция: `Reports/StructTrain/TimeLearner/MeasuredCountM4-20261122/elder-resource-fix-tested-and-native-Train-started.json`.
Принято только адресное исправление списка ресурсов; этап10 и полный
контроллер этим не объявляются завершёнными.
