Процесс работал 21793.547 с. Итоговые state, scalar summary и execution marker отсутствуют. ## Конкретная техническая проблема и следующая работа

1. `uniform_profile_study.run` фиксирует для native leaf 4 GiB; 8 GiB внешнего Python-controller не увеличивают лимит отдельного native-процесса. Прежние сообщения про «8 GiB задания» нельзя интерпретировать как объём памяти native Train. Лимит надо задавать явно, сохранять в attempt manifest и согласовывать с резервированием всех процессов.
2. Рост встроенной истории измерений увеличивает стоимость экспорта. Требуется адресная проверка пика памяти сохранения на репрезентативном большом состоянии. Изменение лимита само по себе не доказывает устранение причины роста памяти. До такой проверки этот шестичасовой Train не повторять.
3. Следует обеспечить сохранение физической модели и допустимого controller checkpoint на завершённых границах, отдельно от тяжёлой первичной истории. Не использовать Copy/Alloc как checkpoint, не обещать восстановление посреди пробы и не терять связь с архивом измерений.
4. После проверки сохранения повторить объявленный cold-протокол; только по реальному итоговому состоянию выполнять Train→Test. Шаблонный Test и Test по предполагаемым конечным параметрам запрещены.

Ранее принятый результат другой сохранённой модели — TP1/FP1/FN0/TN6 на исходной матрице — остаётся в силе. Текущая серия перестановок Elder относится к ней и независима от этой аварии. Исходный план остаётся активным и частично выполненным; научные8/8 не требуются для его завершения.
