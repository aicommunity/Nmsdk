ClassicFullDomainN4Roundtrip на SDK448b153f2/Pulse7b524b8 принят actual native1/1 внутри продолжающегося DATA A3. Это перенос сохранённой stopped модели, не cold Train. Семантический package digest до/после9978cb946bfb0e22be6ace6de7bab207fb23d6955793e183178da5e040b6e17b одинаков; raw serialized digest может отличаться из-за допустимого представления image definitions. В phase-times.json измерены отдельные интервалы: read/decompress/parse1.665s; first import69.775s; export107.307s; summary102.916s; second import69.529s. Четыре stimulus edges, maximum Soma excursion0.0158285724; training outcome остаётся invalid_observation, certificate не появился. Это отдельные интервалы, а не полное разбиение времени test process. Нельзя приписывать весь оставшийся wall time экспорту или интерпретировать его как длительность холодного обучения.

При source review обнаружено различие test harness и штатного training path. RecoveryBoundaryResponse в Tests/Integration/Libraries/Test_PulseLib_CompositeTraining.cpp использует f.Revision для readModelRevision и readFullModelRevision; f.Revision выполняет полный IdentifyModel. NativeProbeExecutor::AfterCalculate вызывает readModelRevision для каждого sample. В production NativeCompositeTrainingAttempt этот callback использует ModelRevisionObserver::Read; полный IdentifyModel остаётся отдельным readFullModelRevision на границах. Observer проверяет фактические typed parameters, связи/порядок/частоту/lifecycle и обновляет digest при изменении, а не доверяет одному own-edit счётчику.

Следовательно, wall времени fixture нельзя непосредственно использовать как production throughput. Доля затрат на full hash не измерена: gdb attachment из отдельного процесса недоступен из-за ограничения ОС, параметры ОС не менялись. Это объяснимая по коду гипотеза о лишней работе harness, не доказанный профиль всех пропущенных интервалов.

Следующая адресная правка после завершения исходного A3: применять в RecoveryBoundaryResponse штатный ModelRevisionObserver для sample callback, сохранив полный readFullModelRevision на границах; добавить раздельные timings model-view comparison, waveform-before/after, serialization/compression/write и total, счётчики FullReads/CacheHits. Никаких изменений критериев, physical ticks, reset policy, частоты, input burst или допусков сравнения. A/B — прежний slow fixture против нового callback на том же полном source package и Pulse commit, совпадение всех stimulus/Soma samples, model revision и ledger; новые timings не заменяют старые файлы. Все затронутые36 controls и оба больших cases повторить на fresh SDK. Это отдельная test-harness приёмка.

Для утверждения production export speedup всё ещё нужен separate before/after binary experiment: baseline Pulse1110808 против optimized7b524b8, одинаковый полный model input и importer/exporter protocol, точные build/runtime closures и явные per-phase intervals. Same-new-binary old wrapper/new helper equality подтверждает совместимость результатов API, но не скорость старого кода. До такого сравнения performance improvement остаётся ограниченным code-level фактом удаления лишних decode, без заявленного численного коэффициента.
