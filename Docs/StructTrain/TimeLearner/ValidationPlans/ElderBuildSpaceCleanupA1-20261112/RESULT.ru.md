# Освобождение места Elder перед независимой сборкой

Удалены только3035 ELF object-cache файлов шести явно перечисленных старых CMake builds и22 копии старых логов, для которых подтверждено полное побайтное совпадение с сохраняемыми файлами. Всего3057 файлов; allocated planned1283821568 bytes. Free before1950846976, after3231657984 bytes. Исходники, Git, модели, executable/runtime и единственные экземпляры результатов не удалялись.

Получена whole-root write reservation при отсутствии held leases. Перед удалением проверено отсутствие активных builders/native-процессов и открытых файлов через fuser; identity/SHA проверены повторно для каждого файла, hash keeper повторно проверен перед удалением его дубликата. Сохранены [план с полными путями/хешами и identity](raw/plan.json), [журнал](raw/journal.jsonl), [результат](raw/result.json) и [контрольные суммы исходных байтов](raw/readback-integrity.json). Identity timestamps сохранены исходными байтами, без JS пересериализации.

Это обслуживание диска, не приёмка алгоритмов или научный результат. Свободное место остаётся ограниченным: новая сборка обязана соблюдать прежний physical floor2GiB; тяжёлые серии на Elder пока не запускаются.
