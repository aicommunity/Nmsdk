# Проверка Build после импорта и сохранности модели

Исходники корня bdefc5402253178b2603adcfdce6290283837089 и PulseLib
1110808f4ad1f67538dadc6fe1d3f097e00c0630 доставляются через Git в отдельное дерево.
Сборка и runtime создаются заново на M40 и не изменяют предыдущие попытки.

Набор включает прежние 14 реальных проверок экспорта, импорта, параметров и
отклика Classic/Branch, N0/N1, а также четыре проверки того, что Build при
активном обучении protocol4/5 по-прежнему прерывает управление. При импорте
завершённой модели Build должен сохранить detached Finished boundary.
Явный Reset должен сбрасывать управление, не выдавая сертификат сходимости.

Все 18 cases запускаются отдельно с полным собственным окном и артефактами.
Условия и математические допуски не ослабляются. Этот набор не подтверждает
научную классификацию и не заменяет всю обязательную матрицу. До фактического
завершения compiler/runtime приёмка отсутствует.
