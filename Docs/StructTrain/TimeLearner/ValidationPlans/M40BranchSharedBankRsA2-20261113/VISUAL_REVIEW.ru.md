# Просмотр Branch Rs: три рисунка

Просмотрены исходные full.png, frames-0-900.png и frames-800-1700.png (3200×1400) по отдельности. Амплитудный диапазон одинаков между всеми видами, время относительно начала реальной пробы. Полный вид показывает все4 входных импульса и весь response/rest tail. Увеличения содержат901 исходный отсчёт с точками, без downsampling. Вход нанесён вертикальными линиями на waveform и отдельной actual-input панелью.

Вмешательство заметно усилило все три различимые вершины; отдельная ранняя четвёртая вершина не появилась. Два поздних максимума в области0.5–0.8s сохраняются. Наличие этих вершин и визуально близкого времени не является новым assigned-peak certificate: omission-controls для изменённой Rs-модели не выполнялись. Numeric timing/amplitude train residuals и классификация8 patterns этим экспериментом не измерены.

Overview пригоден для формы; enlargements для visual sample-level shape, но точное соответствие допускам определяется численно. Единицы модели сохранены, SI/mV не утверждаются. Visual acceptance относится только к этим3 selected originals; full cache воспроизводим на M40.
