# Остановленное обучение: отдельное диагностическое состояние

Статус реализации: рабочая ветка `stage05/stopped-training-state`. Последняя проверенная версия root `57b365929f9e0ee9e10a7520fea78cd3d9fa415d`, PulseLib `12c5ef5f7e6e2ebda26cede86ad9005743899086` прошла 20/20 native cases и 10/10 Python tests на Elder-1 и M40 ASan (detect_leaks=0). Все 20 cases на каждом worker проверили fresh-process import и frozen CSV. Полные maintained suites ещё выполняются на предшествующем source snapshot. Это продолжение этапа 5, а не завершение всего этапа или плана.

Сертифицированный `timelearner_completed_state` остаётся прежней схемой. Новый `timelearner_stopped_state` версии 1 сохраняет фактическую физическую модель, storage-определения и Dataset через тот же native archive/import-путь, но имеет `state_kind=diagnostic` и `certificate=null`. Допустимы только terminal outcomes `external_stop`, `budget_exhausted`, `invalid_model`, `invalid_observation`, `search_unresolved`. Ни экспорт, ни импорт не превращают их в Exact.

Пакет дополнительно содержит причину остановки, исходные revision/epoch захвата, признак полноты references и фактические результаты попыток проб, включая отменённые и неполные наблюдения. Валидный префикс принятых references заново проверяется производственным валидатором; неполный префикс не становится полной амплитудной целью. Численно повреждённый или неописанный физический граф по-прежнему запрещён к переносу: диагностический статус не ослабляет проверку модели.

Это снимок модели на остановленной границе, не checkpoint динамики интегратора. После импорта управление выключено. Новая warm-попытка имеет новый номер, свежие пробы и финальную проверку. Полностью захваченная цель сохраняется. Незавершённый захват разрешено начать заново только на исходной физической модели и epoch; после изменения модели требуется явный cold restart/retarget. Reset сам по себе не разрешает незаметно заменить исходную цель.

Проверки в production storage/Environment fixtures для Classic и Branch: остановка ранней пробы; остановка после одного reference; исчерпание model-time до reference; исчерпание search budget; остановка после реального изменения структуры; остановка незавершённого final sweep; ошибка подготовленной пробы; изменение физики во время неполного capture. Для каждой проверяются null certificate, модель и параметры после import, сохранность наблюдений, отклонение повторно подписанных ложных claims, одинаковый frozen импульсный отклик и ограничения warm restart. В исходных 16 cases используется N1, 2000 Гц; это не вся физическая матрица.

В корневом пакете добавлен `stopped_evidence.py`: отдельный анализатор диагностических пакетов по первичным JSON/CSV, с mutation-проверками. Последняя версия на каждом worker проверила 66 actual primary trials, включая шесть invalid/censored. Дубликаты trial ID и final packet без соответствующего observed packet запрещены native import. Добавлены N0 budget-search и configured V2 partial-capture controls обоих learner, а также повторный stopped export после warm attempt и отказа замены незавершённой цели.

Git evidence: [M40 A1–A3 и reverse transfer](../../../Reports/StructTrain/TimeLearner/s05-stopped-m40/README.md), commit `32142f5959a1e0aa7749576d5fca44d444a8d44c`; [Elder-1 A1/A2 и регрессии](../../../Reports/StructTrain/TimeLearner/s05-stopped-elder1/README.md), commit `e53f277f1c05468802dedcd695d1d139ac8b91ec`. Локально проверены 943 + 1374 stored hashes и 941 + 1372 raw gzip payloads. Первичный Python-аудит M40 выполнялся отдельными командами из immutable tested-source worktrees: combined ASan launcher завершался после native phase, поэтому его нельзя считать выполнением Python-проверок. Отдельные завершённые Python-запуски сохранены в обоих пакетах.

Через Git выполнен перенос 16 M40 ASan A2 пакетов в Elder-1 и 20 Elder-1 A2 пакетов в M40 ASan. В каждом новом процессе совпали model hash и все байты frozen CSV. На последней версии Elder-1 дополнительно прошли 22/22 native service/cold/completed-state regressions и 9/9 certified-evidence Python tests по пяти завершённым пакетам и 62 primary trials. Это scoped regression, а не полная физическая или научная матрица.

Первая ASan-попытка A1 на root `659ec066db6ac279ae97d118e778bb5b827bf6a4` прошла 2/16 cases. Остальные выявили ошибку новой защиты: InvalidateTarget оставлял старый plan, который снова превращался в ограничение неполного capture при следующем Reset. Исправление PulseLib `652c8f3` очищает plan, включая старые callbacks. Это регрессия новой ветки, а не доказательство исторической неработоспособности обучения.

Остаются за пределами этого подэтапа: transfer recognition/conversion/PostTune и калибровки, произвольный checkpoint посреди пробы, новый runner, независимая научная матрица. Существующий анализатор сертифицированных пакетов не следует применять к диагностическим пакетам как доказательство сходимости.

Формат не ослабляет запрет nonfinite чисел: если сама физическая модель или сериализуемое наблюдение содержит NaN/Inf, export отвергается, а не подменяет число нулём/null. Полный run-level diagnostic export таких аварий остаётся обязанностью будущего runner. Первичный Python-аудитор требует реальные исходные пробы; нулевая новая warm attempt с retained references проверяется native codec, но без исходных CSV прежнего capture не получает положительного provenance audit.
