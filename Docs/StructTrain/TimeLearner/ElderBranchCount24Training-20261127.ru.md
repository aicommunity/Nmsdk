# Обучение Branch на Elder с ограниченным поиском числа синапсов

## Постановка

Начат новый расчёт структурно-параметрической адаптации нейрона с общей
ветвью из исходной структуры и заданных параметров. Целевой поток содержит
M=4 импульса:0,80,240 и480 мс от первого импульса. Нормализация изменяет
число синапсов; сопротивления остаются86 МОм. Исходные длины и числа
синапсов равны1, опорный путь закреплён. Частота —2000 Гц.

Цель амплитудной настройки — собственная исходная амплитуда отклика
закреплённого импульса каждого пути, а не максимум всей пачки. Допуск
амплитуды —10⁻⁵, относительный допуск выключен, минимальная измеримая
амплитуда —10⁻⁶; временной допуск —0,02 с. Обход сохраняет обратный
порядок Branch. Ёмкость не подстраивается, PostTune и автоматическая
калибровка выключены. Во время обучения порог равен100.

Новый расчёт ограничивает локальный поиск24 кандидатами и выполняет
один проход. Разрешены160 логических проб,1280 изменений, длина до100
и число синапсов до128. Модельное время поиска ограничено7200 с,
время вычисления поиска на сервере —21600 с; для процесса и полного
управляющего задания выделены25200 и28800 с соответственно. Количество
файлов отдельных измерений не равно числу логических проб.

Это отдельная постановка с изменёнными ограничениями поиска. Исторические
расчёты с другим временем вычисления, числом кандидатов или проходов
не служат однофакторным сравнением эффективности этого изменения.

Причина остановки —`rejected_candidate_window:ambiguous`. После четырёх
разрешённых восстановлений пятое неоднозначное измерение остановило поиск.

У Branch эти L относятся к общей ветви; их нельзя суммировать как длины
четырёх независимых ветвей.

На диагностическом рисунке последней группы64 сопоставлены два полных
отклика, отклик при исключении закреплённого импульса80 мс и разность
записанных реакций. Входные импульсы наложены на полный отклик; весь
интервал1,8 с и хвост видны. Два полных отклика совпали во всех3601

разделяет её на две вершины. Разность кривых не объявляется отдельным
импульсным откликом; допустимость привязки вершины этим рисунком не
