# Очистка каталогов Nmsdk 2026-11-05

Удалены 74 локальных чистых worktree, два старых worktree на Elder и 11 пустых временных каталогов на серверах (Elder: 2; M40: 9). Это обслуживание рабочих копий, а не подтверждение этапов алгоритмической или научной приёмки.

## Локальная проверка и восстановление

Инвентаризация охватила 113 первоначально обнаруженных рабочих копий. Первая группа удаления: 66; дополнительная группа после проверки индивидуальной настройки `core.worktree`: 8. Для всех удалённых копий HEAD уже входил в принятый develop соответствующего репозитория. Проверены чистота индексированных и неиндексированных файлов, отсутствие уникальных игнорируемых файлов (разрешены только воспроизводимые Python-кэши), незавершённых Git-операций, вложенных данных сабмодулей и ссылок файловой системы. Материализованные файлы сопоставлены с Git blobs с учётом checkout-фильтров.

Удаление выполнено штатным `git worktree remove` без force. Ветки, коммиты и общие хранилища Git сохранены. До удаления для каждой копии создана ссылка `refs/archive/timelearner-cleanup-20261105/<имя>`. Итоговая проверка всех 74 путей подтвердила отсутствие каталога и точное совпадение сохранённой ссылки с прежним HEAD. Восстановление: найти запись в verification.json и выполнить `git --git-dir <common_git_dir> worktree add --detach <новый_путь> <head>`; для сабмодулей дополнительно проверить фактический корень новой рабочей копии.

Логический объём удалённых файлов: 1090489212 байт. Наблюдавшееся увеличение свободного места E: — 2 073 075 712 и 58 945 536 байт на двух интервалах. Это показания всего тома, включая распределение блоков и параллельные операции; точное физическое освобождение только этой очисткой из них не следует.

Машиночитаемый перечень, исходная инвентаризация, планы, результаты и SHA256SUMS: [локальные доказательства](../../../Reports/StructTrain/TimeLearner/s02-directory-cleanup-local-20261105/verification.json).

## Что сохранено и почему

- Исходная пользовательская копия nmsdk-git, текущая копия чата, принятые основные Git-хранилища и рабочие каталоги незавершённой интеграции.
- Незакоммиченные/необъединённые копии и worktree с изменёнными gitlinks. Возраст каталога не доказывает ненужность изменений.
- nmsdk.old и архивы прошлых лет: идентичность сохранённым данным не доказана.
- nmsdk-unused-libs: относительные .git-ссылки нарушены, при явном указании реального хранилища обнаружено изменённое состояние. Название каталога не основание для удаления.
- Каталоги с недоступными длинными путями или некорректными вложенными .git-ссылками: проверка не завершена, удаления не было.
- M40 source-build-object-cleanup-m40-proof-a1: предварительная проверка не прошла, каталог сохранён. Пользовательские /home/user/Nmsdk, /home/user/tl-agent/Nmsdk и необъединённые серверные worktree сохранены.

Уникальные первичные данные, модели и исторические научные наблюдения не удалялись. Изменение истории Git и удаление веток не выполнялись. Очистка не означает завершения полного рефакторинга TimeLearner.
