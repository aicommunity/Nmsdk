# Память при экспорте обученной модели

Исходный дефект подтверждён попыткой groupwall600: native процесс завершён
ядром oom-kill при лимите 4 ГиБ, до записи конечного package. Python-контроллер
имел отдельный лимит 8 ГиБ. Это разные kernel units; увеличение лимита одного
не увеличивает лимит другого. [Исходная попытка и сохранённые raw данные](FastN1GroupWall600OOM-20261116.ru.md).

Готовятся два адресных изменения. В PulseLib CanonicalModelDataSha256 подаёт
байты в SHA256 потоком, не удерживая полный канонический буфер. В uniform study
лимиты native памяти и tasks задаются явно; managed reservation учитывает их
вместе с kernel readback контроллера, а запись execution policy сохраняет
выбранные значения. Значения по умолчанию 4 ГиБ/64 сохранены для compatibility;
следующий научный запуск должен выбрать ресурсы явно после приёмки.

Локальный family registry не измеряет свободную память сервера и не заменяет
общий scheduler. Совокупный ресурс внешнего задания и его sibling native units
должен быть учтён до нового Train. Это ограничение нельзя скрывать увеличением
одного числа. Ошибка конфигурации либо переполнение суммы должны отказывать
до создания дорогой попытки.

Проверки: cross-language golden hashes; исходные identity/revision controls;
реальный package 317475838 байт; native full export/import и runtime readback.
Новый научный Train не запускать только на основании успешного unit hash.
Нужны достаточный ресурс, сохранение действительной конечной физической модели
и подтверждение полного export/import на репрезентативной истории. Удаление
primary, подмена модели шаблоном и присвоение сертификата неполной попытке
исключены. Текущая ветка ещё не является runtime-проверенным исправлением OOM.

Python-проверки ресурсов приняты 2/2. Первая C++ сборка a1 обнаружила
пропущенный вызов старого Canonical в VerifyModelIdentity; исправление включено
в PulseLib 9883f9493d0672e603dfb4a03dc572955469ccdf. Изолированная сборка a2
root 9b7fb0eac7107093d2fd87748b85c532c4f2ad9e выполняется отдельно; её
20 identity/export случаев до фактического исполнения не считаются PASS.

Отдельный большой hash-control передаёт TIMELEARNER_CANONICAL_PACKAGE через
штатный contained runner как явно названную fixture. Это не наследование всех
переменных окружения: остальные фильтры сохранены. Python проверяет bytes/SHA
исходного 317475838-байтного файла до и после, actual native request environment,
полный GTest ID без skip и закрытие kernel unit. Для fixture явно объявляется
предел 512 МиБ; общий лимит native-gate inputs не увеличивается. Native cap
остаётся 4 ГиБ. Эта проверка ещё ожидается и не заменяет полный export/import.
