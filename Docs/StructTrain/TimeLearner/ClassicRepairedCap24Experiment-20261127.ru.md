# Обучение Classic с пределом24 кандидата на путь

## Цель и условия

Новый расчёт проверяет, какой результат даёт увеличение локального числа
проверяемых кандидатов в исправленном циклическом обучении Classic.
Основой служит фактическое исходное задание текущего M40 cap8, а не
сохранённый обученный нейрон. Штатная функция`declare_candidate_limit`
меняет только идентификатор попытки и предел8→24 в математическом задании.

Один входной поток содержит M=4 импульса с временами0/80/240/480 мс.
Частота —2000 Гц, исходные длины и числа синапсов равны1, сопротивления —
86 МОм. Нормализация изменяет число синапсов, сопротивления закреплены;
опорный последний путь закреплён. Цель — собственная исходная амплитуда
закреплённого импульса каждого пути. Допуск амплитуды —10⁻⁵, относительный
выключен, временной допуск —0,02 с. Подстройка C, PostTune и автоматическая
калибровка выключены; порог обучения —100.

Сохраняются три кандидата на одно посещение пути, один проход,160 логических
проб,1280 изменений, максимальная длина256 и число синапсов128. Предел
модельного времени —10000 с, вычисления поиска —32400 с. Два дополнительных
тика предназначены для завершения исполнения и не увеличивают время поиска.
Объявленная ёмкость допускает154 поисковых измерения и четыре исходных
измерения при валидных наблюдениях; повторные восстановления могут потребовать
дополнительного времени. Это расчёт необходимой ёмкости, а не обещание
достижения допусков.
