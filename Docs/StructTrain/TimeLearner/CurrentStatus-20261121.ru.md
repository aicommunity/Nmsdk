файлы и не разрешила Test. Контроллер A1 полностью закрыт. Отдельная A2
использует порядок общего `recorded_diagnostic_matrix`: проверить исходный
пакет, материализовать сохранённые первичные данные под объявленными именами,
проверить внешнее зеркало, затем импортировать модель. Исходная попытка,
история и модель сохранены; обучение не повторяется.

Следующие действия после успешной загрузки: получить восемь полных наблюдений,
предложить порог по потенциалу решающего элемента, подтвердить его настоящим
повторным Test и построить читаемые временные графики сомы с фактическими
входными импульсами для каждого паттерна. Подбор на той же матрице явно
обозначается как таковой. Молчание при100 не является успешной детекцией;
критерий включения семейства в описание —TP≥1 иTN≥2. Новое обучение до
