# Влияние четвёртого импульса при сохранении динамики нейрона с общей ветвью

## 1 Задача и модель

Проверяется, зависит ли раннее выходное событие нейрона с общей ветвью
от времени последнего импульса паттерна. Используется ранее полученная
структура и набор параметров; обучение и порог не изменяются. В исходных
условиях нейрон обнаруживает цель и отклоняет шесть из семи отвлекающих
паттернов. [Разбор первой пары](BranchFourthPulseResults-20261126.ru.md)
содержит исходные условия и полную проверенную галерею реакций.

Паттерн содержит M=4 импульса. Первые три подаются через 0, 80 и 240 мс
от начала паттерна; исходный четвёртый — через 480 мс. До исследуемого
предъявления сохраняются пять одинаковых полных паттернов. На шестой
позиции изменяется только время четвёртого импульса; полученный паттерн
помечен как отвлекающий. Исходная цель предъявляется последней и служит
положительным контролем. Каждая последовательность содержит восемь
полных наблюдений и рассчитывается целиком на одном компьютере.

Сопоставляются сброс динамики перед каждой пробой и сброс только в начале
последовательности. Во втором случае состояние нейрона между паттернами
сохраняется. Все условия используют одну структуру и параметры нейрона
и один порог. Это проверка свойств сохранённой модели, а не независимые
повторения обучения.

## 2 Измерения и результаты

Завершены два исходных условия и 14 изменённых: семь времён последнего
импульса для каждого способа сброса. Сохранены и независимо проверены
все 128 полных наблюдений. Классификация использует полное окно реакции;
сравнение участков до четвёртого импульса не заменяет это окно.

Таблица 1 — Изменённые паттерны при двух способах сброса

| Четвёртый импульс от начала, мс | TP / FP / FN / TN со сбросом | TP / FP / FN / TN без сброса между пробами | Ранний выход опережает четвёртый импульс, мс |
|---:|---|---|---:|
| 280 | 1 / 1 / 0 / 6 | 1 / 2 / 0 / 5 | 38 |
| 320 | 1 / 1 / 0 / 6 | 1 / 2 / 0 / 5 | 78 |
| 360 | 1 / 1 / 0 / 6 | 1 / 2 / 0 / 5 | 118 |
| 400 | 1 / 1 / 0 / 6 | 1 / 2 / 0 / 5 | 158 |
| 440 | 1 / 1 / 0 / 6 | 1 / 2 / 0 / 5 | 198 |
| 520 | 1 / 1 / 0 / 6 | 1 / 2 / 0 / 5 | 278 |
| 560 | 1 / 1 / 0 / 6 | 1 / 2 / 0 / 5 | 318 |

Во всех семи условиях со сбросом изменённый паттерн не вызывает выходов
во всём окне. При сохранении динамики каждый из этих паттернов вызывает
один выход через 242 мс от первого входного импульса. Результат не зависит
от проверенного времени четвёртого импульса. Исходная цель, предъявленная
последней, во всех 14 изменённых условиях вызывает выход через 483,5 мс.
Прежнее ложное срабатывание на `phasea-row-4` сохраняется; дополнительное
FP без сброса относится к изменённому паттерну.

В двух исходных условиях с четвёртым импульсом 480 мс получены
1 TP, 1 FP, 0 FN и 6 TN. В исходной непрерывной последовательности
шестая проба является целевой; её ранний выход не увеличивает FP.
Именно замена последнего интервала и метки этой пробы позволяет выявить,
что ранний выход не подтверждает совпадение полного паттерна.

## 3 Сопоставимость и границы вывода

У каждой изменённой последовательности пять предшествующих полных реакций
совпали с соответствующим исходным условием. Затем сравнивались все
записанные сигналы, времена отсчётов, входные и выходные события и записанная
история детекторов строго до более раннего из двух четвёртых импульсов.
Во всех 14 сравнениях максимальные различия равны нулю при допуске
10⁻¹². На этом участке при сохранении динамики уже присутствует выход
через 242 мс. Метод не утверждает равенства незаписанных внутренних величин.
[Описание сравнения](FourthPulsePrefixAnalysis-20261126.ru.md).

Совместно эти измерения подтверждают ограничение данной модели:
после указанной предыстории она может сформировать выход до поступления
четвёртого импульса и поэтому принять все семь исследованных изменённых
паттернов. Сброс перед каждой пробой устраняет это дополнительное
срабатывание в проверенных условиях. Отсутствие эффекта времени последнего
импульса здесь не переносится на другие предыстории, структуры нейрона
или результаты другого обучения.

Полностью просмотрена галерея первых четырёх условий: два исходных
и два с четвёртым импульсом 280 мс. Для остальных 12 условий первичные
данные и независимый анализ приняты; подготовка и визуальная проверка
всех временных графиков ещё требуются. Включение общей серии в следующий
DOCX-выпуск также остаётся открытым. Этот результат не подтверждает
совместного выполнения всех допусков исходного обучения и не закрывает
всю матрицу этапа 11.
