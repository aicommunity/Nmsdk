# Читаемость положительных откликов при общем recovery-масштабе

В Elder baseline/threshold галерее просмотрены16 overview. Отрицательное
восстановление двух spiking-проб растягивает общий Y примерно до−1.45;
положительные отклики остальных проб визуально сжимаются. Старый companion
создавался только при наличии отрицательных отсчётов в самой пробе.

Общий renderer теперь передаёт фактический минимум канала по всей матрице.
Если он отрицателен, отдельный положительный вид создаётся для каждой пробы
с положительным откликом, включая nonspiking. Используется записанный минимум,
а не отрицательный отступ рамки графика. Входные импульсы, native time zoom,
полные отсчёты и ordinary full-range views сохраняются. Метрики не используют
новый масштаб, данные не обрезаются; display clipping и причина companion
записываются в manifest. То же правило применяется к LT decision views.

Изменены plotting.py, reports.py и lt_decision_reports.py. Проверки реального
archived native report и diagnostic threshold report требуют companion для
затронутых молчащих проб, сохранения maximum и читаемого диапазона; local AST
пройдена. Новая серверная генерация, визуальная приёмка и публикация ещё
требуются. Прежняя2391-PNG галерея остаётся исходной публикацией своего renderer,
её bytes не переписываются. Классификация Elder TP1/FP1/FN0/TN6 и heldout4
TP1/FP0/FN0/TN3 этим изменением не пересчитываются и не расширяются.
