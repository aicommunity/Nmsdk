# Диагностическое распознавание конечного состояния Branch Count24

## Модель и задача

Нейрон с общей ветвью обучался паттерну из M=4 импульсов:
0,80,240 и480 мс относительно первого импульса. Частота вычисления —
2000 Гц. В ходе настройки изменялись геометрия и числа синапсов;
сопротивления оставались86 МОм. Цель амплитудной настройки — собственный
исходный максимум закреплённого импульса каждого пути. Временной допуск
равен20 мс, амплитудный —10⁻⁵.

Обучение остановилось из-за неоднозначной привязки вершины и не получило
свежего результата заключительных измерений всех путей. В конечном
векторе API L=82/82/27/1, Ns=1/1/4/1. Эти L относятся к общей ветви,
а не к четырём независимым кабелям. [Полный разбор обучения](ElderBranchCount24Training-20261127.ru.md).

Проверяется именно это сохранённое состояние. Оно прошло штатный импорт,
полную проверку графа и явное преобразование identity с включением всех
точек приложения сигнала. Структура и параметры при предъявлениях
заморожены. Динамика сбрасывается перед каждым паттерном; каждое окно
наблюдения длится2 с и содержит4001 отсчёт.

## Условия оценки

Использованы исходная цель и семь исторических отвлекающих паттернов.
Порог подбирался на той же матрице — Historical Same-Matrix. Независимая
контрольная выборка этим опытом не создаётся. При Test используется
полная реакция, а не вершина закреплённого импульса из Train.

При исходном пороге100 во всех восьми окнах спайков нет:
TP0/FP0/FN1/TN7. Такая доля молчания не означает рабочую детекцию цели.
По полным неспайковым максимумам потенциала порогового элемента предложен
один порог: середина между максимумом цели0,03307997042784827 и ближайшим
строго меньшим максимумом отвлекающего паттерна0,03063698606011067.
Получено θ=0,03185847824397947 в единицах модели.

Пять отвлекающих паттернов имеют максимумы выше цели. Разность максимума
цели и наибольшего максимума отвлекающего паттерна равна
−0,009786725771153693. По этому неспайковому скалярному признаку полной
разделимости нет. Спайковые реакции проверены новым реальным прогоном
при предложенном пороге; offline-прогноз им не заменялся.

## Измеренный результат

| Порог | TP | FP | FN | TN |
|---|---:|---:|---:|---:|
|100|0|0|1|7|
|0,03185847824397947|1|5|0|2|

Во втором прогоне цель вызывает один спайк через252 мс после первого
импульса. Четвёртый импульс предъявляется через480 мс, на228 мс позже
ответа. Поэтому этот TP по критерию полного окна не подтверждает, что
нейрон распознал всю четырёхимпульсную последовательность. Для такой
интерпретации необходимо отдельно учитывать время решения относительно
последнего импульса и результаты вмешательств во входной паттерн.

Результат хуже ранее проверенных моделей с одним FP. Обучение остаётся
незавершённым, а распознавание — диагностическим. Числа TP1/TN2
сохраняются как фактические наблюдения; они не создают задним числом
результат завершённого обучения. Научные8/8 не являются требованием
рефакторинга, но ранний ответ и пять FP должны быть явно видны в отчёте.
