# Branch с измеренным поиском числа синапсов: новая сетка паттернов

## Завершённый результат и область вывода

При фиксированных модели и пороге получено **TP=1, FP=1, FN=0, TN=25**.
Все27 проб завершены и прошли production-аудит; реальные выходы определены
по событиям низкопороговой зоны. Цель не пропущена,25 из26 новых отвлекающих
паттернов правильно отклонены. Нового обучения и подбора порога не было.

На исходной восьмёрке эта же модель имеет TP1/FP2/FN0/TN5. Поэтому результат
на новой сетке не отменяет двух исходных ложных срабатываний и не означает
общего улучшения относительно прежнего поиска. На такой же сетке прежняя
модель с Nₛ=6/5/5/1 также имела TP1/FP1/FN0/TN25. Единственный ошибочный
паттерн совпал: **40;160;240мс**. Модели и пороги различаются; причинный
эффект только числа синапсов этим сопоставлением не установлен.

Обучение новой модели остановлено по бюджету. Исторический финальный проход
выполнен для всех4 входов, но3 амплитудных ошибки вне допуска. Сертификата
Exact для конечного восстановленного состояния нет. Хорошая классификация
в диагностическом Test его не создаёт. Пример удовлетворяет пользовательскому
критерию включения в научные описания: TP≥1 и TN≥2.

## Протокол

Три межимпульсных интервала цели80;160;240мс независимо умножались на
0,5;1;1,5. Получена полная сетка3×3×3:27 разных паттернов, включая прежнюю
цель один раз на позиции13 при индексации с0. Двадцать шесть остальных
отсутствовали в исходной калибровочной восьмёрке. Сетка уже исследовалась
на прежней модели: это новые паттерны относительно калибровки текущей модели,
а не слепая выборка из неизвестного распределения. Единственный положительный
паттерн повторяет обучающую цель; независимое обобщение положительного класса
не проверено. Это одна модель, не27 независимых обучений.

Перед каждой пробой сбрасывалась динамика. Наблюдалось полное окно2с,
4001 отсчёт на пробу. Порог0,0858575482028458 оставался неизменным. Целевой
отклик совпал с исходным DATA-контролем по всем4001 отсчёту: максимальная
разность сигналов0; различия относительных времён менее10⁻¹²с. Входные
и выходные события сохранены. Полная модель до и после проверена неизменной.

Фактический выход цели — через0,4815с после первого входа и1,5мс после
последнего. У ошибочного40;160;240мс — через0,4415с после первого входа,
также1,5мс после последнего. В прежней модели для того же ошибочного паттерна
было0,443с после первого. Ни в одной из27 проб нет отдельного раннего либо
позднего выходного события вне объявленного окна ответа.
