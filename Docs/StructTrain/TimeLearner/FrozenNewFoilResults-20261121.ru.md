## 4 Интерпретация и следующие проверки

Сохранённая модель подавляет25 из26 новых отрицательных примеров при
сохранённом ответе target. Одновременно подтверждено конкретное ограничение:
сокращение первого межимпульсного интервала с0.08 до0.04с при сохранении
следующих0.16 и0.24с всё ещё даёт ответ. Реакция на подпоследовательность
или частичное совпадение —рабочая гипотеза, требующая отдельного вмешательства;
одних обученных длин для такого вывода недостаточно.

Новая матрица не использована для изменения порога. Возможная последующая
настройка по ней будет отдельно маркироваться как Test-only tuning или
Same-Matrix исследование. Эти наблюдения не создают сертификата Exact,
не проверяют continuous stream, другой ITI или независимые случайные обучения.
Временные графики всех паттернов, включая FP, готовятся из тех же первичных
данных без прореживания; технический кэш требует визуальной приёмки перед
включением рисунков в очередную редакцию научных DOCX.
