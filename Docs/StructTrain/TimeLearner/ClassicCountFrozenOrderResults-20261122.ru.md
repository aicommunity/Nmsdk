# Порядок предъявлений для Classic с нормализацией числом синапсов

Зафиксированная модель Classic при M=4 сохранила обнаружение цели и состав
ошибок при всех восьми положениях целевого паттерна. Каждый блок из восьми
предъявлений дал TP=1, FP=1, FN=0, TN=6. Полные отклики и входные и выходные
события совпали с исходным блоком после совмещения по первому фактическому
импульсу; максимальная разность потенциалов равна нулю при допуске1e−12.

Это проверка порядка при **сбросе перед каждой пробой**. Непрерывный поток,
увеличение межпаттернового интервала и новые положительные примеры не
проверялись. Полная разделимость и сходимость обучения не утверждаются.

## Модель и протокол

Использовано состояние распознавания
`cbf49f5990229085ec8395a98b1c85418e2b6744b8e6bc1255ce8bf69de1bf7b`
с порогом0,020736298148054874 из ранее остановленного по бюджету обучения,
описанного в [отчёте о Classic](ClassicCountTrainingM40State-20261122.ru.md).
Новое обучение, выбор порога и замена физики не выполнялись.

Исходные восемь предъявлений служат блоком циклического сдвига0.
На M40 выполнены семь новых блоков со сдвигами1–7:56 полных наблюдений.
С учётом исходного блока цель предъявлена в каждой из восьми позиций.
Повторы не являются независимыми обучениями или новыми паттернами.

| Блок | TP | FP | FN | TN |
|---|---:|---:|---:|---:|
| Исходный, сдвиг0 |1|1|0|6|
| Каждый новый, сдвиги1–7 |1|1|0|6|
| Сумма новых56 предъявлений |7|7|0|42|

Проверены фактический граф и порог, точное множество проб, полные
production-манифесты, неизменность исходных файлов и все56 пар откликов.
