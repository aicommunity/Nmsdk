# Перестановки паттернов сохранённой модели: протокол проверки

## 1 Назначение и границы

Исполнитель `Scripts/StructTrain/TimeLearner/frozen_physical_order.py` проверяет
зависимость отклика от порядка предъявления восьми паттернов. Используется
неизменная физическая модель DATA и уже выбранный порог. Нового обучения,
подбора порога и изменения физики в этом опыте нет.

Условие допуска — полный успешный прогон восьми проб через production
`physical-model-evaluate`, а также подтверждённое совпадение всех его временных
рядов и событий с исходным recognition-прогоном. Источник проходит штатный
`audit_run_manifest`; квитанция сравнения связана с SHA DATA, revision и метриками.
Контроллер должен работать в своей конечной группе процессов.

## 2 План опыта

Исходный порядок служит измеренным контролем. Затем выполняются семь циклических
перестановок, по восемь полных проб каждая. Всего с контролем получаются64
наблюдения, target присутствует в каждой позиции. Для новых проб задаются новые
run/trial ID; сохраняются sample ID, метка, hash, пачка импульсов, длительность,
окно измерения и сброс перед пробой. Положения target проверяются по меткам.

Для каждой новой пробы штатный scorer проверяет полное окно, сетку, события и
неизменность модели. Дополнительно сравниваются классификация, все отсчёты и
входные/выходные события с исходной пробой того же sample ID. Допуск сравнения
временных рядов1e−12 не является новым допуском сходимости learner.
Изменившийся валидный отклик сохраняется как обнаруженная зависимость от порядка;
он не скрывается ошибкой запуска. Неполный native-прогон не даёт итогового verdict.

## 3 Ресурсы и интерпретация

Предел native —28800с и2ГиБ; внешний контроллер ограничен отдельно и резервирует
ресурсы глобального реестра машины. Запуски на одном сервере последовательны.
Нельзя менять лимиты работающего задания или подменять его runtime.

Это проверка порядка при `reset_per_trial` на той же матрице. Она не проверяет
непрерывный поток, другой ITI, независимые паттерны или повторное обучение.
Производственный Python-путь пока явно отклоняет continuous stream; снимать
это ограничение только ради расширения серии нельзя. Все эти проверки остаются
отдельными пунктами основного плана.

Сохранённые Train завершились по бюджету. Даже полное совпадение64 реакций
не создаёт сертификата Exact и не меняет интерпретацию исходных отрицательных
квитанций. Полные данные и рисунки хранятся во внешнем архиве M40; в Git — код,
этот протокол и компактные проверенные ссылки.
