## Большие INFO-логи

На Elder в двух `Bin/Platform/Linux/EventsLog` найдено около110GB логов;
на M40 в пользовательском Bin — около59GB. В архиве M40 Data
`NmsdkStructTrainArchive/local_host_packs/local_20261012T045250Z/EventsLog`
найдено ещё200618577265B INFO-логов. Выборки начала/середины/конца крупных файлов
показывают многократное повторение `EolGateAudit` между изменениями состояния.

Версионированный `Scripts/StructTrain/TimeLearner/diagnostic_log_cleanup.py`
обрабатывает только `EventsLog/NeuroModeler.*.log.INFO.*`. Для последовательных
одинаковых EolGateAudit payload сохраняются первая/последняя исходные строки,
число повторов и byte interval. Любое изменение payload создаёт новую запись.
Все остальные строки, включая warning/error и другие диагностические сообщения,
сохраняются побайтно в base64. Полный SHA256 и line/byte counts исходного файла
записываются до удаления.

Это **не lossless архив оригинального лога**: промежуточные wall-clock timestamps
в одинаковых сериях удаляются по разрешению пользователя вместе с избыточным
текстом. Нельзя заявлять возможность восстановить весь оригинал по его SHA.
Сохраняются диагностические переходы, а не каждый одинаковый tick header.
Первичные измерительные waveform/CSV/JSON этим инструментом не обрабатываются.

Перед чтением и удалением проверяется fuser; изменившийся/открытый файл остаётся.
Сначала создаётся gzip summary, затем независимый structural readback проверяет
непрерывность byte intervals, counts, endpoints и footer. Summary и receipt
синхронизируются на диск до unlink. При ошибке/лимите summary оригинал остаётся.
Инструмент прошёл3 server tests на каждом worker: переходы/raw строки,
явное удаление только после readback, отказ для открытого лога/чужого типа файла.
Проверенный source commit5ed19492fefc38e680e091d5957c44cc16528c9d.

Большие log batches пока выполняются. Их промежуточные счётчики не являются
окончательной приёмкой. Малые журналы внутри отдельных исторических Train/Test
оставлены для evidence review. Полный обход миллионов файлов M40 был явно
остановлен как избыточный; адресный поиск EventsLog завершился отдельно.
Частичная выдача остановленного обхода не считается полным inventory.

## Предотвращение повторного роста

Подтверждён источник: в PulseLib38edfcad7983478a7e2ca736c32ae2703861c1fd
`NNeuronTimeLearner.cpp:5835` и `NNeuronTimeLearnerBranch.cpp:6766` печатают
EolGateAudit в legacy EndOfLearning при EnableDebug и незакрытом gate.
Дедупликация в самих компонентах пока не реализована. Это открытый пункт
ограниченной диагностики для compatibility/replay, не исправление математики.
Нельзя молча менять исторические настройки debug или путать обучение с
наличием/числом строк журнала.

После фактической нехватки места первого normal N0 job добавлен preflight
engineering corpus: не менее512MiB свободно для первичных данных до создания
output и запуска Console. Проверка2**63B budget подтверждает отказ без запуска.
Это ограничитель известного корпуса, **не scheduler reservation** и не общий
оценщик любого эксперимента. Полный ресурсный контур этапов2/10 ещё открыт.

Новая normal попытка N0 выполнилась в проверенном tmpfs с scratch на том же
filesystem, опубликована через Git и losslessly восстановлена на M40 Data
по1150 member hashes. Первая отменённая попытка сохранена отдельно и не PASS.
Никакие numerical jobs ради cleanup не перезапускались.
