# Сопоставимый Branch с предложением числа синапсов по измерениям

Новый поиск действительно изменил исследованные числа синапсов и приблизил
амплитуды к исходным целям. При одинаковых бюджете и конфигурации лучшие
амплитудные ошибки среди кандидатов с выполненным временным допуском
уменьшились примерно в5–11раз. Оба обучения завершились
`budget_exhausted / maximum_sweeps_exhausted`; ни один обучаемый вход
не выполнил одновременно исходные временной и амплитудный допуски.
Дополнение23.11: фактическая проверка новой модели дала TP1/FP2/FN0/TN5.
[Новый результат и ограничения](MeasuredCountBranchRecognitionResults-20261123.ru.md).

разбирался. Смысл вывода ограничен этим сопоставлением двух запусков.

## Измеренный результат

Каждый обучаемый вход имеет25 записей кандидатов, включая явный повтор
выбранного состояния. Новых кандидатов от этого не становится25 вместо24.
В каждом запуске всего75 записей,158 составных групп и948 первичных проб.
Одинаковое количество проб не означает одинаковую траекторию поиска.

|Вход|Конечная L в обоих запусках|Старое Nₛ|Новое Nₛ|Лучшая старая eₐ|Лучшая новая eₐ|
|---|---:|---:|---:|---:|---:|
|0|239|6|12|−0,01223943|−0,00106665|
|1|201|5|10|−0,01336322|−0,00224512|
|2|121|5|8|−0,01061935|−0,00212809|

Здесь eₐ — измеренная амплитуда закреплённого импульса минус собственная
исходная амплитуда входа. Потенциал выражен в условных единицах модели.
В таблице выбраны реальные кандидаты с выполненным временным допуском,
а не прогноз секущей. Опорный вход3 сохраняет L=1 и Nₛ=1.
Все сопротивления равны86МОм; ёмкость не настраивалась.

В новом запуске проверены, в частности, Nₛ=8 для входа2, Nₛ=10 для входа1,
Nₛ=11 и12 для входа0. Последовательности полного вектора параметров,
остатки, номера измерений и границы контекста сохранены в компактной
проекции. Нельзя приписывать меньший остаток только локальному Nₛ одного
входа: состояние общей ветви и ранее выбранные банки также различаются
между двумя траекториями. Сравнивается алгоритм целиком при одной исходной
задаче, а не изолированная проводимость в неизменном конечном графе.

## Что ещё не доказано

Даже лучшие новые ошибки больше исходного допуска. Свежая финальная
проверка всех входов не завершена; локальные улучшения не являются
сертификатом конечной модели. Предел128 не достигнут, физическая
недостижимость и целочисленная квантизация не доказаны. Для последней
нужны измеренные соседние точки вокруг цели, которых здесь нет.

По коду запас локального уточнения расходуется при помещении предложений
в очередь. Секущая и обычные соседи разделяют этот конечный запас;
он не пополняется после удачного измерения. Это объясняет, почему более
близкий кандидат не даёт неограниченного продолжения. Проверка того,
как лучше распределять прежний общий бюджет между уточнением и другими
длинами, остаётся отдельной гипотезой. Исходные бюджеты текущих запусков
не менялись. Полный независимый повтор всех решений контроллера по истории
пока не реализован; проекция его не заменяет.

Историческое промежуточное состояние22.11: на фактической новой остановленной модели выполнялись восемь исходных
диагностических проб. После их аудита отдельная очередь выбирает порог
по той же матрице и подтверждает его настоящим прогоном. До завершения
нельзя переносить прежние TP1/FP1/FN0/TN6 или результат новых отвлекающих
паттернов на новую модель. Повторный холодный Train для этой оценки не нужен.
