## Следующая научная проверка

После положительного полного аудита проверить сохранённую модель на
исходных восьми паттернах: полные двухсекундные окна, reset-per-trial,
baseline с исходным порогом100, затем один объявленный Same-Matrix
кандидат порога и настоящий подтверждающий Test. Если нет разрешимого
промежутка для целевого ответа, сохранить отрицательный результат.
Не подбирать модель по отвлекающим, не менять обученные параметры,
не выдавать baseline или калибровку за завершившийся Train.

Построить временные графики сомы и LT с реальными входными импульсами
для всех паттернов обеих фаз, включая увеличения без прореживания.
Полные модели, пробы и история должны попасть во внешний архив M40
с независимым чтением; этот документ не заменяет первичный комплект.
