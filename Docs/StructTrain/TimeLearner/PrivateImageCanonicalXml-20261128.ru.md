# Сохранение приватных образов: единая запись нейтрального состояния

## Подтверждённый исход

На .12 завершён адресный проход12 native-проверок в новой сборке корня
`15e0a347b4c732725c8ef31500a2c33303c7815b`, PulseLib
`d97b1b5f33244a4a35bd88032c347dc21c8dfdea`. Получено11 успехов и один
отказ `NativeImageRestSnapshot.RepeatedArchiveAndPoolReuseAt20000`.
Все12 объявленных случаев присутствуют в JUnit; процессы закрыты,
исходники и staged DATA сохранены. Полный этап хранения модели не принят.
[Каталог первичных данных](../../../Reports/StructTrain/TimeLearner/Progress-20261128/Jump12-private-image-native12-fr764.json)
ссылается на внешние объекты M40; тяжёлые данные в Git не добавляются.

Это отдельный проход после fr750, где было8 успехов из9. Три новых
проверки канонизации нейтрального буфера, сохранения ненулевого/широкого
буфера и различий State живого графа прошли. При2000 Гц повторный
archive roundtrip прошёл. Linux-проход не доказывает исправления
удерживаемого CSV handle в Windows.

## Оставшееся различие

В трёх циклах20кГц сравнение полных архивов не прошло. На первом цикле
до импорта записано1159685 байт, SHA256
`564d62c5f73f5a7111821414e04f98093d96b8aa1b8fef131e4846af6c0b2c5a`;
после —1159757 байт, SHA256
`b085f889ef789ce9486f12fee6fe2ebe9f48f3c3d3b7d6c2fde37f2ec8a6ff13`.
Изменились только XML hashes двух определений `NPMembraneBio` и общий
hash архива. Полный рекурсивный разбор XML этих определений дал одинаковые
узлы, атрибуты и значения. Текстовый diff показал по два пустых
`TrainerClassName`: `<TrainerClassName .../>` против
`<TrainerClassName ...></TrainerClassName>`. Нейтральные буферы уже совпали.

Причина подтверждается реализацией: кандидат d97b1b5 пропускал XML
через Load/Save только при исходном буфере1×1 с нулём. Для уже пустой
матрицы0×0 оставлялись прежние байты. Парсер Rdk и прямой SaveComponent
по-разному представляют пустые строковые узлы. Отказы не связаны с
различием физических параметров и не являются доказательством успешного
полного экспорта. Равенство массивов входов, времени, канала и сомы
в данном проходе проверено отдельно и не заменяет archive equality.

## Кандидат исправления и приёмка

PulseLib `724be61ee9cc038eeb17fe790571cd455f992bab` проводит через один
Load/Save обе строго проверенные нейтральные формы:0×0 с пустым текстом
и1×1 с конечным нулём. Область остаётся прежней: только приватная копия
определения нативного NPMembraneBio без связи InputFeedbackSignal.
Ненулевые, широкие, подключённые и неизвестные состояния не изменяются;
State живого графа, prototype и общий сериализатор Rdk не правятся.

Нужна отдельная серверная сборка и повтор тех же12 production-проверок.
Исходные ASSERT/EXPECT полного равенства архивов сохраняются. Необходимо
проверить2000/20000 Гц, все три цикла, реальный ненулевой отклик и
точное сохранение входных импульсов, времени, канала и сомы; отрицательные
контроли должны по-прежнему отличать запрещённые изменения. На момент
этой записи runtime-приёмки уточнения ещё нет. Научные Train Classic
fr613 и Branch fr766 используют прежние замороженные runtime.
