## Что следует из опыта

Получен воспроизводимый пример с одним ложным foil вместо массовых ложных срабатываний. Результат сохраняется при всех положениях target в режиме reset-per-trial. Для улучшения разделимости остаётся конкретный мешающий паттерн `phasea-row-4`; изменение порядка само по себе не устраняет его ответ. Успешное холодное обучение всей модели, перенос на независимые данные и устойчивость без сброса этим опытом не доказаны.

Августовские визуальные4/8–6/8 сохраняются как наблюдения своего протокола; эта серия их не переопределяет. OOM нового cold groupwall600 относится к другой попытке обучения и не отменяет здесь выполненный Test сохранённой модели. Полный исходный план остаётся активным, этапы1–12 частичны; научные8/8 не являются условием его завершения.
