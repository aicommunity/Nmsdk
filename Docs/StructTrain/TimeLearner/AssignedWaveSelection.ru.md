# Явный выбор назначенной волны в широком окне

Подэтап `stage07/assigned-wave-selection` продолжает измерительную schema 3.
Статус этой редакции: реализация подготовлена, серверная приёмка ожидается.

`ProbeSpec` и `VerificationProtocol` содержат `PeakSelectionPolicy`:

- `IsolatedWindow` — прежнее значение по умолчанию: окно содержит ровно один
  локальный максимум, совпадающий с назначенной волной.
- `AssignedBurstWave` — только schema 3 с `OrderedWholeBurst`: сначала
  проверяется вся наблюдаемая пачка, затем выбирается волна указанного
  stimulus ID на указанном физическом канале. Несколько максимумов внутри
  широкого окна допустимы при этом явно объявленном режиме.

Обе соседние с выбранным плато реальные samples должны находиться внутри окна.
Недостаточно численно расположить границы вокруг пика между отсчётами.
Missing/extra/clipped/nonfinite/incomplete пачка не становится валидной после
смены политики. Прогноз задержки не подтверждает отсутствующий пик.

Политика входит в протокол references и сертификата, проверяется при Start
native service и при каждом измерении. Warm restart с иной политикой требует
нового захвата references. Исторические schemas 1/2 запрещают назначенный выбор.

`ProbeEvidenceJson` использует envelope 2 с явным `peak_selection` в requested
и actual specs. Python auditor версии 3 читает envelope 1 как исключительно
isolated; envelope 2 требует явной согласованной политики. Неизвестное значение
и внедрение нового поля в envelope 1 отклоняются. CSV подтверждает всю пачку
и соседние samples выбранного плато. Это аудит измерений, не recognition verdict.

Контролируемые проверки: задержанная первая волна после второго стимула,
широкое окно с двумя максимумами, clipped neighbours, plateau, missing/extra
wave, смена политики и неправильная schema. Native проверки используют реальные
Classic/Branch, штатный reset/scheduler и неизменную физику: различаться должна
валидность выбора, но не waveform или model hash.

Ordered assignment предполагает одну положительную волну на стимул с сохранением
порядка. Это не доказательство идентифицируемости причин для произвольной
нелинейной физики. Автоматический подбор длительности наблюдения, configured V2,
большие исторические длины, производительность identity и научная матрица
остаются незавершённой работой исходного плана.
