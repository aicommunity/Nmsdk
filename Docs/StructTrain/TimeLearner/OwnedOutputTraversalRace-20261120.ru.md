# Удаление временного каталога во время контроля размера output

Console16 A1 на Elder закрыт с process_error после476.23с. Сохранены восемь
полных stopped-вариантов: Classic/Branch, fixed4/window5, N0/N1; каждый прошёл
свой cold preflight, Train, запись фактического пакета и frozen diagnostic.
Общая серия не получила итоговый результат Python и не считается принятой.
Owner и все наблюдённые native-группы закрыты, аренда освобождена.

Причина — FileNotFoundError для `worker/tmp/timelearner-cli-interface-*`.
Supervisor считал disk allocation через `Path.rglob`. Обработчик отсутствующего
файла был внутри тела цикла; удаление временного каталога могло вызвать
исключение при следующем шаге самого рекурсивного итератора. Оно вышло из
monitor callback и штатно остановило принадлежащую заданию группу.
Это дефект наблюдения output, а не отказ алгоритма обучения или C++ экспорта.

Python-only правка использует `os.walk` с явной обработкой ошибок обхода.
Исчезнувший дочерний каталог разрешён; отсутствующий корень задания,
ошибка доступа и ошибка I/O сохраняют отказ. Размер учитывается через lstat,
включая корневой каталог; символьные ссылки не обходятся. Лимиты не отключаются
и не увеличиваются. Механизм остановки группы при другом отказе monitor
остаётся прежним.

Добавлены четыре адресные проверки: реальное удаление каталога непосредственно
перед descent; PermissionError/I/O error; внешняя directory symlink; отсутствующий
корень output. Первые выполняются через production-функцию на реальной
файловой системе с детерминированным воспроизведением момента удаления.
Все серверные результаты правки ещё требуются. Исходная отрицательная
квитанция и primary A1 сохраняются. Повтор Console16 проводится отдельной
попыткой и отдельным Python actor на том же уже проверенном SDK; пересборка
C++ и изменение работающего Branch для этого не нужны.
