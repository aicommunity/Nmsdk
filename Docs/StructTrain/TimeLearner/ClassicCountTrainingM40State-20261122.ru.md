# Classic с нормализацией числом синапсов: новая сохранённая модель M40

Холодное обучение `s11-classic-count-training-m40-a1` завершилось с исходом
`budget_exhausted`. Нативная группа и её контроллер закрыты, код процесса0.
Получено остановленное состояние, а не сертификат Exact. Полный аудит
первичных данных прошёл. Все8 реакций при пороге100 действительно измерены
и полностью проверены:TP0/FP0/FN1/TN7. После выбора порога на той же матрице
выполнен отдельный настоящий Test всех8 паттернов; процессы закрыты, полный
аудит ещё выполняется. Рабочая классификация пока не утверждается.

синапсов, индивидуальные исходные амплитуды остаются целями. Постановка
сопоставима с прежним сопротивительным контролем; код и параметры сохраняются
в [исходной декларации](MatchedClassicCountTraining-20261121.ru.md).

В подготовку добавлен штатный `compact_json_transport`, уже применяемый
при физическом экспорте. Он удаляет только пробелы вне строк, сохраняет
все числовые токены, строки, поля и историю. Для него создаётся отдельный
файл: исходный пакет и жёсткие ссылки на него не переписываются. Лимиты
Python/Console и прежний SDK сохранены. После этого всё равно обязательны
строгие проверки пакета, разрешённого задания и нативного импорта.
