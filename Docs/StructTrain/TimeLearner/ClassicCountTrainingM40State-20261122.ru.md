# Classic с нормализацией числом синапсов: новая сохранённая модель M40

Холодное обучение `s11-classic-count-training-m40-a1` завершилось с исходом
`budget_exhausted`. Нативная группа и её контроллер закрыты, код процесса0.
Получено остановленное состояние, а не сертификат Exact. Полный аудит
первичных данных прошёл; реакции на восемь проверочных паттернов ещё не
измерены. Рабочая классификация этой новой моделью пока не подтверждена.

Использованы обычная топология, M=4 и2000Гц. Нормализация изменяет число
синапсов, индивидуальные исходные амплитуды остаются целями. Постановка
сопоставима с прежним сопротивительным контролем; код и параметры сохраняются
в [исходной декларации](MatchedClassicCountTraining-20261121.ru.md).
Новый алгоритм предложения Nₛ по секущей в этом опыте не использован.

Фактический нативный процесс занял33113,39с, около9,20ч. Модельное время —
1127,2235с; эти величины не смешиваются. Записаны627 внутренних предъявлений
и2254293 отсчёта. Это не627 независимых обучений или проверочных паттернов.
Сохранённая модель имеет revision
`b803678f5e47c7a393658d8847aba0a7b7f1237ece576043a6feb044473214d8`.
Пакет полного остановленного состояния занимает1173768677байт, сводка —
52795350байт. Они остаются вне Git.

При финальном сохранении временные наблюдения заменены именами
`train_stopped_trial_*.json/.csv`. Нулевое число временных `raw-trial-*`
в этот момент не означает потери данных. До закрытия группы данные не
использовались как завершённый результат. Достоверность полного набора,
истории поиска и конечной модели проверяется отдельным производственным
аудитом с лимитом16ГиБ. Он завершился за565,01с:1/1 без ошибок и пропусков,
все1992 исходных файла проверены, полный пакет разобран один раз. Группа
закрыта, исход budget_exhausted сохранён.
[Полный аудит и исходный пакет](../../../Reports/StructTrain/TimeLearner/MatchedClassicCountTraining-20261121/m40-count-full-primary-audit-passed.json).

Первая подготовка оценки остановилась до нативных проб: исходный пакет
1,17ГБ превышает предел1ГиБ файлового транспорта. Это ошибка подключения
существующих средств передачи данных, а не результат классификации.
В подготовку добавлен штатный `compact_json_transport`, уже применяемый
при физическом экспорте. Он удаляет только пробелы вне строк, сохраняет
все числовые токены, строки, поля и историю. Для него создаётся отдельный
файл: исходный пакет и жёсткие ссылки на него не переписываются. Лимиты
Python/Console и прежний SDK сохранены. После этого всё равно обязательны
строгие проверки пакета, разрешённого задания и нативного импорта.
Проверка исправления на действительном большом пакете ещё нужна.
[Исходный отказ и конкретное исправление](../../../Reports/StructTrain/TimeLearner/MatchedClassicCountTraining-20261121/m40-count-baseline-prepare-a1-rejected.json).

После успешного полного аудита подготовленная очередь выполнит восемь
исходных паттернов при исходном пороге, полный аудит, предложение порога
на той же матрице, настоящий прогон с ним и повторный полный аудит.
Из старых опытов берутся только паттерны и критерий. До фактических реакций
ни TP/FP/FN/TN, ни отделимость, ни успех семейства не выводятся из формы
или размеров обученной структуры. Все реакции потребуют читаемых временных
графиков сомы с входными импульсами и настоящими выходными событиями.
[Протокол](LinuxCountStoppedRecognitionProtocol-20261122.ru.md).

[Точные исходные статусы, модель, хеши файлов и реальная группа аудита](../../../Reports/StructTrain/TimeLearner/MatchedClassicCountTraining-20261121/m40-count-native-closure.json).
Полный внешний архив новой попытки ещё не опубликован; компактная квитанция
закрытия процесса не заменяет научную публикацию данных.
