# Classic: отдельная проверка предшественника цели

Подготовка следующего ограниченного опыта. До серверных проверок и
отдельной квитанции запуска этот документ не означает начатый расчёт.

В циклических поворотах короткого потока цель во всех непервых положениях
следует после `phasea-row-7`. Ранний дополнительный выход при сохранении
динамики обнаружен в нескольких положениях. Проверка Branch после разных
предшественников не заменяет проверку Classic на другой модели.

Следующий опыт использует прежнюю физическую DATA-модель Classic
`cbf49f5990229085ec8395a98b1c85418e2b6744b8e6bc1255ce8bf69de1bf7b`,
прежний порог `0.020736298148054874` и исходные восемь паттернов.
Обучение и подбор порога отсутствуют. Каждый из семи отвлекающих паттернов
отдельно предшествует цели; перед целью динамика либо сбрасывается, либо
сохраняется. Итого14 условий и28 наблюдений одной модели.

Первый паттерн всегда начинается со сброса. Заданная длительность первого
окна0,69с, фактические времена входов регистрируются. Последнее окно
включает не менее двух секунд после последнего входного импульса цели.
Весь поток наблюдается без разрывов. Изменение предшественника и политика
сброса — два явно заданных фактора; физика, модель, порог, исходные паттерны,
частота и положение цели остаются одинаковыми.

Используется `frozen_physical_predecessor_study`: то же объявление,
проверенное на Branch, с общей исполняющей частью
`frozen_physical_trial_study`. Она запускает штатный native pipeline и
производственный scorer. Полные окна, точное множество проб, неизменность
модели и порога, финальная тишина и закрытие процесса обязательны.
Специальный расчёт ответа нейрона в Python не вводится.

Перед запуском проверить14 действующих тестов объявлений на реальном
экспортированном Classic job, затем первые реальные парные условия.
Отдельно сравнить семь одинаковых первых ответов между политиками и
шесть целей после сброса между предшественниками. При различиях исходные
трассы сохраняются, ожидаемые счётчики не подставляются.

Публикация содержит реальные LT-события, их время относительно каждого
входа, TP/FP/FN/TN по прежнему критерию и отдельную отметку выхода до
последнего импульса цели. Нельзя приписывать событие в непрерывном потоке
одному текущему паттерну без оговорки о динамике предыдущего. Классификация
и своевременность ответа остаются разными характеристиками.

Запуск на M40 допускается после закрытия прежних112 проб, их процессов
и поставленного архивирования исходной пары. Реестр ресурсов должен
освободить слот. Чужие runtime, исходники и действующие задания не меняются.
Бюджеты каждого процесса и всей серии фиксируются в Git до запуска;
автоматического повтора завершённого опыта нет. Все28 реакций должны получить
полные временные графики с входными импульсами и выходными событиями.
Данные и производные файлы публикуются только во внешний архив M40.
