terminal selection сохранены прежние30с. Native memory cap —16GiB;
у Elder дополнительно резервируются8GiB владельца, итого24GiB.
Проверенная ёмкость его реестра24GiB, физически доступно более27GiB,
свободный диск превышает объявленные2GiB floor плюс4GiB output.

поиска, она не воспроизводит прежний84600с бюджет и не является ранее
[подготовленным часовым опытом](BoundedTerminalScience-20261120.ru.md).
Часовой опыт пока не запускается.

На Elder исправленный Python actor22259e764749a8c38ea2c07e15fd260b6c67220a
обслуживает контроль Console16; сам научный Train использует прежний
проверенный SDK и его штатный finite-controller. Падение обязательного
контроля прекращает последовательность до научного запуска.

## После завершения

Сначала установить состояние точных существующих handles и получить итоговые
пакеты/маркеры исполнения; отсутствие наблюдения не разрешает повтор.
Сохранить полные primary во внешнем архиве M40. Проверить закрытие процессов,
фактическую модель и полноту измерений. BudgetExhausted остаётся
диагностическим исходом, отсутствие модели запрещает Test шаблона.

Затем выполнить полный набор восьми паттернов, объявленную Same-Matrix
калибровку и отдельный реальный Test выбранного порога. Сохранить реакции
каждой сомы с фактическими входными импульсами, обзором и читаемыми
увеличениями. Ни запуск, ни наличие модели, ни PASS инженерных контролей
не являются новым научным результатом классификации.
