# Наблюдение за завершёнными процессами Windows

24 ноября исправлена ошибка наблюдателя собственных процессов. Она мешала
закрыть очередь построения отчётов и перейти к следующему эксперименту;
ошибкой нейронного алгоритма она не являлась.

## Дефект и исправление

После завершения процесса Windows ещё может сохранять открытый дескриптор
его объекта. Прежняя функция `live` сначала запрашивала путь исполняемого
файла и время создания. Запрос пути для уже завершённого процесса возвращал
`WinError 31`, хотя проверка состояния по тому же дескриптору могла
подтвердить завершение.

В `windows_stopped_recognition_study.py` состояние проверяется до запроса
идентичности. Если процесс завершился между этими действиями, повторная
проверка того же дескриптора подтверждает завершение. Ошибка чтения
идентичности живого процесса по-прежнему передаётся вызывающему коду:
неизвестное состояние не объявляется завершением. Проверки точного времени
создания и пути исполняемого файла сохранены.

## Фактическая проверка

Исправление корня `52cb5019f2e9b5ef3e0333e6fd70f530d2fa69fd`
проверено на Windows-работнике через целые производственные модули.
Исходный SDK и его вычислительная среда не изменялись.

| Проверка | Требуемое поведение |
|---|---|
| Живой собственный процесс | Идентичность подтверждена |
| Другой момент создания при том же PID | Совпадение отвергнуто |
| Завершённый процесс с удерживаемым дескриптором | Возвращено состояние завершения |
| Завершение реального дочернего процесса во время чтения идентичности | Повторная проверка подтверждает завершение |
| Ошибка чтения идентичности ещё живого процесса | Ошибка сохраняется |

До исправления выполнены пять проверок, получены две ошибки; после
исправления прошли все пять, без пропусков. Обе ограниченные группы
процессов полностью закрыты. Это проверка наблюдателя Windows, а не новое
обучение, проверка нейрона или приёмка всего этапа10.

Полный пакет из36 файлов независимо восстановлен на M40 с проверкой
контрольных сумм. Сохранена также первоначальная ошибка подготовки,
при которой проверки ещё не запускались. [Проверяемая внешняя квитанция](../../../Reports/StructTrain/TimeLearner/Progress-20261124/Windows-process-lifetime-AB-dn25.json).

## Отдельная ошибка постановки очереди

Попытки `dimension-lifecycle-native-dn22` и зависимая
`classic-third-pulse-sensitivity-dn23` закрылись до запуска вычислительных
операций. В описании проверок использован разделитель `Suite.Test`, тогда
как производственный реестр выдаёт `Suite/Test`. После исправления
разделителя созданы отдельные попытки `dimension-lifecycle-native-dn31`
и `classic-third-pulse-sensitivity-dn32`; прежние ошибки сохранены.
Регистрация новой очереди сама по себе не доказывает прохождения проверок
или завершения научного опыта. Их результаты учитываются отдельно.
