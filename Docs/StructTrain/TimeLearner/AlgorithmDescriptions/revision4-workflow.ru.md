# Поддерживаемые описания алгоритмов

Общие требования находятся в [правилах научных отчётов](../ScientificReportRules.ru.md).
Публикации авторов задают стиль и терминологию; действующие алгоритмы объясняются
по реализации и фактическим наблюдениям.

Четвёртая редакция перерабатывает оба документа по восьми замечаниям пользователя
от19.11.2026. Оригинал с комментариями сохранён вне Git без изменения. Журнал
замечаний: [Review-20261119.json](Review-20261119.json); текст:
[revision4-content.ru.json](revision4-content.ru.json); исходники схем:
[diagrams/sources.json](diagrams/sources.json).

Предыдущий генератор и его исходники доступны в корневом commit
`c863b1f0d16cf460c2bc3b9f9deeca3c75599f8c`, путь
`Scripts/StructTrain/TimeLearner/publications/build_algorithm_docx.py`.
Смена генератора не изменяет уже опубликованные редакции и оценки опытов.

Новый путь подготовки:

1. Получить из внешнего архива выбранные первичные наблюдения и полные условия.
   Проверить контрольные суммы файлов и принадлежность архивам. Исторический
   адаптер сохраняет исходный критерий и явное происхождение каналов.
2. Построить схемы через `render_algorithm_diagrams.cjs` и Graphviz.
3. Построить временные графики через `plot_algorithm_trials.py`, измерения и
   измеренные шаги поиска через `plot_algorithm_measurements.py`. Эти средства
   иллюстрируют данные и не создают нового итогового verdict.
4. Собрать каталог иллюстраций, включающий условия каждого примера, источник,
   фактический порог и версию измерителя. Полный комплект содержит реакции
   на все паттерны; в Word выбираются характерные TP, TN и имеющиеся FP.
5. Собрать оба документа через `build_algorithm_docx.py`, указав `--source`,
   `--output`, `--diagrams` и `--figures`. Режим `--draft` допускает пропуски
   только для внутренней проверки; он не создаёт принятую редакцию.
6. Отрисовать оба DOCX через `render_docx.py`; просмотреть каждую страницу,
   исправить формулы, шрифты, масштаб и размещение рисунков. Результат генерации
   не означает завершения визуальной приёмки.
7. Опубликовать документы, рисунки, первичные выборки, команды и контрольные
   суммы во внешнем архиве M40. В Git записать только исходники и компактную
   ссылку на принятую редакцию; затем закрыть обработанные замечания.

Поясняющее усечение полной записи обязательно маркируется как методическая
иллюстрация. Его нельзя выдавать за действительно прерванную пробу. Исторический
отказ назначения вершины не означает физического отсутствия любого отклика.

На момент подготовки исходников четвёртой редакции полная визуальная приёмка
ещё не завершена; последний принятый комплект документов сохраняет свой статус.
