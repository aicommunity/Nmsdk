## Источники и выпуск

`content.json` содержит общую часть и различия топологий;
`evidence-register.json` — версии, actual observations, критерии и внешние refs;
`authoring-spec.json` — требования и приоритет экспериментов.
Сборщик: `Scripts/StructTrain/TimeLearner/publications/build_algorithm_docx.py`.
Запускать его в подготовленном document runtime с python-docx, Pillow и lxml;
он требует отдельный новый выходной каталог и явные шрифты Arial Windows.

```text
python build_algorithm_docx.py --source <этот каталог> --output <новый внешний cache>
render_docx.py <Classic.docx> --output_dir <QA Classic>
render_docx.py <Branch.docx> --output_dir <QA Branch>
```

После сборки обязательны отрисовка и просмотр всех страниц. Успешная запись
DOCX не означает приёмки. Проверять формулы, индексы, принадлежность таблиц
конкретному примеру, размер подписей и переносы страниц. Выпуск связывать
с hashes входов, сборщика, DOCX и просмотренных страниц.

В Git хранятся только источники и компактная `publication.json`.
DOCX, полный выпуск с источниками и рисунки находятся во внешнем архиве M40;
локальная копия для чтения — `E:/Science-Repo/TimeLearner-Documents/2026-11-16`.
Нативные N2-данные и отрицательные legacy controls сохранены отдельным primary.

## Когда обновлять

При изменении алгоритма, effective storage physics, режима измерений,
export/import, калибровки или критериев обновить соответствующий раздел и
реестр доказательств в том же этапе. При новом результате проверить TP/TN,
completeness, frozen revision, actual threshold и число уникальных foil.
Сходные варианты добавлять в существующее семейство; различия и наблюдаемый
эффект описывать отдельно, причинный эффект утверждать только по matched
контролю. При смене исходников пересобрать оба затронутых документа,
повторить визуальную проверку и опубликовать новую неизменяемую версию.

Научные эксперименты имеют приоритет. Если выпуск конкурирует за необходимые
им ресурсы, зафиксировать требуемое обновление и отложить вёрстку до границы
экспериментального этапа. Не оставлять старый Word-файл под видом новой версии.
