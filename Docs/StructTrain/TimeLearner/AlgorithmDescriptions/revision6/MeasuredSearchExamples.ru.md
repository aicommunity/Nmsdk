# Измеренные примеры поиска

## Назначение контрольных примеров

Ниже разобраны две сохранённые последовательности измерений нейронов
с независимыми дендритными путями. Они поясняют, как изменение
геометрии сочетается с амплитудной настройкой. Для первой последовательности
изменялось число синапсов, для второй — сопротивление. Различаются
также исходные длины, собственные амплитудные уровни и ограничения
поиска. Это два примера действия правил, а не парный опыт с изменением
только одного фактора.

В каждой точке сохраняются параметры обоих путей. Опорный путь имеет
длину1, один синапс и сопротивление86МОм. В таблицах приведены параметры
настраиваемого пути, подписанная временная ошибка и ошибка его собственного
амплитудного уровня. Полные значения и исходные истории находятся
в связанном наборе данных [1]; численные значения текста округлены.

## Дискретная настройка амплитуды

В первом примере разрешены L=2 или3 и n=1 или2. Сопротивление
зафиксировано на86МОм. Исходный уровень настраиваемого пути равен
0,002968945525607114 в шкале модели. Временной допуск составляет20мс,
абсолютный амплитудный —10⁻⁵. Ограничение поиска —четыре новых
кандидата и один проход.

Таблица — Измерения при настройке длины и числа синапсов

| Измерение | L | n | Временная ошибка, мс | Амплитудная ошибка |
|---|---:|---:|---:|---:|
|1|2|1|−68,0|0|
|2|3|1|−58,5|−0,0004389148545|
|3|2|2|−68,0|+0,003239092459|
|4|3|2|−58,5|+0,002321355456|
|Повтор выбранного состояния|2|1|−68,0|0|

Увеличение длины с2 до3 уменьшает величину временной ошибки с68
до58,5мс, но оба результата остаются вне20мс. При одном синапсе
дополнительный сегмент одновременно ослабляет выбранный максимум.
Второй синапс увеличивает амплитуду: при L=3 ошибка меняет знак,
переходя от−0,0004389 к+0,0023214.

Эта пара показывает ограничение настройки только числом синапсов
при данной геометрии. Заданная амплитуда находится между двумя
измеренными уровнями, а ни один из них не выполняет амплитудный
допуск. Дополнительное изменение длины либо другой разрешённый
параметр потребовали бы новых измерений и иных объявленных границ
поиска.

Алгоритм возвращает измеренное состояние L=2,n=1. Его амплитудная
ошибка равна нулю, временная —−68мс. При сравнении кандидатов сначала
учитывается выполнение временного допуска, затем амплитудного;
из исследованных точек временной допуск не выполнила ни одна.
Возвращение исходного амплитудного уровня не завершает задачу
синхронизации. Поиск остановлен после разрешённого одного прохода.
Последняя строка таблицы является повторной проверкой выбранной
точки, а не пятым новым кандидатом.

## Настройка сопротивления после изменения длины

Во втором примере у нейрона два дендритных пути и один синапс на
каждом. Для настраиваемого пути разрешены длины1–3 и сопротивления
43–86МОм. Используется паттерн из двух импульсов с промежутком30мс;
задержка до первого импульса задана отдельно и составляет10мс.
Частота вычисления —2000Гц. Временной допуск равен20мс, абсолютный
амплитудный —10⁻⁵.

Собственный исходный уровень настраиваемого пути составляет
0,004590480933837182, опорного —0,005492406840386876 в шкале
модели. Настройка должна восстановить первый из этих уровней
после изменения его пути, сохраняя второй как собственный уровень
опорного пути.

Таблица — Измерения при настройке длины и сопротивления

| Измерение | L | R, МОм | Временная ошибка, мс | Амплитудная ошибка |
|---|---:|---:|---:|---:|
|1|1|86,000000|−28,5|0|
|2|1|43,000000|−28,5|+0,005008987920|
|3|2|86,000000|−19,0|−0,001207591551|
|4|2|43,000000|−19,0|+0,002483243516|
|5|2|60,811183|−19,0|+0,0002846501353|
|6|2|66,315065|−19,0|−0,0001435073551|
|7|2|64,416929|−19,0|−0,000004571329887|

При L=1 изменение сопротивления между границами заметно меняет
амплитуду, но временной остаток−28,5мс остаётся вне допуска.
Увеличение длины до2 при86МОм меняет остаток на−19мс. В этой
точке временное условие уже выполнено, однако максимум стал ниже
собственного исходного уровня на0,0012076.

Сопротивление43МОм при той же длине даёт ошибку другого знака.
Промежуточные сопротивления постепенно уточняют область изменения
знака. Измеренная ошибка при60,811183МОм положительна, а при
66,315065МОм отрицательна. Следующее значение64,416929МОм
проверено отдельной пробой. Ошибка−4,5713·10⁻⁶ удовлетворяет
амплитудному допуску10⁻⁵; временной остаток−19мс удовлетворяет
допуску20мс.

Итог означает выполнение объявленных ненулевых допусков в этой
контрольной постановке. Временная ошибка при этом сохранилась:
неопорный отклик приходит раньше опорного на19мс. Совместное
рассмотрение двух ошибок показывает, почему точного совпадения
времён нельзя заключать только из программного названия результата.

## Распознавание в примерах с двумя импульсами

Для отдельных контрольных моделей обеих топологий с нормализацией
сопротивлением сохранены реакции на цель и один растянутый во времени
отрицательный паттерн. Каждый из них предъявлялся при двух правилах
подготовки динамики: со сбросом и с её сохранением. Для каждой
топологии зарегистрированы TP=2,FP=0,FN=0,TN=2 [2]. Два правильных
отклонения относятся к одному различающемуся паттерну в двух условиях.

У нейрона с независимыми путями применён порог
0,004778170524504632, у нейрона с общей ветвью —0,009585770684824468
в шкале соответствующей модели. Эти значения относятся к сохранённым
моделям распознавания после подбора порога. Они отличаются от порога
измерений, использованного при обучении.

Контрольные примеры используют свою историческую версию измерения
пачки. Новая проверка закреплённой вершины через полную пачку,
пропуски и повтор описана отдельно в методике. Условия измерения
каждого примера сохраняются при сопоставлении результатов.
