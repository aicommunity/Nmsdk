# Windows package6: actual build failure

Дополнительная .14 сборка Root877/Pulse674 завершилась отрицательно. [Исходный terminal/backend result и конец compiler log](../../../Reports/StructTrain/TimeLearner/s02-windows-package6-build-failure-root-observation/terminal-and-compiler-tail.json): MSVC C2607 в NativeTrainingServiceComposite.cpp:206; Ninja остановлен, owned batch вернул13. Backend отдельно обнаружил PID9464 при выходе main process и завершил весь Job: execution=descendants_remaining, all_processes_closed=true. Эти два факта не объединяются в «ошибка descendants вместо compiler error». Build не принят; C++ tests и научные модели не запускались.

Проверка noexcept для std::optional<TrainingCapacitance> не переносима на наблюдённую MSVC STL. TrainingCapacitance содержит std::map; установленный map move constructor не объявлен noexcept, а _Tree move constructor вызывает _Alloc_sentinel_and_proxy. [Readback установленной STL](../../../Reports/StructTrain/TimeLearner/s02-windows-package6-build-failure-root-observation/msvc-map-optional-header-readback.json) фиксирует SHA256 map/xtree/optional и точные snippets. Это объясняет compile-time отказ; повреждение C0 при actual Windows Train не наблюдалось, поскольку build был остановлен.

Утверждение защищает транзакционную публикацию после InvalidateOwnerControlLifetime. Удалять его или безусловно объявлять map move noexcept нельзя: пустой target optional может потребовать создания map и выделения памяти уже после отзыва старого управления.

В отдельной Pulse branch подготовлен кандидат f1df2500d43ecab4723d2536cd4a7ce073416feb: optional C0 value помещается в unique holder до последнего model/clock guard, затем публикуется noexcept pointer swap. Для отсутствующего C0 holder не выделяется; чтение возвращает неизменяемое empty optional. Refresh сначала готовит новый holder; Reset очищает holder. Public values, wire schemas, storage physics и Rdk lifecycle не меняются. Static assertion сохранён для действительной операции публикации. **Это source candidate, ещё без компиляции и runtime приёмки.** Нужны MSVC build, Linux/Windows C0-present/absent, asymmetric roundtrip, warm import, failed restart и полная согласованная проверка core.

Backend сообщил закрытие всех процессов, exact cmd984/FILETIME134387227012441181 больше не жив; свежая проверка named Job, полный negative archive и postfailure source/dependency readback пока не приняты.
