# Параметризованные проверки компонентов на Windows

## Причина изменения

Полная проверка текущего `Test_PulseLib_StorageComponents.exe` на .14
остановилась до расчёта: список содержит, например,
`TopologiesAndRates/NativeTimingProperties.RejectNonfiniteWithoutChangingPreviousValue/0`.
Прежняя Windows schema4 принимает только пару `Suite/Case` и заменяет
разделитель на точку. Такая замена не сохраняет имена параметризованных
проверок. Отказ подготовки fr709 сохранён; успешная проверка полного
набора этой попытке не приписывается.

## Контракт нового запуска

Явная schema7 использует существующие production-разбор полного имени,
формирование фильтра и проверку JUnit. Слеши внутри имени класса и
параметра сохраняются; разделителем класса и метода служит единственная
точка. Дубликаты, неизвестные имена, пропуски, незавершённые и пропущенные
тесты по-прежнему запрещают положительную приёмку.

Windows Job Object, ограничения памяти и числа процессов, захват реально
загруженных библиотек, проверка полного закрытия процессов, неизменность
runtime и исходников сохраняются. Объявляемые каталоги результатов
ограничены существующим списком переменных fixtures. Фильтр ограничен
24576 кодовыми единицами UTF-16, оставляя место другим аргументам
CreateProcessW. Набор разбивается на конечные части до запуска; каждая
часть сохраняет точные имена и собственный JUnit.

Schema4 сохраняет прежний контракт. Linux schema6 остаётся отдельным
контрактом с cgroup и `tasks`; перенос его полей в Windows не разрешён.
Загрузка записанных внешних моделей этим изменением не добавляется.

## Проверки и границы доказательства

Новые проверки вызывают production-сериализатор фильтра и валидатор:
два положения слешей, старый формат, обязательные поля, ограничения
процессов, неизвестные переменные окружения, дубли, внедрение операторов
фильтра и различие Windows/Linux бюджета аргумента. Настоящий запуск
параметризованных C++ fixtures должен дополнительно подтвердить отбор,
JUnit, сохранность результатов и владение процессами на .14.

При фиксации этой исходной правки серверные проверки ещё не выполнены.
Полная приёмка этапов4/7/10 и всего плана не объявляется. Физика модели,
цель обучения и действующие научные задания не изменяются.
