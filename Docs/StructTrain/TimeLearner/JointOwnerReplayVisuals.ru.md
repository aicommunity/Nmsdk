# Графики фактического переноса обученной модели

[Открыть выбранные графики](../../../Reports/StructTrain/TimeLearner/s11-joint-owner-replay-visual-a2/index.html).

Проверка на M40 построила 60 видов для восьми моделей Classic/Branch × N0/N1 × C-Off/On и всех 12 каналов сомы. Каждый вид содержит фактический SumPotential и наложенный фактический вход. Все отсчёты сохранены; размер PNG — 1920×960. На увеличениях показано по 100 шагов с разрешением не менее восьми пикселей на шаг; предусмотрены локальные амплитудные увеличения. Реальный серверный тест проверил весь комплект: 1/1, без ошибок и пропусков.

В Git сохранены 24 выбранных рисунка, HTML, manifest и контрольные суммы полного кэша. Полные 60 видов PNG/SVG/PDF (12 258 931 байт, 182 файла с HTML/manifest) находятся на M40:
`/media/user/Data/TimeLearnerRefactor/readbacks/s11-joint-owner-replay-visual-a2/full-report-cache`.
Первичные данные повторно в отчёт не копируются. Их Git commits: native304 — `25bbda5529caea24e8847973cd603d50b1b45826`, восемь новых отдельных процессов — `fceadad95533874093d192ec968595b69b0fc270`. Renderer source — `ae1f9e152eedfc20454cdeec6262aaa901d454f1` в отдельной непринимаемой пока целиком ветке; текущий develop не объявляется содержащим весь этот программный контур.

Первый запуск графиков использовал системный Python без matplotlib и завершился ошибкой окружения. Его журнал и закрытие изолированной группы сохранены в verification.tar.xz. Повторный запуск использовал plot-venv-a1, вновь проверил восстановленные данные по Git-архивам и прошёл. Повторного расчёта нейронов или обучения не было. Обе группы процессов закрыты по проверке ядра. Сохранение данных на отдельном диске не затрагивает активную ASan-сборку.

Локально независимо сверены SHA256 всех опубликованных файлов. Вручную просмотрены четыре рисунка: Classic/N0/C-Off — zoom-001, Classic/N1/C-On — overview, Branch/N0/C-Off — zoom-001, Branch/N1/C-On — overview (Soma1). Оси, подписи, входные импульсы и форма ответа читаемы, заголовки помещаются. Полная ручная приёмка всех видов не заявляется; `visual_acceptance_complete=false` сохранён в первичном manifest.

Это диагностический отчёт о сохранении отклика после переноса, с одним объявленным паттерном на модель. Он не заменяет реакции на всю классификационную матрицу и не доказывает разделимость, устойчивость к ITI/порядку или причинный эффект LT-мембраны. Использованы инженерные профили с явными допусками; выводов об августовских наблюдениях по этим графикам нет.

Для воспроизведения использовать указанный renderer source и Python с matplotlib/Pillow; восстановить исходные архивы из двух указанных Git commits, затем выполнить модуль `Scripts.StructTrain.TimeLearner.recognition_owner_replay_reports SOURCE REPLAY --output NEW_CACHE`. Production audit перед рисованием проверяет соответствие реального переноса исходной модели. Пути SOURCE/REPLAY должны указывать на восстановленные корпуса, а выходной каталог должен быть новым.
