# Git в фоновой проверке исходников Windows

Публикация новых реакций cap24 fr705 остановилась после закрытия
научных процессов, при проверке Python-исходников. Один `git ls-tree`
завершился с кодом3221225786 (`0xC000013A`). Причина прерывания
не установлена. Сам Train и оба Test из-за этого не повторяются.

В используемых функциях `_source_snapshot`, `_git` коллектора и
`source_closure` отсутствовал `CREATE_NO_WINDOW` для Git-подпроцессов.
Фоновый Python без консоли не должен открывать новые интерактивные
консоли при каждом чтении blob. Эти вызовы теперь явно используют
штатный Windows-флаг; на Linux значение остаётся0. Тот же режим
применён к подготовке настоящего временного Git в двух регрессионных
проверках source projection.

Не меняются коды ошибок, режим запрета lazy-fetch, проверка точных
байтов blob, чистоты дерева, commit и runtime. Прерванная проверка
не превращается в успешную и автоматически не пропускается.
Новый публикатор должен работать из отдельного Git-привязанного
Python-дерева, повторно проверить сохранённые исходные данные и
архивировать все16 реакций. Это новая попытка публикации, без нового
обучения или вычисления модели.

На момент фиксации правки серверная проверка новых Git-вызовов и
повторная публикация ещё открыты. Исходный отказ fr705 сохраняется.
Наличие пропущенного флага не устанавливает причину конкретного
прерывания по одному exit code.
