# Короткое холодное обучение Classic и Branch N4

Два новых холодных Train при одинаковой Fast3-физике дали сохранённые
остановленные модели. После отдельного фактического подбора readout обе
модели отвечают на target и шесть из семи foil: **TP=1, FP=6, FN=0, TN=1**.
Это отрицательный результат короткого обучения. В описания работающих
алгоритмов он не включается: требование TN≥2 не выполнено. Исходный порог100
даёт полное молчание обеих моделей, TP=0/FP=0/FN=1/TN=7.

Это новый Train двух моделей, не повтор Test старой terminal21600 модели.
Сильнейший ранее подтверждённый Branch результат TP=1/FP=1/FN=0/TN=6
сохраняет собственные условия и этим опытом не отменяется.

## Обучение и область вывода

ControllerVersion2, N1, CapturedPerInput, anchorN−1, частота2000Гц,
C-trimOff; допуски амплитуды1e−5/0 и времени0.02с. Для каждой модели
объявлены120с model time и240000 native ticks. Остановка — external_stop
после исчерпания model tick budget, reference_complete=true,
completed_boundary=false. Общего TrainingCertificate нет. Структуру посреди
поиска нельзя считать сходимостью или динамическим checkpoint пробы.

| Топология | Конечные L | Конечные Rs Ом | Размер stopped package байт |
|---|---|---|---:|
| Classic |3,1,1,1|86000000 для каждого входа|43417149|
| Branch |3,3,3,1|86000000 для каждого входа|18542650|

Обе модели фактически экспортированы Train и полностью импортированы native
Test. Сохранение свежей759-probe истории в прежнем OOM-сценарии этим не
доказано. Owner4ГиБ/native8ГиБ и host reservation12ГиБ проверены во время работы.

В каждой summary search_probes=8, записаны всего три кандидата. Последний
измеренный Classic кандидат относится к input0/L2/Rs86M: timing остаток
−0.478с при исходном−0.480с, амплитудный остаток−0.005101293201065005.
Последний Branch кандидат относится к input2/L2/Rs86M: timing−0.238с
при исходном−0.240с, тот же амплитудный остаток. Оба допуска не выполнены.
Сохранённая конечная структура уже отличается от этой последней измеренной
точки: в stopped state оказался следующий эффективный edit. Это не скрыто
выбранный лучший кандидат и не locally certified input. Результат Test
относится именно к фактически сохранённой модели.

Для следующего matched cold опыта сохранены исходные длинные бюджеты
7200с model time/14400000ticks и21600с общего control wall, с native16ГиБ
и совокупным host admission24ГиБ. Это новый холодный Train, не продолжение
остановленной пробы. После завершения публикации запущен
`s10-finite-long-cold-train-integrated-m40-a3`, controls
`690630e10263c63d4bccccabebc85fa542d13c7e`, actor
`bc81b4c4bd953e310d13aad3626414d495bf8f9b`.
На 03:56 UTC 17 ноября подтверждён работающий Classic native process,
native MemoryMax16ГиБ, host reservation24ГиБ; Branch следует за ним.
Границы L1..256 и Rs1..86МОм, исходная физика и математическая цель не
изменялись. Получение конечной модели и результат длинного Train ещё не заявлены.

## Порог и фактическая классификация

Сначала предъявлены все восемь PhaseA паттернов при threshold100. Production
proposal использовал неспайковые LT traces этой же матрицы; кандидат
фиксировался до нового native Test. Сам offline proposal не доказывал
фактический спайковый результат.

| Модель | Фактически проверенный порог | TP | FP | FN | TN |
|---|---:|---:|---:|---:|---:|
| Classic baseline |100|0|0|1|7|
| Branch baseline |100|0|0|1|7|
| Classic candidate |0.02277503092148453|1|6|0|1|
| Branch candidate |0.03939337360819445|1|6|0|1|

Все32 наблюдения полные и валидные, окна2с, reset_per_trial; frozen model
hash проверен в каждой серии. Это Same-Matrix diagnostic, не независимая
оценка или Exact. Положительный исход процесса означает исполнение опыта,
не научный PASS. Потенциалы и пороги — в native model units.
