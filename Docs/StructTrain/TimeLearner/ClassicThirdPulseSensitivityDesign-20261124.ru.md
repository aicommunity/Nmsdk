# Диагностическая чувствительность Classic к третьему импульсу

Постановка24.11.2026. Проверяется уже обучавшееся физическое состояние
`eee84b64692115508ccd8ca7e69b29477d29198b9b0758e69f16a781f4093367`,
с фиксированным порогом0,02620777717403984. Его исходный Train завершён
по бюджету; финального сертификата всех входов нет. Длины243/200/1/1
и числа синапсов13/11/1/1 сохраняются во всех пробах.

## Основание и вопрос

Исходная цель имеет фактические входы0,01;0,09;0,25;0,49с. Известный FP
`phasea-row-6` имеет входы0,01;0,05;0,09;0,49с: в нём тоже присутствует
импульс0,09с, хотя он занимает другую порядковую позицию. Это наблюдение
не доказывает нечувствительность к третьему импульсу и само по себе
не выделяет причинный механизм ошибки.

В новой серии первые два и последний моменты фиксированы, сдвигается только
третий. Время от первого входа:

```math
P(\delta)=\{0;\ 0{,}08;\ \delta;\ 0{,}48\}\ \text{с},
\qquad
\delta\in\{0{,}12;0{,}16;0{,}20;0{,}24;0{,}28;0{,}32;0{,}36;0{,}40\}.
```

Цель — только исходный паттерн при δ=0,24с; остальные семь обозначены
отвлекающими. Исходная задержка генератора0,01с сохранена. Таким образом,
момент третьего входа относительно начала первой пробы равен δ+0,01с.
Все моменты лежат на исходной сетке2000Гц. Восемь значений, их порядок
и метки зафиксированы до расчёта.

## Протокол и проверки

- Штатный frozen Test через `prepared_physical_evaluation`; нового Train,
  retarget обучаемой цели или калибровки нет.
- Сброс физической динамики перед каждой пробой, полное окно2с,
  запись всех четырёх сом, входов, LT-потенциала и выходных событий.
- Неизменность хеша модели и порога, эффективный readback входного фактора
  и совпадение контрольной цели с прежней полной реакцией.
- Сохранение исходного критерия классификации; отдельный учёт времени выхода
  от последнего входа. Максимум отдельной сомы не заменяет решающий LT-сигнал.
- Единый `ConditionSpec` для каждого условия и отдельно для упорядоченной
  матрицы; пути и ID попытки не входят в научную идентичность.
- Лимит нативной операции3600с и8ГиБ; незавершённая серия не получает
  положительного verdict. Общее окно —32 000 модельных тактов плюс
  штатные граничные такты планировщика.

Рассчитать и сохранить фактические TP/FP/FN/TN, входные и выходные времена,
все полные кривые и увеличение окрестности последнего входа. Число ложных
ответов не задаётся заранее. Применить обычные проверки полноты, первичной
связности данных и реального native исполнения.

## Предел вывода

Серия выбрана после изучения FP и структуры остановленной модели.
Это направленная диагностика, допускающая пересечение с прежними
паттернами; она не является независимым Test и не заменяет уже законченный
набор семи новых отрицательных примеров. Повтор цели не увеличивает число
положительных классов. Возможная слабая чувствительность будет результатом
этой модели при данном пороге, а не доказательством общего свойства всех
вариантов обучения. Вывод о роли распределения бюджета требует также
закрытого парного контроля политик0/4.
