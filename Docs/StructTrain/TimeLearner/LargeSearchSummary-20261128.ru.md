# Большая история Classic/Rs и бюджет чтения отчёта

Закрытый Train fr613 сохранил законный summary9 размером276897143байт.
Полный production-аудит Train завершён;1621 файл опубликован в каталоге
`experiments/2026-11-28/M40-Classic-Rs-cold-primary-fr852.json` внешнего
архива. Это ещё не независимая приёмка или оценка распознавания.

Общий `analyze_search_history` раньше имел неизменяемое ограничение64МиБ
при чтении summary. Такой источник нельзя обработать этим интерфейсом,
даже если полный аудит всех первичных данных успешен. Отдельная малая
проекция fr852 сохранила27 кандидатов, но для конечного графа обратилась
к несуществующим именам `actual_parameters`/`terminal_selection` вместо
`parameters`/`terminal_event` summary9. Она явно сохранила null; это
ограниченный промежуточный разбор, не полный отчёт конечной модели.
Исходный архив и эта проекция не переписываются.

Подготовлен явный бюджет чтения `maximum_summary_bytes` в API и
`--maximum-summary-bytes` для `analyze --format native-search-history`.
Default64МиБ сохраняется, предельное допустимое значение —1ГиБ;
булево, нецелое и неположительное значение отклоняются. Для этой серии
объявляется512МиБ в ограниченном серверном процессе. Размер источника,
его полный digest и вся строгая проверка неизменности файла сохраняются.
Бюджет чтения не меняет численные допуски, историю или исход Train.

Новый проход должен вызвать полный production CLI и штатную проекцию
summary9, сохранив реальные конечные параметры отдельно от последнего
поискового графа. `test_large_search_summary` требует настоящий полный
Train через `TIMELEARNER_LARGE_SEARCH_PRIMARY`; проверяет27 измерений,
15 временно допустимых точек, отсутствие совместного допуска и
отрицательные claims об attestation/вердикте. Default должен по-прежнему
отказать для большого файла. Новые проверки ещё не выполнены; они не
заменяются анализом отдельной функции или копии тела алгоритма.
