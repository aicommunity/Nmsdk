## Пути и ограничения

| Назначение | Путь или предел |
|---|---|
| Исходники и штатные ресурсы | `/home/user/Nmsdk` и `/home/user/Nmsdk/Bin` |
| Частный CMake | `/home/user/Nmsdk-build-tools/cmake-3.28.4` |
| Новая сборка, логи, runtime | `/home/user/Nmsdk-builds/timelearner-sdk-20261126-fn85` |
| Минимальный свободный остаток | 32 ГиБ = 34 359 738 368 байт |
| Предварительный резерв новой сборки | дополнительно 12 ГиБ |
| Порог защитной остановки собственной сборки | 33 ГиБ свободного места |
| Параллельная компиляция | 4 потока, NMSDK_BUILD_PARALLEL_JOBS=4, CPUQuota 400% |
| Память сервиса сборки | не более 16 ГиБ |

Подготовка запущена отдельным пользовательским systemd-сервисом
`timelearner-jump12-sdk-fn85.service`. Она явно устанавливает число compile jobs в CMake, поскольку make-wrapper
проекта по умолчанию выбирает число процессоров; одного параметра
`cmake --build --parallel 4` для его настройки недостаточно.
Сборка использует существующее дерево
как CMake source, Bin как resource root и отдельный каталог runtime.
Проверяются исходная Git closure и её неизменность после сборки.
Сервис не начинает научных экспериментов автоматически. Готовность
исполнителя требует успешной сборки, проверки runtime и контрольного
воспроизведения реальных реакций модели.

## Использование существующих данных

Перед каждым расчётом выбирать нужные конфиги и данные в предоставленном
дереве, проверять их происхождение, полноту и контрольные суммы. Наличие
старого отчёта не превращает его данные в подтверждённое исходное состояние
нового опыта. Управляющие файлы нового задания должны ссылаться на точные
проверенные входы; не копировать весь Bin в ещё одно рабочее дерево.
После начала задания исходники, его входы и runtime сохраняются неизменными.

Для экспериментов также обязателен резерв 32 ГиБ. При допуске учитывать
сумму предельных новых выходов всех собственных заданий на разделе,
включая временные файлы и журналы. Проверки остатка только перед запуском
недостаточно: нужен контроль во время работы и остановка своего процесса
до достижения предела. Изменения диска посторонними приложениями отдельно
наблюдать; абсолютную гарантию против их произвольной записи не заявлять.

Машина остаётся jump host для остальных исполнителей. Первый научный
допуск — одна задача; повышать параллелизм после замера нагрузки, памяти,
дисковых выходов и работы SSH. Число логических процессоров не является
числом автоматически разрешённых тяжёлых задач. Результаты по завершении
проверять и архивировать в едином хранилище M40; в Git сохранять компактные
ссылки. Существующие данные на .12 самостоятельно не удалять.
