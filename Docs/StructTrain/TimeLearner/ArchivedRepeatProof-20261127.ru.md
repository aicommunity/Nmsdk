# Связывание завершённого повтора с архивной базовой реакцией

## Причина изменения

Координатор Branch на .14 рассчитал все8 исходных реакций и сравнил
их с первоначальным архивом: все сигналы и выходные события сохранились.
Переход к новым паттернам завершился отказом
`physical_study_source_replay_not_verified`. Общий preparer принимает
исторический replay либо современный repeat с явным `repeat-binding.json`.
Координатор передал обычную оценку с отдельным файлом сравнений;
отдельный файл не даёт preparer права считать её проверенным повтором.

Исходный отказ сохраняется. Повторно вычислять восемь реакций либо
переименовывать native-job в исторический replay нельзя. Требуется
связать уже закрытый результат с полным исходным архивом и заново
проверить содержимое обоих комплектов.

## Контракт

`prepared_physical_repeat` поддерживает binding версии2 с
`source_archive`; версия1 с `source_controls` сохраняется.
Новая операция `--bind-archive <request.json>` принимает:

```json
{
  "kind": "timelearner_closed_archive_repeat_binding",
  "schema_version": 1,
  "controls": "<полный путь к controls закрытой оценки>",
  "source_archive": {
    "kind": "timelearner_archived_physical_evaluation",
    "schema_version": 1,
    "catalog": {"path": "<путь>", "size": 1, "sha256": "<SHA-256>"},
    "bundle": {"path": "<путь>", "size": 1, "sha256": "<SHA-256>"},
    "primary": {"path": "<путь>", "size": 1, "sha256": "<SHA-256>"},
    "restoration": {"path": "<путь>", "size": 1, "sha256": "<SHA-256>"},
    "restored_root": "<полный путь к восстановленным файлам>",
    "native_prefix": "data-job/native"
  }
}
```

Это схема с заполнителями, а не готовое задание. Размеры и SHA берутся
из действительных файлов. До операции исходный primary должен быть
восстановлен штатным `portable_primary` с сохранением всех regular aliases.
Операция проверяет catalog и обе привязки объектов, hash compressed
primary, полную инвентаризацию восстановленного комплекта, квитанцию
восстановления и каждый файл. Проверяются все8 первичных наблюдений
через production-аудитор, а не сохранённый положительный verdict.

Уже вычисленная оценка отдельно проходит штатную проверку входов,
model hash, execution, полных наблюдений и закрытия принадлежащих ей
Windows-процессов. Два результата должны иметь одинаковые модель,
порог и весь протокол за исключением идентификаторов нового запуска.
Сравниваются входы, времена, все записанные каналы и выходные события.
Сравнение результата с самим собой запрещено. Допуск существующего
компаратора1e-12 не изменяется.

```text
verify immutable archive and every restored member
audit archived native baseline
audit actual closed current evaluation and process closure
compare model, threshold and complete trial protocol
recompute all eight full-response comparisons
write versioned binding and derived repeat proof
reverify binding before allowing any follow-up preparation
```

Прежние native-job, runtime и исходные наблюдения остаются своими
первичными документами; новая операция создаёт отдельное доказательство
сравнения. Она не запускает модель, не подбирает порог, не переносит
сертификат сходимости и не восстанавливает недостающие сведения
о владельцах либо библиотеках исторического процесса.

## Проверка и область применения

Первая приёмка должна использовать настоящий архив94 файлов Branch
и фактически закрытые восемь оценок .14. Требуются проверки повреждения
члена архива, неполного набора, подмены исходного binding, изменения
условий и сравнения результата с самим собой. После успешного
связывания используются существующие `prepare/run` направленных
опытов. Результаты этих проверок ещё не заявляются выполненными.

Код: `Scripts/StructTrain/TimeLearner/archived_physical_evaluation.py`
и `prepared_physical_repeat.py`. В Bin, PulseLib и отчётных каталогах
новый исполняемый launcher не добавляется. Все тяжёлые данные остаются
во внешнем архиве M40; декларации и контрольные суммы —в Git.
