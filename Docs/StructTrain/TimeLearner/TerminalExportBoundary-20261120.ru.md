# Потеря конечного пакета при повторной проверке истории

Classic `s11-terminal-n4-classic-on-elder-a1` остановлен по85200.60с.
Все процессы закрыты, OOM отсутствует. Последняя659-я проба неполна и
содержит `native_training_time_budget_exhausted`. Стек показывает вызов
`Summary` из `NativeTerminalStateFactory::Export`: проверка большой истории
повторяется после того, как пакет уже собран, но ещё не передан для записи.
Обученная модель на диске отсутствует; её нельзя заменить шаблоном Test.

## Исправление

В отдельной ветке `codex/timelearner-terminal-export-boundary` PulseLib:

1. Экспорт исторического протокола5 возвращает сводку из того же полного
   проверенного архива. Внешняя терминальная сводка использует её без
   повторного воспроизведения каждой трассы. Отдельный публичный Summary
   сохраняет независимую проверку; пользователю не предоставляется путь
   подстановки непроверенной сводки.
2. Необязательный приёмник получает проверенный пакет до последующих
   действий. Старые перегрузки API сохранены. Приёмник не меняет модель,
   не запускает Calculate/Build/Reset; после возврата проверяется граница.
3. Console пишет пакет в новый `.pending` и переименовывает без перезаписи.
   Затем формируются сводка и публикация. `execution.json` остаётся последним
   маркером завершения, наличие одной модели успех задания не означает.

Схемы, физика, CapturedPerInput, допуски, поисковая задача и бюджеты научных
заданий не меняются. Работающий Branch использует исходный runtime.

## Приёмка и ограничения

Сравнение полной общей сводки с независимым публичным Summary добавлено в
реальные сценарии Classic/Branch: протоколы4/5, N0/N1, завершение/остановка,
фактический возврат к измеренному кандидату и простые терминальные модели.
Проверяются однократная доставка и запись модели, исключение после записи,
отсутствие completion marker и запрет перезаписи конечного файла. Существующие
проверки импорта, повреждения, эпох, параметров и отклика сохраняются.

Серверная сборка и выполнение новых проверок ещё требуются. Исправление
не объявлено принятым и не объединено в develop. Старый неудачный Train
не перезапускается до проверки; его первичные данные сохраняются отдельно.
