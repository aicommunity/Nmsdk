# Classic M=4 на новых отвлекающих паттернах

На заранее объявленной сетке новых паттернов сохранённая Classic-модель
дала **TP1, FP4, FN0, TN22**. Модель и порог не изменялись по результатам
этой проверки. Повтор целевого паттерна в середине матрицы сохранил исходную
форму отклика точно. Это проверка22 правильных отклонений и четырёх ложных
ответов среди26 новых отрицательных примеров; сходимость обучения из неё
не следует.

## Условия

Применён общий [протокол новой сетки](FrozenNewFoilProtocol-20261121.ru.md):
первый импульс остаётся на месте, три межимпульсных интервала независимо
умножаются на1/2,1,3/2. Получены27 различных паттернов, включая точный
целевой. Все26 отвлекающих примеров отсутствовали в прежней калибровочной
матрице. Метка определяется точным совпадением заранее, до получения отклика.

Порядок зафиксирован; целевой пример занимает позицию13 при нумерации с0.
Перед каждой пробой выполняется сброс. Полное окно2с содержит4001 отсчёт
при2000Гц, все четыре потенциала сомы, реальные входы и выходные события.
Результат определяется событиями во всём объявленном окне, а не первым
или максимальным пиком изображения.

Фиксированный порог —0.025742023300155625. Он ранее подобран и проверен
на исходной восьмистрочной матрице; новая сетка для его изменения не
использована. Исходный Train остановился по бюджету, сертификата Exact нет.

## Сохранность модели и контроль

Revision конечного физического графа:
`ec82f91aaf806a562fcfcc29501eeabbfa0ccd0d2a93bccaf9a7190681c5cda3`.
Все4001 отсчёт каждого физического сигнала повторного target совпали с
исходным точно. После перевода в координаты фактического первого входа
разность времён не превышает2.45e−15с при заранее фиксированном допуске1e−12.
Общий максимум всей пачки не использовался вместо закреплённого импульса
при обучении; данная серия вообще не изменяет обучение.

Нативный Test занял5037.38с, внешний контроллер5054.99с. Процессы завершены
с exit0, runtime подтверждён, обе группы закрыты. Production manifest
имеет `completed/valid`, целевой контроль прошёл. Результат не получен
из незавершённого префикса.

## Сопоставление с Branch

На той же сетке [Branch-модель](FrozenNewFoilResults-20261121.ru.md) дала
TP1/FP1/FN0/TN25. Это установленное различие данных двух сохранённых моделей,
но не однофакторный опыт по топологии: различаются обученный граф, физические
параметры, порог и версии использованного SDK. Результаты не объединяются
как независимые повторения одного условия.

Оба варианта проходят пользовательское правило включения в научное описание
TP≥1 и TN≥2. Ни один не распознаёт все новые отрицательные примеры.
Зависимость от порядка здесь не исследуется заново; отдельная завершённая
проверка всех позиций target сохраняется в [отчёте перестановок](ResponseOrderResults-20261121.ru.md).
Непрерывный поток и другой ITI этой серией не проверены.
