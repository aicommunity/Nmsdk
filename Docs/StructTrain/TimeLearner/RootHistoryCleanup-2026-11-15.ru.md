## Найденные технические дефекты и проверки

- Длинный Windows-путь бокового reference-файла превысил доступный предел. Исправлен native path adapter без изменения системного реестра. Реальный отказ и безопасное продолжение воспроизведены отдельно; чужое изменение sidecar отклонено.
- Чтение sparse-индекса вне рабочего каталога Git показывало неправильные skip-worktree flags, и исходная проверка повторяла ту же ошибку. Чтение перенесено в native worktree context; исходные flags восстановлены из неизменённых index backups. В 20 локальных индексах восстановлены 1 586 669 отметок; staged contents/modes/conflict stages и рабочие файлы сохранены. Отдельная проверка отвергает изменённый после миграции staged content. На обеих Windows-машинах расхождений flags нет.
- Обновление refs создало дополнительные reflogs, отсутствовавшие в исходном снимке. Исправляются только два поля OID, без удаления записей и изменения авторов, времени или сообщений. Повторная проверка включает все refs и reflogs.
- Старые commit-graph/multi-pack-index признаны производными кэшами; перед GC они удаляются только внутри соответствующего root object store.
- В старом partial clone GC пытался получить недоступный старый promised object. Риск воспроизведён на копии. Перед переходом к полному режиму проверяется полная текущая closure; исходные config/promisor markers сохраняются отдельно. Автоматическая загрузка старой истории запрещена.

Production archive tests: 12/12 на каждой Windows-машине; прежний Linux набор 189/189 сохранён со своим source receipt. Последняя отдельная Git-репетиция включает девять сценариев, включая staged/unstaged, stash, linked worktrees, unmerged stages, detached/shallow, отказ при drift/collision и удаление только проверенного архивного кэша. Нельзя суммировать эти адресные проверки как прохождение всей научной матрицы.

Сравнение refs PulseLib/Bin/Rdk с исходной инвентаризацией: 660 сопоставимых stores, 0 изменений. Для четырёх stores исходный снимок недостаточен для такого сравнения; они не выдаются за независимо доказанный PASS. Ограничение root allowlists и сохранность gitlinks проверены отдельно.
