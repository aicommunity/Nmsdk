# Полный повтор физической DATA оценки

`Scripts/StructTrain/TimeLearner/prepared_physical_repeat.py` добавляет
отдельный путь повторного импорта уже проверенной DATA-модели на Windows.
Прежний `prepared_physical_replay` сохраняет собственный контракт источника
диагностического экспорта; новый результат не переименовывается в старый.
Шесть серверных проверок подготовки прошли; полный повтор расчёта нейроном
и его допуск в последующие исследования ещё ожидаются.

## Вход и действия

Вход — существующие управляющие условия завершённого
`prepared_physical_evaluation` с восемью полными пробами. Проверяются
фактическая модель, исходный job/envelope, контрольные суммы входов,
нативные первичные наблюдения, метрики, загруженные файлы и закрытие точных
процессов. Число TP не служит допуском: корректный отрицательный результат
тоже можно повторить. Подготовка не вызывает расчёт нейрона.

```json
{
  "kind": "timelearner_physical_repeat_preparation",
  "schema_version": 1,
  "source_controls": "C:/Projects/TimeLearnerWorker/controls/EXISTING-SOURCE",
  "run_id": "new-physical-repeat",
  "python_source": "C:/Projects/TimeLearnerWorker/ISOLATED-ACTOR",
  "python_root": "FULL_ACTOR_COMMIT_SHA"
}
```

Изменяются только идентификаторы запуска и проб. Сохраняются полный граф,
storage-образы, индивидуальные параметры, порог, паттерны, метки, порядок,
сброс, окна наблюдения и критерий оценки. Неизвестные поля, в том числе
попытка передать новый порог или reset policy, отвергаются.
Реальное выполнение использует `prepared_physical_evaluation` и его общий
lock, Windows Job Object, лимит8ГиБ/3600с и захват загруженных файлов.

```text
python -m Scripts.StructTrain.TimeLearner.prepared_physical_repeat --prepare declaration.json
python -m Scripts.StructTrain.TimeLearner.prepared_physical_repeat --run CONTROL_DIRECTORY
python -m Scripts.StructTrain.TimeLearner.prepared_physical_repeat --verify CONTROL_DIRECTORY
```

Нативный результат остаётся обычной физической оценкой в `terminal.json`.
Отдельный `repeat-terminal.json` содержит заново вычисленное сравнение
всех восьми откликов по sample ID. Сравниваются полные сигналы, временная
сетка, окна и фактические входные/выходные события относительно реального
onset, с прежним допуском10⁻¹². Пропуски или различия запрещают положительный
результат повторяемости. Сохранённых булевых признаков недостаточно.

`prepared_physical_study` принимает этот путь только при явном
`repeat-binding.json` и заново проверенном `repeat-terminal.json`.
Исходное обучение и происхождение подбора порога не переклассифицируются;
сертификат обучения, checkpoint динамики и независимая калибровка не создаются.

## Приёмка

Метаданные проверять на реальном завершённом Windows источнике через
`test_actual_physical_repeat_preparation`: граф, полные восемь проб,
неизменность всех физических условий и отказы для недопустимых факторов,
неизвестной схемы и отсутствующего источника. Эти проверки не заменяют
новый нативный повтор и сравнение всех4001 отсчётов каждой пробы.
Отдельно подтвердить допуск нового источника в frozen study без ослабления
прежнего legacy-пути. Полные этапы5/9 этим ещё не закрываются.

25.11.2026 все6 проверок выполнены на Windows через фактический завершённый
источник `classic-policy4-data3-midgap-eight-dk10`; пропусков и ошибок нет.
За246,139с проверены полный исходный граф и восемь наблюдений, точное
копирование модели, сохранение физических условий и отказы при изменении
порога, сброса, схемы либо отсутствии источника. Расчёт нейрона эти тесты
не выполняли. Дочерний процесс и его владелец закрыты; загруженные файлы
зафиксированы. Все35 членов доказательств, включая реальный подготовленный
граф, определения очередей и полный Git-пакет Python-исходников, независимо
восстановлены на M40. [Доказательства и внешний архив](../../../Reports/StructTrain/TimeLearner/Progress-20261125/Windows-physical-repeat-metadata-and-queues-external-ea18.json).

Очередь `Classic-cap8-native-repeat-after-confirmation-ea13` ждёт точного
закрытия последовательности распознавания случая8. Затем она повторяет
реальную подтверждающую восьмёрку без изменения порога, модели или проб
и сравнивает все восемь полных откликов. При корректном отрицательном
результате без кандидата порога повторяется исходная бесспайковая восьмёрка;
такой повтор не выдаётся за успешную классификацию. Производственный
адаптер последующих исследований допускается только после нового сравнения.
Нативная часть приёмки пока не выполнена.
