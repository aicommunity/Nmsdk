# Закрытая проверка порядка и ошибка оформления результата

На M40 задание `classic-count-M4-frozen-order-m40-d3` выполнило все56 новых
проб на фиксированных модели и пороге. Нативный расчёт завершился;
затем Python-контроллер упал при повторной проверке исходного файла.
Переменная `comparison`, первоначально содержащая путь, была заменена
словарём сравнения откликов. Передача этого словаря в `file_record` вызвала
`AttributeError`. Исходный `process_error` сохраняется; полный конвейер
этого запуска не объявляется успешным.

В `frozen_physical_order.py` путь и результат сравнения теперь имеют
разные имена. Работающий runtime и исходники прежнего задания не менялись.
Повторять56 физических проб для исправления оформления не требуется.

Версия2 `frozen_physical_order_audit.audit_closed_order` допускает отдельную
проверку полностью закрытых нативных данных после ошибки внешнего
контроллера. Она по-прежнему требует завершённый нативный процесс,
захват загруженного runtime, неизменные источники по исходному design,
два полных production-аудита, точный набор56 проб и сравнение каждого
отклика с соответствующим исходным контролем. Ошибка контроллера,
отсутствие его terminal и результат проверки данных записываются раздельно.
Неполный или ошибочный нативный расчёт положительную проверку не получает.

Реальная проверка новой процедуры на этих56 наблюдениях ещё не завершена.
Изменение не доказывает устойчивость к порядку, до получения измеренного
результата не добавляет научный PASS и не закрывает этап11.
