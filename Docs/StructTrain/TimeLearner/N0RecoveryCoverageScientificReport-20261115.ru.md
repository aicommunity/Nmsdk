## Следующий научный вопрос

Более дальняя длина в проверенных пяти точках не дала однозначного раннего пика. Поэтому автоматическое повышение бюджета, подстановка общего максимума пачки либо ослабление исходных допусков не следуют из опыта. В выбранных full/omission/repeat кривых видна причина отказа; ошибки назначения, позволяющей принять input1, этими примерами не обнаружено. Следующий контраст должен проверять образование раздельного отклика при корректном storage-профиле либо ограничение последовательного закрепления геометрий; математическая цель остаётся фиксированной. Повторный подбор порога на каждой неудачной terminal-модели не заменяет завершённое обучение. Полные этапы1–12 остаются частичными.
