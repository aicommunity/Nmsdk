# M40: размещение данных и подтверждённая очистка

29.10.2026. Пользователь разрешил перенос завершённых данных на отдельный диск,
а удаление ограничил подтверждёнными дублями и кэшами. Уникальные исходные трассы
не объявляются устаревшими по возрасту или отрицательному результату.

## Выполнено

Отдельный ext4 filesystem `/dev/sda` смонтирован в `/media/user/Data`;
системный — `/dev/sdb2`. Десять завершённых generated runtime перенесены из
`/home/user/timelearner-refactor/runtime-*` в
`/media/user/Data/TimeLearnerRefactor/completed-runtime`: **5 410 721 907 bytes**.
Перед переносом проверено отсутствие executable/cwd/maps/open-fd использования.
Каждый обычный файл проверен по SHA256, размеру и mode до/после копирования;
symlink targets сохранены. Только после проверки старые копии заменены
символьными ссылками. Прежние абсолютные пути доступны; настоящий перенесённый
binary успешно запускается и перечисляет tests через старый путь.

В старых архивных lanes найдены 12 групп byte-identical read-only Git pack files.
Полные SHA256 и размеры каждой копии совпали. **191 физический дубль** заменён
атомарными hardlinks к идентичному immutable pack на том же filesystem:
освобождено **18 389 184 512 allocated bytes**. Все прежние пути и содержимое
сохранены, Git history не переписана. После операции повторно проверены hashes,
inode/path связи и чтение HEAD commit objects в 75 Git directories. Это не
полный fsck каждого исторического репозитория.

После операций свободно около **7,9 GiB на `/`** и **407 GiB на Data**;
текущие цифры меняются при выполнении заданий. Уникальные scientific raw files
не удалены. Старые build-cache каталоги не удалялись целиком по одному имени.
Работающие full regression runtime/source/cache не переносились.

Полный обход размера Data был остановлен как избыточный после адресного
обнаружения дублей. Его частичная выдача не является полным census архивов.

## Следующие сборки и задания

Для новых M40 runtime/build/output использовать отдельные каталоги под
`/media/user/Data/TimeLearnerRefactor`, проверив настоящий mount и свободное место
до создания каталогов. Поддерживать исходники/конфиги/результаты через Git;
внутрисерверный storage перенос не заменяет публикацию в Git. Runtime остаётся
неизменяемым в течение задания. Нельзя перенастраивать cache/deploy работающего
задания на другой диск.

Production worker profile, disk reservation/lease, проверка объёма первичных
данных, cleanup policy и автоматический fail-closed publisher остаются частью
незавершённых этапов 2/10. Разовые maintenance операции не заменяют эти компоненты.
