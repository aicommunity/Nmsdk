# Branch N0: ограниченный поиск каждого входа

Исследовательский опыт следует за [сравнением поиска длины](N0BranchLengthScientificReport-20261115.ru.md). Оба предшествующих Train исчерпали wall budget на input2. В production-контроллере уже существует переход после исчерпания локального числа кандидатов: восстановить лучший полный вектор, заново измерить anchor/input и продолжить с очередным входом. Новая реализация этого механизма не добавляется.

Единственный изменяемый фактор — `configuration.search.maximum_candidates_per_input`:128→12. Значение12 выбрано после просмотра предыдущей траектории: она уже содержит timing-ready L27 и дискретный Ns4/5 bracket. Это post-hoc exploratory allocation, не независимая проверка и не доказательство достаточности12 кандидатов. Меньший лимит может ухудшить найденный локальный остаток и сузить исходную сетку длин; результат требуется оценивать по полному журналу, а не только числу посещённых входов.

Подготовка создаёт отдельный неизменяемый каталог. Job, condition fingerprint и index пересчитываются вместе; обратная замена12→128 должна побайтово восстановить прежний signed job. Исходная подготовка и runtime не изменяются. Перед Train нужен штатный preflight с полным readback исходного графа. Запуск на M40 через jump .12, результаты во внешнем архиве; в Git только код, постановка, метрики и проверяемые ссылки.

Измеряем: фактически исследованные входы и кандидаты; лучшее измеренное полное состояние каждого входа; повторное измерение после восстановления best; ухудшение ранее обработанных входов; исход поиска; финальную all-input проверку и actual terminal graph. Локальный inexact не становится Exact. Сертификат возможен только через свежую штатную финальную проверку исходных допусков. При незавершённом Train дальнейшие ответы остаются diagnostic-only. СерияD не возобновляется.

Ожидаемые ограничения: пять неоднозначных проб могут по-прежнему исчерпать общий invalid budget; более широкое покрытие входов не означает сходимость или разделимость. При любом исходе сохранить полные primary и графики сомы/actual inputs; не подставлять промежуточный best вместо terminal state при последующей оценке.
