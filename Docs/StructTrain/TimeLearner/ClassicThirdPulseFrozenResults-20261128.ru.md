# Распознавание Classic при изменении момента третьего импульса

## 1 Модель и условия исследования

Проверяется избирательность одного ранее настроенного нейрона Classic
к времени третьего импульса. Классификатор получает один временной
паттерн из M = 4 импульсов. При обучении каждому импульсу сопоставлялся
свой путь распространения возбуждения; настраивались длины путей и числа
синапсов. Описание обучения, его ограничений и выбора сохранённой
структуры приведено в [исходном отчёте](ClassicCount8TrainingResults-20261127.ru.md).
Обучение остановилось по ограничению времени вычисления; выполнение
всех заданных временных и амплитудных допусков не подтверждено.

В настоящем исследовании структура и параметры нейрона сохраняются.
Моменты первого, второго и четвёртого импульсов равны 0, 80 и 480 мс.
Изменяется только момент третьего импульса u:

$$p_u=(0,80,u,480)\;\text{мс}.$$

Соответствующие интервалы между импульсами равны 80, u−80 и 480−u мс.
Целевой паттерн имеет u = 240 мс. В исходном обучении и при выборе
порога он уже использовался. Семь других значений u определяют новые
отвлекающие паттерны и не участвуют в выборе порога этой серии.

Частота вычисления — 2000 Гц, шаг — 0,5 мс. Перед каждым предъявлением
сбрасывается динамика. Каждое окно содержит 2 с реакции и 4001 отсчёт.
Порог 0,026100997379370133 в условных единицах модели выбран ранее на
исходной матрице и зафиксирован до нового исследования. Обучение и
подбор порога здесь не выполняются. TP означает наличие выходного
события на цели, TN — отсутствие выхода на отвлекающем паттерне; FP
и FN обозначают соответственно ложное срабатывание и пропуск цели.
Для оценки используются полные окна и фактические выходные события.

## 2 Результаты изменения третьего импульса

| Момент третьего импульса u, мс | Роль паттерна | Выход относительно начала, мс | Оценка |
|---:|---|---|---|
| 120 | Отвлекающий | Нет | TN |
| 160 | Отвлекающий | Нет | TN |
| 200 | Отвлекающий | Нет | TN |
| 240 | Целевой | 483,5 | TP |
| 280 | Отвлекающий | Нет | TN |
| 320 | Отвлекающий | Нет | TN |
| 360 | Отвлекающий | Нет | TN |
| 400 | Отвлекающий | Нет | TN |

Получены **TP = 1, FP = 0, FN = 0, TN = 7**. Выход цели возникает
через 3,5 мс после четвёртого импульса. Ранних выходов в этой серии
нет. Таким образом, при фиксированных остальных моментах нейрон
разделил целевой паттерн и семь исследованных вариантов третьего импульса.

Перед новой матрицей на той же машине повторены восемь исходных
паттернов: TP = 1, FP = 1, FN = 0, TN = 6. Полные кривые и события
этих восьми контрольных реакций совпали с прежними при допуске 10⁻¹².
Сохранилось известное ложное срабатывание на паттерн 0/20/240/480 мс,
его выход — 481,5 мс. Успех новой матрицы получен на прежней модели
без устранения этого известного ограничения.

## 3 Сопоставление направлений изменения паттерна

Все три проверки относятся к одной сохранённой структуре и одному порогу.
В каждой строке таблицы изменяется один момент при фиксированных остальных.

| Изменяемый импульс | Исследованные моменты, мс | TP / FP / FN / TN |
|---|---|---|
| Второй | 10, 20, 40, 60, 80, 100, 120, 160, 200, 220 | 1 / 6 / 0 / 3 |
| Третий | 120, 160, 200, 240, 280, 320, 360, 400 | 1 / 0 / 0 / 7 |
| Четвёртый | 320, 360, 400, 440, 480, 520, 560, 640 | 1 / 0 / 0 / 7 |

При изменении второго импульса нейрон существенно хуже отклоняет
отвлекающие паттерны. При изменении третьего и четвёртого импульсов
на выбранных сетках ложных срабатываний нет. Это устанавливает
различие избирательности по направлениям изменения временного паттерна;
новый способ обучения в этих опытах не вводился.

Целевой положительный пример повторяется во всех трёх матрицах.
Эти повторения не являются тремя независимыми положительными примерами
или независимыми обучениями. Полученные результаты относятся к
объявленным сеткам; совместное изменение нескольких моментов и
проверка иных обучаемых целей требуют отдельных исследований.

## 4 Временные графики и проверка данных

Для всех 16 реакций, включая исходный контроль, построены 32 PNG и
32 SVG. Графики содержат потенциалы всех четырёх участков сомы,
фактические входные импульсы и выходные события. Для каждой реакции
доступны полное окно со всем диапазоном потенциала и отдельный масштаб
положительного отклика. Отрицательный начальный переход сохраняется
в полном диапазоне. Потенциал принятия решения LT этими графиками
не измеряется, поэтому по одному максимуму отдельного участка сомы
нельзя восстанавливать правило срабатывания всего нейрона.

Кэш полного отчёта на M40:
`/media/user/Data/TimeLearnerRefactor/readbacks/third-pulse16-gallery-fr671/report/index.html`.
Высокое разрешение исходных рисунков и полный SVG сохранены в архиве [2].

Независимо восстановлены все 187 первичных и 139 галерейных файлов;
повторён штатный анализ всех 16 реакций, проверены фактические входные
времена, байты загруженных библиотек и управляющие Git-комплекты.
Просмотрены все 32 PNG на восьми читаемых обзорных листах. Отдельное
открытие каждого оригинала в полном разрешении не заявляется;
SVG проверены по байтам. Полная приёмка этих данных и доказательств
независимого анализа опубликована [3].
