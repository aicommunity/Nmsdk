# Сохранение закрытого native acceptance run

`Scripts.StructTrain.TimeLearner.closed_native_collection` — конечный collector уже завершённого native запуска. Он использует существующие frozen-file roles, reservation/heartbeat, compact primary и artifact inventory. Native jobs, модели и сборки не запускаются и не восстанавливаются. Lifecycle компонентов не вызывается; научный verdict всегда null.

Вход — Git-публикуемая декларация с SHA, полная исходная readonly inventory и точные regular-file roles. Проверяются полные множества regular paths и symlinks обоих original directories, а не только сохранность заранее перечисленных файлов. Это закрывает пробел прежней неисполненной подготовки234: добавленный после freeze файл тоже запрещает успех. Source namespace проверяется целиком с исключением .git; runtime остаётся byte-equal исходному снимку.

Карта finite child intents/bindings должна точно совпадать с сохранённой декларацией и supervisor cleanup. Original outer/children и supervisor должны быть закрыты; исходный released lease проверяется через SQL read-only snapshot. Native JSON-lines supervisor сохраняется в собственном диалекте. Collector не подделывает STARTED text log и не создаёт Python-validation receipt. Native JUnit повторно читается production parser и сопоставляется с исходным фактическим inventory; failed/not-run не повышаются до PASS.

Bulk copy выполняется под собственным lease. После проверки входов до/после, остановки heartbeat и release остаются два завершающих control JSON; artifact-inventory записывается последним. Получается пять артефактов для существующего `publisher.stage_artifact_set`. Сама metadata collection не заявляет внешнюю cgroup: её owner PID/start записывается штатным reservation API. Original bound groups проверяются независимо. Исполнимый код находится в Scripts, отчётная подготовка234 не используется как launcher.

Текущий scope ограничен явным frozen snapshot,64MiB expanded capture/128MiB output и известной finite картой native детей. Это не новый supervisor, не возобновление прерванных экспериментов и не численная аттестация моделей. Обязательны worker filesystem regressions и реальная адресная проверка на original native48 (11 executed:9PASS/2FAIL;37not-run). Пока эти проверки не выполнены, реализация не принята.
