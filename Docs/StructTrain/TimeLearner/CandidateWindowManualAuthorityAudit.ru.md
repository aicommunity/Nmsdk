## Наблюдаемый source-путь

1. Публичный constructor `NativeCompositeTrainingAttempt(owner, protocol, limits, declaration, actualTime, Wall())` разрешён для native-ready owner вне активного service. `Bind` проверяет `NativeTrainingOwned`, actual declaration, readiness, отсутствие recognition/edit failure и service state != CapturingReferences/Searching. Он не регистрирует manual actor в `NativeTrainingService::composite`. Это отдельный явный API; пользователь кода сам вызывает actor BeforeTick/AfterTick вокруг обычного Rdk scheduler.
2. `NativeCompositeTrainingAttempt.cpp:41–54`: сохраняется owner lifecycle observation, private actor generation и начальный ModelEpoch. `requireOwnerControl` требует `service.composite.get()==this` только при state CapturingReferences/Searching. При Idle и Finished эта lambda ничего не требует.
3. Actor выпускает закрытое candidate/final measurement, удерживая private lease и exact immutable identity. `CompositeTrainingMeasurement.cpp:59` проверяет lease, protocol/run/trial/input/revision/epoch/purpose/channel/source/family. Затем closed `requireLiveModel` (`NativeCompositeTrainingAttempt.cpp:407`) проверяет actual clock/Need, actual graph instances, current semantic revision, source/storage/C0 и candidate witness. Для закрытого measurement не требуется, чтобы он оставался ПОСЛЕДНЕЙ группой actor: это допускает последующие собственные группы без физического изменения.
4. `NNeuronTimeLearner.cpp:4420` / Branch:5199 `BeginNativeTraining` вызывают `NativeProbeControl.ResetControl()`, затем service ResetControl либо InvalidateTarget. В этом пути нет owner Reset/Default/Build/Init/UnInit. Service ResetControl (`NativeTrainingService.cpp:378`) отзывает только свой сохранённый `composite`, если такой есть. Отдельный ранее созданный manual actor там неизвестен.
5. Новая Service5 attempt получает свой actor, service semantic attempt/session, `compositeGeneration`, новые группы и собственный family. Пока service активен, old manual actor блокируется state/pointer-проверкой. Service после Finish сохраняет state Finished. Конкретные learners (`Classic:7560`, `Branch:8735`) снимают Need автоматически лишь при CalculateMode0; в mode1 Need=true допустим после успеха.
6. После Finished прежний `requireOwnerControl` снова ничего не проверяет. Manual actor остаётся alive/not cancelled; owner lifecycle не менялся. Если actual source/graph/C0/instances прежние, clocks монотонны и изначально объявленные лимиты ещё действуют, source-путь closed Consume не сравнивает ownership generation/session с фактом чужого Begin. Поэтому повторное live admission старой попытки представляется достижимым ПО ИСХОДНИКАМ. Его фактическое выполнение и точный результат пока не измерены.

## Уже существующие поколения не равнозначны takeover-generation

| Механизм | Что защищает в Pulse800 | Чего НЕ утверждает |
|---|---|---|
| Rdk owner observation | owner lifecycle/destruction до dereference | Изменение logical service ownership без owner lifecycle |
| Global private actor `AttemptGeneration` / liveAttemptBinding | Уникальный actor/refresh lease, не portable authority | Автоматический отзыв всех иных manual actors того же owner |
| Service `SessionAttempt`, `compositeGeneration`, actor pointer | Его собственные callbacks, reentry и replacement | Локальные leases другого actor после перехода service в Finished |
| Executor `controlGeneration` | `Queue` и `ResetControl` увеличивают; actor сохраняет после своего Queue; take/cancel проверяют exact generation+run/trial | Closed Consume не сравнивает этот счётчик; он меняется также при ЗАКОННЫХ следующих своих N+2 raw-пробах |
| Epoch/current semantic revision | Actual physics/edit/candidate consistency | Новый Begin на том же неизменном graph может не изменить ни epoch, ни revision |
| Family/proof IDs | Неизменяемое исходное семейство/воспроизводимое measured DATA | Текущий владелец права публиковать НОВЫЙ accepted input |

Публичного getter executor generation у concrete learners нет. Fixtures не вводят такой getter, не угадывают его значение и не сериализуют адреса/callbacks как authority. Они проверяют фактически доступные счётчики, состояние и native данные.

## Отдельные понятия и ожидаемый control-контракт

Смена владельца не должна уничтожать историческую корректность уже записанных full/omit/repeat waveform, frozen proposal, source/model binding и semantic proof. Это portable DATA, которое можно заново прочитать после чужого сеанса. Но предлагаемая здесь regression-постановка требует: **чужой явный Begin, забравший тот же executor, навсегда отзывает право старой manual attempt принять НОВЫЙ final input; Finished и Need=true это право не восстанавливают**. Expected result fixtures — InvalidObservation, zero accepted inputs, no new certificate. Это явный ожидаемый ownership-контракт, а не уже доказанная гарантия Pulse800 и не новый физический критерий пика.

Проверка `currentExecutorGeneration==generationLastRaw` как готовое исправление НЕ предлагается: та же attempt вправе выполнить следующую собственную группу. Новое ownership generation должно отличаться от raw-probe generation и учитывать штатные owned edits/refresh. Production решение остаётся за отдельным review после actual reproducer. Автоматическая проверка любого `Finished && pointer != this` также не исследована здесь для всех допустимых manual-after-completed-service входов.

## Четыре адресных native fixture

`NativeCandidateWindowManualAuthority.*` используют production owner/storage/source/selector/replay/final APIs, N2/2000Hz, N0, C-trim Off, один обычный scheduler. `.2` sync — технический plumbing control, не научное подтверждение default `.02` сходимости. AmpAbs1e−5/min1e−6 не меняются.

- **ClassicForeignBeginThenFinishedDoesNotReviveOldManualConsume**, **BranchForeignBeginThenFinishedDoesNotReviveOldManualConsume**: allN refs старого manual actor → закрытая и armed final-input0 группа → сохранение actor/measurement → настоящий чужой `owner.BeginNativeTraining(plan,true)` → Finished/Exact в CalculateMode1/Need=true без AppliedEdits → попытка старого Consume. Assert actual neuron/dataset/generator pointer equality, source semantic model equality, actual neuron revision equality, owner observation still-current, monotonic advanced native time и отсутствие deadline-отказа как объяснения. На Pulse800 source audit прогнозирует отсутствие требуемого отзыва: это deliberately expected-red hypothesis controls, НЕ результаты выполненного теста.
- **ClassicOwnNextGroupsKeepCurrentClosedMeasurementUsable**, **BranchOwnNextGroupsKeepCurrentClosedMeasurementUsable**: вместо чужого Begin выполняется дополнительная собственная search N+2 группа, меняющая raw generations, но сохраняющая actual graph/source. Старый pending input0 затем принимается, fresh final-input1 даёт обычный cert3. Этот positive защищает от слишком широкого запрета по raw generation или просто «measurement не последнее».

Group model/wall budgets явно заранее расширены до **30 native seconds / 3600 wall seconds**, attempt остаётся **120 / 7200**. Это НЕ изменение scientific tolerance и не fake time. Иначе обычный short group deadline мог бы скрыть ownership hole. Actual clocks берутся из environment/steady clock, owner/model не откатываются, тест не двигает clock вручную после исходного штатного fixture setup. После fallible DATA replay непосредственно перед Consume assert проверяет оба actual group elapsed против сохранённых actual group caps. Дополнительно real timestamps, взятые ДО actor construction, дают консервативную верхнюю границу обоих attempt elapsed; она тоже меньше attempt caps. C0 state остаётся фактически отсутствующим, а сохранённый frozen proposal полностью равен декодированному как JSON object (QJsonObject equality), с исходной candidate revision/binding. Потребление само повторно вызывает production fresh guards.

Existing source controls для разрешённых owned edits остаются без изменений: `NativeCandidateWindowService.Classic/BranchOwnedGrowthMeasuresPeakBeyondInitialReferenceWindow`, `...Classic/BranchWarmAfterOwnedGrowthKeepsOriginalTargetsAndHistory`, а также STEP2 `NativeCandidateWindowFactory.Classic/BranchGrowthKeepsImmutableP0AndUsesMovedFrameWindow`. Они не объявлены пройденными в этом подэтапе и должны остаться отдельными controls будущего исправления.

## Primary и границы доказательств

При `TIMELEARNER_COMPOSITE_OUTPUT` старые refs/pending group и own-next-group/final сохраняют реальные N+2 packets/CSV всех source+soma channels, actual proposal/context/selection, initial model/source и текущий after-model. Перед вмешательством сохраняется self-contained production actor archive2; ПОСЛЕ вмешательства strict production decoder повторно читает этот же immutable archive. Decode success не становится live admission token.

Foreign service отдельно сохраняет свой полный production service archive2, все primary и actual cert3/boundary. `live-authority-observation.json` записывается ДО expected-negative assertions и содержит actual old group/proof/family, current status/accepted count, реальные clocks/limits, revisions, lifecycle/Need и явное `executor_control_generation_publicly_observed=false`. Поэтому возможный красный результат не прячет waveform или статус. Package6/summary7/CLI и independent numerical Python replay здесь не создаются.

Новый четырёхэлементный inventory отдельный; historical source-preparation470 не переписывается и не объявляется accepted474. Прежде чем включать эти controls в server gate, root должен подтвердить ожидаемый ownership-контракт и production correction scope. Никаких production правок, broad `4||5` replacements или исправлений гипотезы наугад нет.
