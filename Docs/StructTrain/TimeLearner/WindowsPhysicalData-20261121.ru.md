## 2 Экспорт и повторное измерение

Подготовка полного источника завершилась за58.43с. Удалены только пробелы JSON
вне строк; исходные поля и история сохранены. Native export завершился за307.76с,
exit0, с подтверждённым runtime, закрытой группой и нативным import/roundtrip.
DATA занимает11334968байт, его SHA:
`924c8f689ce84eecec1d4f0deb21ca34148703dd9e204f7bc5a80717afcc5c18`.
Revision модели сохранён; сертификат обучения и checkpoint не передаются.

`prepared_physical_replay.py` отдельно проверяет отклики после импорта DATA.
Он использует production `validate_job`, `audit_execution` и scorer, проверяет
полное исходное множество sample ID, неизменный протокол, модель и порог.
При новых run/trial ID сохраняется остальная спецификация каждой пробы.
Входные/спайковые события и все отсчёты сопоставляются с исходными наблюдениями.
Разность свыше1e−12 или изменение событий означает невалидный перенос реакции;
сами валидные наблюдения и метрики остаются доступны для разбора.

Повтор ещё должен завершиться отдельным реальным прогоном. Успешный roundtrip
графа не подменяет проверку отклика. Все тяжёлые данные остаются вне Git.

После закрытия export ОС уже повторно использовала его PID19928. Новые creation
identity и executable отличаются. Этот процесс не принадлежит завершённому
заданию; его нельзя считать работающим export или останавливать по номеру PID.

## 3 Условие следующего сравнения N0/N1

В исходном N1 search bounds для всех входов `maximum_synapses=1`, а у первых
трёх разрешён поиск Rs от1МОм до86МОм с дополнительной native проверкой
допустимости физики. Эти bounds корректны для данного N1; простое переключение
`model.normalization` в N0 оставило бы Ns неподвижным.

Для N0 требуется отдельная явная декларация: начальная физика и образы те же,
у обучаемых входов разрешён целочисленный диапазон Ns, Rs фиксирован на исходном
значении86МОм, опорный вход сохраняет Ns1/Rs86МОм/L1. Верхняя граница Ns сама
по себе не разрешает физически недопустимое состояние: проверка суммарных
проводимостей и интегратора остаётся обязательной. Это различие разрешённых
управлений двух алгоритмов, а не доказательство разных результатов по одному
флагу. Новый N0 Train пока не запущен.
