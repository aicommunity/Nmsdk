# Проверка composite206: состояние 08.11.2026

Это техническая приёмка service/archive, а не научная классификация и не
завершение этапов 5–8. Принятый M40 core143 остаётся отдельным результатом.

## Elder A1: сохранённый отрицательный результат

Исходники Root `d433acf6ed250e7ed5da781970b3963a51c56a26`, Pulse
`f925e37247bb987980fce80da47831a1c31d04c9`. Сборка и линковка завершены;
из 206 объявленных случаев выполнены 112: 111 успешных, один неуспешный,
94 не запускались. Архивные 23 проверки ещё не выполнялись; шесть новых
native-архивов не получены.

`NativeCompositeTraining/ClassicRawProbeCannotEnterCompositeProtocol`
ожидал исключение от `EncodeVerificationProtocol` на строке 238.
Однако protocol4 уже имеет явный portable codec. Сериализация декларации
сама по себе не предоставляет право принимать raw observations.
Соседние запреты Arm/Consume/Capture не дали ошибок.

Отрицательная попытка не переоценивается как успешная. Evidence commit:
`9b9a38f1a5d8842ada5e167d9bdbf33bd24b6381`.
[Независимая проверка](ElderCompositeArchiveA1NegativeVerification.json)
сверила 810 членов архива, 3687 файлов исходников с Git, JUnit и закрытие
всех 25 групп процессов. Резервирование освобождено; исходная диагностика
failed-unit сохранена. Ранее принятые runtime и 327 ресурсов не изменились.

## Исправленная постановка A2

Root-only commit `22af717465cbfe110a923f927d31406337a2c3a8` от точного
родителя d433; Pulse f925 не меняется. Вместо устаревшего ожидания исключения
проверяются roundtrip protocol4 и отказ при удалённом composite contract
или неверной маркировке schema3. Запреты raw admission и отсутствие
выданных проб/сертификата сохранены. Требуется новая полная проверка 206
случаев с отдельными request, runtime и журналами; результата A2 пока нет.
Metadata-only продолжение `540179d70ddf3764334eb6bb59b7fef691054eee`
исправляет hash исходника в трёх inventory: используется точный Git blob,
а не локальная CRLF-копия. Код и набор из 206 случаев не меняются.

Перед A2 выполнено отдельное обслуживание закрытого A1 runtime: удалены
только семь производных статических библиотек `Lib.CMake/*.a`, 87 737 788 байт.
Исходный runtime manifest остаётся историческим снимком до удаления;
новый manifest явно фиксирует эти семь отсутствующих файлов.
ELF, INI, результаты, исходники, общий build cache и три других runtime
сохранены. Свободное место после обслуживания — 1 680 998 400 байт.
Evidence `e86b5081515efa75a4195c264866be23e8a79f56` и
[независимая проверка](ElderCompositeArchiveA1StaticRetirementVerification.json)
содержат точные пути, хеши и журнал удаления. Порог допуска A2 по месту
остаётся 1,5 GiB и проверяется заново непосредственно перед запуском.

## Windows: сборка не принята из-за завершения процессов

A2 на .14 собрал Console и StorageComponents: основной процесс вернул 0.
Но production guard обнаружил остававшийся дочерний процесс PID 15228
и закрыл собственную группу. Его назначение не установлено; предположение
о вспомогательном процессе компилятора не считается фактом.
Новые native-тесты на Windows не запускались, runtime не принят.
Ранее принятые три runtime сохранены.

Evidence `2483362581205cffacd487888d6466730110f051` опубликован отдельно.
[Независимая проверка метаданных](WindowsCompositeA2IndependentVerification.json)
сверила все 58 членов архива, восемь репозиториев source closure,
неизменность трёх защищённых runtime и сохранённый снимок закрытой группы.
89 строк реальной компиляции и две линковки подтверждают выполненную сборку;
они не отменяют отказ production guard.

Следующая отдельная диагностика должна записать идентичность процессов
своей группы, пока они живы: PID, время создания, путь и hash executable.
Проверка закрытия группы сохраняется. Успешная диагностика одного
перекомпилированного объекта не заменит приёмку полной сборки.
