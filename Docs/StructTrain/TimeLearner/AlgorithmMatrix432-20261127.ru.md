# Проверка поиска и управления TimeLearner на .4

## 1 Цель и границы

Для текущего кандидата объявлена расширенная проверка алгоритмов выбора
длины, числа синапсов и сопротивления, управления измерениями и подготовки
распознавания. Она относится к этапам4,6–8 утверждённого плана. Результат
исполнения432 случаев ещё не принят. Прохождение C++-проверок само по себе
не устанавливает качество классификации или выполнение всех допусков
обучения на паттерне из четырёх импульсов.

Проверяется существующий SDK без изменения работающих опытов Classic на
M40 и Branch на .14. В обозначениях исходного программного интерфейса
`N0` означает настройку числа синапсов, `N1` — сопротивления. Эти поля
не являются названиями топологий Classic и Branch. Число импульсов в
паттерне в описании метода обозначается M.

## 4 Что остаётся за пределами проверки

Отдельные тесты PostTune и финализации требуют архивных входов, явно
подключаемых через переменные окружения. Они не включены в эту432;
их нельзя считать пройденными или заменить пропусками. Открыты полная
матрица режимов и профилей, независимая проверка первичных данных новой
попытки, сопоставление с приёмками исходного плана и интеграция в develop.
Проверки `NativeImageRestSnapshot` в эту выборку также не входят:
[три прежних отказа сравнения архивов](NativeImageRestDiagnostic-20261127.ru.md)
сохранены отдельно. Совпадение18 пар временных откликов не устранило
различие формы одного поля состояния и не отменило этих отказов.

Архив M40 на .4 пока не смонтирован. Управляющие файлы и Git bundle уже
переданы через jump host и сохранены во внешнем хранилище; после закрытия
расчёта тем же способом публикуются первичные выходы. Ошибка последующей
архивации не является основанием повторять C++-расчёт: сохранённый полный
комплект нужно проверить и опубликовать отдельно, сохранив исходный отказ.
