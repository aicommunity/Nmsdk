# Отчёт о поиске: сохранённая граница schema9

При разборе закрытого Branch Train fr766 обнаружен отказ Python-модуля
`training_search_report.analyze_search_history`: `dict() got multiple values
for keyword argument 'native_execution_attested'`. Ошибка возникла после
проверки первичных данных, при сборке результата отчёта. Сам Train и его
сохранённое состояние не менялись. Отказ read-only задания fr787 сохранён
в `/home/user/Nmsdk-experiments/branch-Rs-primary-analysis-fr787/failure.json`.

Проекция terminal summary9 уже содержит отрицательное утверждение
`native_execution_attested=False`. Обёртка дополнительно передавала его
явным аргументом вместе с развёрнутой проекцией. Для summary8 этого
совпадения не было, поэтому прежний корпус не обнаруживал отказ.

Исправление собирает это поле один раз для обеих версий. Его значение
остаётся False: проверка DATA не является новым наблюдением исполнения
нативного процесса. Проверки hashes, полной первичной модели, terminal
journal, измерений и соответствия manifest не ослабляются. `budget_exhausted`
не превращается в завершённое обучение, прежние измерения не привязываются
к новой эпохе после восстановления графа.

Проверка включает два уровня: адресную сборку отчёта schema8/schema9 на
связанных файлами unit-данных и настоящий production CLI на всех первичных
данных Branch fr766. Второй уровень явно требует исходный summary9536697
байт, SHA256 `18ee1a4fc4369f16d44c8a90df1a1a03adf555320596d7ea9f4ef8c25f909571`.
Mock-аудит первого уровня не выдаётся за интеграционное доказательство.
На .4 прошли23/23 проверки за140,834с, без ошибок и пропусков, включая
полный production CLI на исходном summary9 и всех его первичных данных.
Проверялся корень `dde74327a652d6efaed64427f42cca4bcd12fce9`.
[Внешний первичный комплект](../../../Reports/StructTrain/TimeLearner/Progress-20261128/Worker4-Branch-Rs-cold-primary-analysis-fr799.archive.json)
содержит Train, исходный отказ, полный новый отчёт, результаты23 проверок,
Git-комплекты управления и использованные библиотеки. Повторного Train
и нового native-расчёта ради исправления отчёта не было.

Сам научный исход и следующая проверка бюджета описаны в
[разборе Branch](BranchResistanceBudget8-20261128.ru.md). Независимая
повторная проверка восстановленного архива
[завершена](../../../Reports/StructTrain/TimeLearner/Progress-20261128/Branch-Rs-native12-independent-finalized-fr815.archive.json):
читатель на .12 повторил полный production-аудит и получил тот же отчёт.
Различаются только явно сохранённые пути source_manifest/source_summary
нового восстановленного дерева; hashes, размеры и все содержательные
поля совпали. Учёт model revision/epoch и отрицательные утверждения
об аттестации остались прежними. Ошибка завершающего file_record через
CIFS сохранена; публикация доказательств проверена на native FS M40.
