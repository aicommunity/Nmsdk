MiniPC .8 — `D:/Projects/TimeLearnerWorker`. Исходники, runtime, управляющие
файлы, задания, входные данные, результаты и локальные кэши этого
исполнителя размещаются на D. Для запуска используется существующий
`C:/Python313/python.exe`; отдельная установка проекта на C не создаётся.

## Явный рабочий корень новых заданий

В прежних Python-запускателях обнаружена привязка к
`C:/Projects/TimeLearnerWorker`. Для работы на D добавлен явно заданный
`worker_root` с отдельными версиями документов:

| Документ | Прежнее поведение | Новое объявление |
|---|---|---|
| План prepared_physical_evaluation | Версии 1 и 2, прежний корень C | Версия 3, обязательные worker_root и execution_limits |
| Подготовка prepared_physical_repeat | Версия 1, прежний корень C | Версия 2, обязательный worker_root, ограничения сохраняются из исходной оценки |
| Подготовка prepared_physical_study | Версии 1 и 2, прежний корень C | Версия 3, обязательные worker_root и execution_limits |
| План DATA-преобразования или порогового кандидата prepared_physical_export | Версия 1, прежний корень C на Windows | Версия 2, обязательный worker_root; прежние ограничения памяти и времени |
| Сохранённая спецификация оценки или исследования | Версия 1, прежний корень C | Версия 2 с сохранённым worker_root |

Новый корень должен быть существующим абсолютным локальным каталогом.
UNC, корень диска, относительный путь, переход через `..`, symlink и junction
отклоняются. Старое объявление не может молча переопределить корень.
Исходная оценка, её повтор и последующее исследование остаются в одном
объявленном дереве; выходы и блокировка привязаны к нему.

Новая спецификация исследования передаёт большую модель через
checked-file-source-v1 с проверкой исходного файла и разрешённого задания.
Прежние сохранённые спецификации продолжают использовать свой исходный
формат. Это изменение размещения и передачи данных не меняет нейрон,
порог, входной паттерн или математическую цель обучения.

## Следующие проверки

Проверить адресные сценарии владения каталогом на настоящей Windows .8,
затем импортировать сохранённую модель нейрона и получить восемь полных
реакций через штатный запускатель. Сравнить структуру, параметры, фактические
импульсы, кривые и выходные события с проверенными исходными наблюдениями.
После успешного повторения выполнить исходный случай направленного
исследования четвёртого импульса, затем остальные объявленные случаи.

На настоящей .8 прошли восемь адресных проверок рабочего корня без
пропусков, включая реальный junction. Полный комплект подготовки из 133
файлов, исходные 54 члена переданного комплекта и развёрнутые 50 файлов
сохранены внешне и независимо восстановлены на M40.

Первая попытка оценки сохранённой Branch-модели a71ae527 завершилась
до первой реакции: native exit2, physical_model_native_conversion_mismatch.
Загруженные 47 модулей зарегистрированы, все процессы закрыты. Проверка
сравнения нативно восстановленного DATA2 со входным документом обнаружила
несовпадение. Его точный состав и причина ещё не установлены. Возможные
различия версии программы, представления storage-образов и платформы
следует проверить по отдельному результату штатного DATA1→DATA2 преобразования;
данный отказ сам по себе не выбирает одну из этих причин.

Исходный DATA3 не изменяется, сравнение документов и проверки runtime
сохраняются. Диагностический новый DATA2 должен иметь собственную запись
происхождения; его нельзя подставить вместо старой модели и назвать
воспроизведением. До проверки полных реакций научный допуск .8 остаётся
незавершённым. Новый эксперимент по четвёртому импульсу не запускался.

Эта запись не заявляет новый научный результат, допуск всей матрицы
или завершение этапов 2, 10 и 11.
