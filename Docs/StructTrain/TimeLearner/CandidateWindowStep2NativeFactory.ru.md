# STEP2: source preparation native5 reference/candidate factories

Это отдельный source-подэтап после механического `d6888c9` и declaration/frame/data/readback кода. Runtime acceptance отсутствует. Исторические pure40 и callback248 receipts не заменяют будущий SDK/native gate; callback baseline248 и mechanical A/B требуют своих проверок. Train5, service/CLI/defaults не активируются.

`NativeCompositeTrainingAttempt` имеет отдельную constructor overload5 с явным attempt ID и primary-byte cap. Initial reference groups сохраняют actual plateau indices, original P0/C0, source/proof/family. Private staged seeds не видны search/final. После полного `CapturedReferences` actor повторно проверяет каждый live token и только затем возвращает opaque complete ReferenceSet. Owner Reset/Default, Need=false и rebuild старого графа закрывают этот переход; штатные neuron/dataset Reset внутри N+2 допустимы.

Candidate proposal вычисляется из real actual parameter/bank/receiver/source readback и complete refs. Общий strict replay вызывается до первой queue и после complete closure. Actual native frame endpoints берутся из сохранённых samples; никакой прогноз не считается пиком. Старые Bounded/Final5 typed/raw guards сохраняются, поэтому этот подэтап не разрешает получить Train certificate через старый API. Archive2 portable reference import/warm reuse остаётся следующим обязательным подэтапом.

При `TIMELEARNER_COMPOSITE_OUTPUT` сохраняются `classic-native-window5/*` / `branch-native-window5/*`: actual `raw-*.csv` со всеми somas и stimulus, raw prepared/spec/native packets, `matched-witness.json` только для полностью закрытой группы, `window5-boundary.json` с полной protocol/source/binding/proposal/spec/selection, actual after-model и boundary math. Boundary fixture explicitly `training_certificate_eligible=false`; это не archive2 и не portable reference authority. Future independent replay должен использовать primary, а не ожидания assertions.

Полный контракт — `PulseLib/Docs/TimeLearner/CandidateWindowTraining-Step2Contract.ru.md`.
