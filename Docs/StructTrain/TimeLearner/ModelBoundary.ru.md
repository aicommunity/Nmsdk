# Явные stimulus-порты физической модели

Статус: реализация в отдельной ветке refactor/timelearner-s05-boundary-ports,
серверная приёмка продолжается. Это часть этапа 5; ControllerVersion=2 и новый
контур обучения данным изменением не вводятся.

Замкнутый ModelIdentity/ModelArchive версии 1 сохраняет прежний формат и hash.
Для модели с явно объявленными внешними источниками используется schema_version=2
(соответственно semantic identity и native archive), с тем же canonical encoder.
Номер схемы данных не является версией алгоритма обучения.

ModelBoundarySources сопоставляет живой UIProperty выхода с постоянным ID порта.
В архив попадают ID, matrix_binary64 type, полный target path и индекс каждого
слота. Адрес указателя, имя внешнего генератора и текущее значение его выхода
не входят в identity физического нейрона. Это позволяет назначить независимый
Test-источник и проверять неизменность модели при разных предъявлениях.
Паттерны, реальные timestamps, параметры генератора и порядок/ITI относятся к
ProbeSpec/RunManifest; одинаковый model hash не означает одинаковых условий пробы.

Текущий API поддерживает штатные matrix<double> stimulus-выходы. Null, пустой или
дублирующийся ID, внутренний источник, неиспользованное объявление, другой тип и
необъявленная внешняя связь делают identity невалидной. Scalar/multirate и
ExternalDataSource/AttachTo здесь не получают молчаливую поддержку.

## Штатное подключение

Экспорт проверяет оригинальный граф без изменения его параметров или dynamics.
Rehearsal строит отдельный экземпляр и восстанавливает declared slots. Native
Build может связать вход с default-источником профиля; поэтому для каждого входа,
имеющего порт, сохраняется и применяется полный список слотов из identity,
включая внутренние источники в смешанном входе. Другие входы не исправляются
overlay: их native Load/Build проверяет полное финальное сравнение графа.

Применение использует native Disconnect/Connect, а не постоянные SetPointer
поверх структурной настройки нейрона. Источники должны быть Init/Ready до этой
операции. Их Build проходит штатный fast path; вложенного Calculate нет.
Подключения меняются до первого импульса следующей пробы. Динамические значения
источников и порог не подгоняются при каждом тике.

Временная rehearsal-модель и незавершённый импорт освобождают native listeners
перед возвратом в pool. Владелец возвращённой импортированной модели отвечает за
длительность жизни источников: перед возвратом модели/источников нужно вызвать
native BreakLinks, затем обычный Free/ReturnObject. Прямой SetPointer без
штатного учёта связей не заменяет этот lifecycle.

При импорте множество supplied IDs/types должно точно совпасть с архивом.
Проверяются slots, конечные реальные связи, morphology/параметры/кэши и semantic
hash. Образы классов остаются замкнутыми и неизменяемыми: stimulus-порты
принадлежат экземпляру физической модели, а не общему storage prototype.

## Оставшаяся работа

Native fixtures проверяют независимый внешний источник, 2000/20000 Гц и fresh
process import, но ещё не заменяют реальный learner adapter и полный Train→Test.
Нужно захватить targets/references/certificates/conversion/calibration у их
владельцев, связать implementation_id с runtime provenance и замкнуть общий
ProbeSpec/Observation/frozen runner. Контроллерный checkpoint и общая транзакция
регистрации образов остаются отдельными незавершёнными требованиями.
