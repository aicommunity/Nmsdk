Все восемь полных реакций повторно проверены из отдельного восстановления

финальной проверки сходимости всех входов нет.

## Сопоставимые условия

Исходный SDK обоих опытов: корень
`49c4f08cc4cbc4675ce3e6dba160b931ab18d556`, PulseLib
`f52713ce3d807c9a0abd8655caff82daba400519`. Использованы один сервер,
одинаковый холодный граф `5c97864335ce7cc91a3bcd071514e2bceb8b88e38aa122e055d8306881450964`,
M=4, частота 2000 Гц, нормализация числом синапсов, CapturedPerInput,
закреплённые импульсы и одинаковые объявленные бюджеты. Абсолютный
амплитудный допуск равен 10⁻⁵, временной — 0,02 с.

Меняется `maximum_n0_length_proposals`: 0 отключает дополнительное
ограниченное исследование соседних длин после целочисленного уточнения,
4 разрешает четыре таких предложения в пределах общего бюджета.
Это не переключение между обычной и ветвящейся топологиями.
