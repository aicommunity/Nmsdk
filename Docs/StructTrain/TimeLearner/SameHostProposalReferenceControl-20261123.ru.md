# Контроль начальных условий поиска на Elder

Техническая сверка условий для сравнения Classic до и после исправления
порядка резервирования предложений числа синапсов. Она связывает версии
реализации, фактическую сборку и исходные измерения нового холодного опыта.

## 1 Подтверждённый допуск и начало опыта

На Elder завершены114 из114 объявленных интеграционных SDK-проверок,
без отказов и пропусков. Полный JUnit независимо прочитан, три группы
процессов закрыты. Это адресный набор регрессий изменения N0-поиска;
вся обязательная физическая и режимная матрица плана остаётся шире.

[Полный исходный JUnit](../../../Reports/StructTrain/TimeLearner/N0ProposalReservation-20261123/Elder-SDK114-original-text-ae8/native.xml),
[объявленный состав](../../../Reports/StructTrain/TimeLearner/N0ProposalReservation-20261123/Elder-SDK114-original-text-ae8/cohort.json),
[точный runtime](../../../Reports/StructTrain/TimeLearner/N0ProposalReservation-20261123/Elder-SDK114-original-text-ae8/case-runtime.json).
В Git сохранены эти малые текстовые доказательства; полный тяжёлый SDK-пакет
Elder ещё не архивирован, исходные закрытые файлы сохраняются на сервере.

После допуска штатно начался `classic-n0-proposal-cold-elder-ab3`.
Две реальные предварительные проверки подтвердили прежний холодный граф
44 узла и контроль45 узлов с Nₛ=2. Native PID1112225 и его start identity
проверены по cgroup; на12:31 UTC записаны72 завершённые сырые пробы.
Итог этого обучения пока не получен.

## 4 Следующий этап и пределы вывода

Очередь `classic-n0-proposal-full-primary-audit-elder-ae4` подтверждена ядром.
Она привязана к конкретным native/controller groups и начнёт полный аудит
истории только после их закрытия и освобождения слота. Controls commit
`364d9ce59512df91651c08fb023ba9614293e266` и Git bundle сохранены в архиве M40.

Равенство исходных реакций подтверждает сопоставимость этого контрольного
этапа. Итоговые длины, числа синапсов, остатки, причины остановки и
классификация ещё требуют измерения и аудита. Нагрузка ОС не фиксирована;
число обработанных кандидатов при том же wall-бюджете нельзя само по себе
выдавать за чистый коэффициент ускорения. Случайный повтор не объявлен.

После аудита конечной модели следуют реальный подбор/проверка порога,
замороженные реакции всей восьмёрки и временные графики всех сом с
фактическими входами в читаемом масштабе. Настоящая сверка условий
не создаёт сертификат Exact и не заменяет эти результаты.
