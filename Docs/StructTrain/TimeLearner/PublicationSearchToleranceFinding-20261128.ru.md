# Относительный амплитудный допуск в иллюстрациях поиска

При подготовке шестой редакции найден открытый дефект генератора
`Scripts/StructTrain/TimeLearner/publications/plot_algorithm_measurements.py`.
Для поисковых рисунков он берёт ширину амплитудной полосы только из
`amplitude_absolute`, хотя действующий критерий имеет вид
`amplitude_absolute + amplitude_relative * abs(reference_raw_potential)`.

Сверены код генератора, `native_evidence.py` и
`publications/plot_measured_count_bracket.py`. Последние два используют
собственный исходный уровень соответствующего пути. Это подтверждённое
source finding, ещё без серверного воспроизведения отрицательного случая.

Для двух повторно используемых контрольных историй N0/N1 относительный
допуск равен0. Их нынешняя полоса10⁻⁵ соответствует декларации; новые
неверные выводы об этих двух историях не обнаружены. Рисунки не формируют
научный verdict, но неверная полоса в другом режиме способна исказить
визуальное объяснение выполнения допуска.

До общей приёмки анализа/отчётов требуется:

1. Получать эффективный допуск именно для настраиваемого пути и
   связывать его с правильным исходным уровнем по контракту источника.
   Не угадывать ID пути по позиции произвольного JSON-списка.
2. Сохранять абсолютную и относительную части, ID и значение reference,
   эффективный допуск в manifest рисунка. Отсутствующую привязку при
   ненулевой относительной части отклонять как недостаточный источник.
3. Явно обрабатывать нулевой допуск при выборе масштаба увеличения:
   масштаб рисунка не создаёт ненулевой полосы принятия результата.
4. Выполнить адресную серверную проверку на реальном сохранённом
   источнике: нулевая/ненулевая относительная часть, разные собственные
   уровни, перестановка записей reference, отсутствующий/дублирующийся
   ID, NaN/Inf и нулевой полный допуск. Проверить действительный renderer,
   его изображение и metadata, сохранив прежние рисунки.

Подготовлен source-кандидат: версия2 спецификации рисунков требует
первичные JSON/CSV reference-пробы. Штатный аудитор проверяет их;
индекс пути получается по связи окна с ID фактического стимула, а
reference ищется по ID. Проверяются контекст, revision и исходный
измеренный максимум. Версия1 без пробы разрешена только при относительной
части0 и сохраняет привязку как unknown. Полная формула допуска и
привязка сохраняются в manifest. Нулевой допуск не рисует положительную
полосу; отдельный масштаб отображения не изменяет критерий.

Серверные отрицательные проверки и визуальная приёмка кандидата ещё
не выполнены. Дефект остаётся открытым в остатках этапов3/9/12 и
включается в ближайший адресный проход на реальном сохранённом источнике.
Он не требует нового Train, смены математической цели или повторения
уже законченных реакций модели.
