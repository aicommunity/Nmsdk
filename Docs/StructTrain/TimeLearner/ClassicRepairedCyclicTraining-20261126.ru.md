# Classic: полный аудит исправленного циклического поиска

Обучение `classic-fresh-selection-q3-m40-ez17` закрыто со статусом
`budget_exhausted`. Полный независимый аудит исходных данных завершён
на .12. Результат распознавания этой конечной модели пока не измерен;
соответствующее продолжение поставлено после уже действующей серии .12.

Использованы M=4, частота 2000 Гц, CapturedPerInput и настройка числом
синапсов. Циклический порядок исследует по три кандидата за посещение
пути. [Исправление выбора координат](CyclicProposalSelectionImplementation-20261126.ru.md)
сохраняет ранее найденные предложения и проверяет их при текущих параметрах
других путей. Это описание относится к Classic; алгоритм с ветвлением
этим исправлением не менялся.

## Полнота доказательств

Восстановлены все 2615 файлов исходного архива, 3 448 374 835 байт.
Штатный `audit_execution('train', ...)` независимо прочитал полные
первичные данные. Аудит закрыт с кодом 0, фактически загруженные файлы
его процесса сохранены. Исходное обучение не запускалось повторно.

Архив содержит 129 составных групп измерения, 773 нативных предъявления
и 2 783 317 отсчётов. Это разные уровни учёта: число сырых предъявлений
не равно числу поисковых решений. Полная проверка не подтвердила свежий
сертификат заключительного измерения всех входов.

Единицы сопротивления следуют объявлению физической модели; таблица
не вводит новую калибровку единиц. В журнале поиска сохранены 60 изменений
при пределе 1280. После штатного выбора конечного состояния фактическая
эпоха равна 61, а исторические измерения относятся к эпохе 60. Совпадение
векторов параметров не разрешает переносить измерения между этими эпохами.
Фактический идентификатор модели:
`37171255e3b48254910796f7cb40d05fa0e31aca3cccf3b328dba5ec08b71050`.

Причина остановки — `native_training_time_budget_exhausted`. В коде
`NativeTrainingService::CheckBudget` это объединённая проверка модельного
и стенового времени: пределы 10000 и 32400 с соответственно. Полный
нативный процесс занял 33207,45 с, включая подготовку и завершение вне
внутреннего измерителя. Эта величина сама по себе не доказывает, какая
из двух внутренних границ сработала первой. Не объявлять исчерпанным
модельное время по одному тексту этой причины.

## Перенос в проверку распознавания

Из неизменённого полного исходного состояния построен отдельный
DATA-документ, содержащий реальный граф, параметры, образы и настройки.
Полный файл исходного состояния размером 1 206 455 851 байт и его история
сохранены отдельно. Проекция сохраняет фактическую эпоху 61 и связь
с предшествующим полным аудитом; она не создаёт сертификат обучения.

Продолжение на .12 выполняется после завершения четырёх действующих
условий Branch. Оно включает штатный импорт DATA, identity conversion
в модель распознавания, восемь полных реакций с порогом 100, предложение
одного порога по Historical Same-Matrix и реальную проверку кандидата
на тех же восьми паттернах. Если пригодного кандидата нет, отрицательный
результат сохраняется. Порог не подтверждается одним offline-анализом.
Поддерживаются резерв диска 32 ГиБ и остановка собственного задания
с запасом при 33 ГиБ. Шаблонная модель вместо конечного состояния
не используется.

Последовательный контроль на M40 и отдельное циклическое обучение на .14
продолжаются. Их результаты пока не заменяют этот аудит и не позволяют
сравнить окончательные свойства исправленных вариантов.
