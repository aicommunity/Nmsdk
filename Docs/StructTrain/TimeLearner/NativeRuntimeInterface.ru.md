# Candidate: runtime integrity и native job interface

Обнаружена ошибка orchestration live-routing A3: manifest baseline33fc/native-runtime.json относится к Test_PulseLib_StorageComponents, не NeuroModelerConsole. Verify_runtime правильно подтвердил integrity того executable, но не его роль. GoogleTest проигнорировал Console flags и начал общий test suite. Этот запуск остановлен оператором по exact parent/registered-native bindings; он не является Train/Test экспериментом. Модели других jobs не останавливались.

Новый native_cli.inspect_native_cli проверяет actual advertised command interface через существующий --help до создания output задания. Требуются --app-ini,--timelearner-output и requested native operation flags. Проверка не зависит от имени файла и допускает runtime с суффиксом.rs2. Console help завершается в QCommandLineParser до engine init. GTEST_FILTER=-* и GTEST_LIST_TESTS=1 не дают ошибочно выбранному GoogleTest binary выполнять test bodies при этой проверке. Timeout5s и output limit128KiB; private temporary cwd, owned process group/PID handle и verify_runtime до/после. Это не способ запуска произвольных недоверенных программ и не полный cgroup scheduler; наследуемые worker OS caps сохраняются.

Общий managed pipeline и standalone native Train/export/evaluate/probe/calibration/PostTune выполняют эту проверку. Успешный worker сохраняет runtime-cli-interface.json в hash-covered artifacts. Старые manifests/primaries читаются по прежним схемам; новый producer не имеет bypass для этой проверки. Advertised help — необходимая предварительная проверка интерфейса, не доказательство фактического job выполнения, native schema или научного PASS; все прежние effective model/observations/process audits сохраняются.

Исправление orchestration также требует построить отдельный manifest настоящего Console из неизменяемого baseline33fc SDK; нельзя выдавать test-runtime fingerprint за Console или просто переписать путь без source/build/library snapshots. Некорректный live A3 сохраняется полным negative evidence; до восстановления доступа/проверки actualConsole и guard7 повторные модели не запускать.

Подготовлены7 реальных server checks без mocks/извлечения тел: actual Console all8operations; actual gtest negative; duplicate operations; renamed Console; wrong gtest rejected before standalone Train output; wrong gtest rejected before pipeline output; unknown/empty operation rejection. Локально только AST. Нужны actual7, full coordinator8, live6, scorer/readers и остальные production regression before merge. Никакие алгоритмы/physics/storage/tolerances не изменены. Общий план остаётся частичным.
