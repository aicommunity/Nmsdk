# Распознавание Classic при изменении момента четвёртого импульса

## 1 Задача и модель

Нейрон Classic, ранее обученный на паттерне M=4 с временами импульсов
0/80/240/480 мс, проверен на семи новых отвлекающих паттернах и прежней
цели. Моменты первых трёх импульсов фиксированы: 0, 80 и 240 мс;
момент четвёртого меняется. Сохранённая структура и индивидуальные
параметры нейрона не изменяются. Порог 0,026100997379370133 выбран ранее
по исходной матрице и перед этой серией зафиксирован.

Расчёт выполнен на Windows .8 при 2000 Гц после проверки исходной
матрицы на актуальном runtime: все восемь полных реакций совпали с
Linux при допуске 10⁻¹². Эта проверка переноса отдельно принята
по всем 496 первичным файлам и 33 файлам независимого читателя.
В новой серии обучение и подбор порога не выполнялись. Перед каждой
пробой сбрасывается динамика; анализ охватывает полное объявленное окно.

## 2 Наблюдения

| Четвёртый импульс, мс | Роль паттерна | Выход нейрона относительно начала, мс | Оценка |
|---:|---|---|---|
| 320 | Отвлекающий | Нет | TN |
| 360 | Отвлекающий | Нет | TN |
| 400 | Отвлекающий | Нет | TN |
| 440 | Отвлекающий | Нет | TN |
| 480 | Целевой | 483,5 | TP |
| 520 | Отвлекающий | Нет | TN |
| 560 | Отвлекающий | Нет | TN |
| 640 | Отвлекающий | Нет | TN |

В этой серии получены **TP=1, FP=0, FN=0, TN=7**. Выход целевого
паттерна возникает после четвёртого импульса; ранних выходов до него
не зарегистрировано ни в одной пробе. Семь отрицательных паттернов
не использовались для выбора порога данной серии. Положительный
паттерн уже предъявлялся при обучении и прежней калибровке.

Полученный результат устанавливает разделение выбранных восьми
паттернов при фиксированных первых трёх импульсах. Он не устанавливает
общую избирательность ко всем четырёхимпульсным паттернам. На том же
нейроне [изменение второго импульса](ClassicSecondPulseFrozenResults-20261127.ru.md)
ранее дало пять FP среди семи новых отрицательных паттернов. Новая
проверка не отменяет этого ограничения.

Длительность изменённых паттернов составляет 320–640 мс. Это проверка
распознавания моделью, обученной цели 480 мс; обучение историческим
целям длительности 25/50/100/200 мс остаётся отдельной будущей работой.

## 3 Данные и состояние проверки

Полный первичный комплект из 494 файлов опубликован во внешнем архиве
M40 вместе с реальными байтами загруженных библиотек, моделью и
управляющими Git-комплектами. На M40 повторён production-аудит всех
восьми наблюдений и проверен перенос исходного задания с разделённым
файлом модели. Построены 16 PNG и 16 SVG: для каждой реакции показаны
все записанные потенциалы участков сомы, фактические входные импульсы
и выходные события, полный диапазон и дополнительный положительный
масштаб. Кэш галереи:
`/media/user/Data/TimeLearnerRefactor/readbacks/Win8-fourth-gallery-fr632/report/index.html`.

На момент записи самостоятельное независимое чтение нового первичного
комплекта и полный визуальный просмотр этой галереи ещё ожидаются.
Итог численного опыта приведён с этой оговоркой; приёмка всей серии
пока не объявляется.
