23 ноября2026. Описаны завершённые наблюдения, прочитанные после восстановления
связи. Число импульсов M=4; топология Branch, нормализация числом синапсов N0.

## Результат

Новая остановленная модель обнаруживает цель и правильно отклоняет пять из
семи отвлекающих паттернов: **TP=1, FP=2, FN=0, TN=5**. Это действительные
выходные события при пороге0,0858575482028458. Порог выбран по той же матрице;
независимой проверкой этот результат не является. Обучение завершилось по
бюджету, без Exact и без завершённой границы обучения.

|Модель и проверка|Порог|TP|FP|FN|TN|

|Прежний ограниченный поиск Nₛ=6/5/5/1; Same-Matrix|0,06760345444849075|1|1|0|6|
|Новый поиск Nₛ=12/10/8/1; исходный высокий порог|100|0|0|1|7|
|Новый поиск Nₛ=12/10/8/1; Same-Matrix|0,0858575482028458|1|2|0|5|

Следовательно, уменьшение лучших амплитудных ошибок в5–11раз пока не
улучшило классификацию: появилась дополнительная ошибка. Изменились
состояние общей ветви и траектория поиска, а при калибровке — также порог.
Отдельный причинный эффект одного Nₛ этим сравнением не установлен.
Критерий включения примера TP≥1 и TN≥2 выполнен. Молчание при пороге100
не является детектором, несмотря на долю правильных ответов7/8.
