# Проверка селективности Classic при изменении второго импульса

27 ноября 2026 года завершена проверка фиксированной модели Classic,
которая на исходной восьмёрке давала TP1/FP1/FN0/TN6. На новой матрице
из десяти паттернов получено **TP1/FP6/FN0/TN3**. Из семи действительно
новых отрицательных паттернов пять вызвали ложный ответ, два были
правильно отклонены. Результат показывает ограниченную селективность
этой модели за пределами исходного набора. Исходный результат FP1
сохраняет силу для своего протокола и состава отвлекающих паттернов.

## Модель и условия

Использован результат [холодного Classic cap8](ClassicCount8TrainingResults-20261127.ru.md).
Обучение завершилось по вычислительному бюджету; выполнения исходных
допусков всех входов не установлено. В данном опыте обученная физическая
модель и ранее подтверждённый порог **0,026100997379370133** заморожены.
Нового Train, изменения структуры и повторного выбора порога нет.
Идентификатор модели —
`8d66abe56a9ce8468e3888834b32017f23fc724d70cd2cd7a33ffe678797d226`.

У каждого паттерна **M=4** импульса. Их времена относительно первого:
`0 / t₂ / 240 / 480 мс`. Меняется только t₂. Целевой паттерн —
`0 / 80 / 240 / 480 мс`; в новой матрице он находится на пятой позиции.
Длительность от первого до последнего импульса остаётся 480 мс.
Это проверка новых отвлекающих паттернов, а не обучение более короткой цели.
Исторические цели 25/50/100/200 мс относятся к
[отдельному будущему плану](PostPlanResearchBacklog.ru.md).

Частота расчёта — 2000 Гц, шаг — 0,5 мс. Перед каждой пробой выполняется
штатный Reset физической динамики. Каждое окно длится 2 с и содержит
4001 отсчёт, реальные входные и выходные события. Все 18 окон полные,
валидные и не цензурированные. Классификация использует реальные выходные
события, а не максимум SumPotential одного участка сомы. Несколько
выходных спайков одной отрицательной пробы считались бы одним FP.

Исходное объявление опыта зафиксировано до новых наблюдений в управляющем
Git `86ea612b7ba59943fc75e20662f8ef8935560a0e`. Исполнитель — Elder.
Сначала выполнены восемь исходных контрольных реакций. Все их временные
сетки, отсчёты потенциалов и входные/выходные события совпали с M40
при допуске 10⁻¹²; сохранились TP1/FP1/FN0/TN6. Затем выполнена новая матрица.

при фиксированных остальных входных импульсах. Оно не доказывает,
что каждый из четырёх импульсов необходим для выхода: для причинного
вывода требуется отдельное корректное вмешательство в предъявление.

## Временные графики и проверка данных

Для каждой из 18 реакций построены два вида: полное окно с отдельным
увеличением отклика и положительный масштаб полного окна. На графиках
показаны записанные потенциалы всех четырёх участков сомы; наложены
реальные входные импульсы и выходные события. Полный вид сохраняет
отрицательный выброс, сопровождающий выход, а дополнительный масштаб
позволяет различать положительные вершины. LT decision potential в этой
галерее отдельно не изображён; сравнение SumPotential с одним числом
не заменяет реальное исполнение порогового механизма.

Всего получены 36 PNG и 36 SVG. Все PNG просмотрены по девяти контактным
листам; реакция нового FP с t₂=200 мс дополнительно просмотрена в полном
разрешении. SVG проверены по байтам, отдельного визуального просмотра
всех SVG не заявляется. Галерея хранится во внешнем архиве и восстановлена
в кэше M40:
`/media/user/Data/TimeLearnerRefactor/readbacks/Classic-second-pulse18-gallery-fr582/report`.

Опубликованы **185 первичных файлов** и **154 файла галереи**. Независимый
читатель .4 восстановил все 339 файлов, повторил оба production-аудита,
проверил все 72 PNG/SVG, байты реально загруженных файлов двух основных
процессов и сравнение восьми исходных реакций. Его 34 файла доказательств,
управляющий Git и загруженные байты Python проверены на M40.
Первоначальное владение уже закрывшимися процессами этим не аттестуется заново.
