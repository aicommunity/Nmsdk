# Состояние TimeLearner на 27 ноября 2026

Полная цель остаётся активной: полностью принят этап 0, этапы 1–12
выполнены частично. Новый подтверждённый результат получен для конечной
Classic-модели после исправления циклического поиска: 1 TP, 4 FP, 0 FN,
3 TN при реальном расчёте с выбранным порогом. Это дополнительная модель
с плохой разделимостью; прежние результаты с одним FP сохраняются
в своих условиях. Завершён также полный направленный опыт Branch
с семью изменениями времени четвёртого импульса.

Дополнение27.11, после закрытия опытов .12/.4:
[направленная проверка Classic](ClassicFourthPulseHistoryResults-20261127.ru.md)
независимо принята по всем64 наблюдениям. При переносе четвёртого импульса
на280 и320 мс изменённый паттерн отклоняется после сброса, но вызывает
ложный выход через240,5 мс при сохранении динамики. Положительный контроль
остаётся активным. Первые пять полных реакций и записанные участки до
изменения условий совпали. Это подтверждает ограничение временного
распознавания данной модели; ранний TP не доказывает приём всей пачки.
Исходная и изменённая восьмёрки имеют различный состав: цель перенесена
в последнюю позицию вместо одного прежнего отвлекающего паттерна.

Полный производственный аудит последовательного Train M40 завершён;
проверена и проекция его фактической конечной модели. Сохраняются
`budget_exhausted`, отсутствие завершённой границы и отсутствие свежей
проверки всех входов. Из50 записей кандидатов25 относятся к входу0,
25 — к входу1; вход2 не исследован, вход3 является опорным. В самой
постановке поле циклического обхода отсутствует, как и предусмотрено
исходным последовательным режимом. Теперь идёт реальное распознавание
этой модели; итоговые числа пока неизвестны.

При упаковке самого аудита обнаружено, что системное обновление M40
заменило `libexpat.so.1.9.1`: прежняя контрольная сумма из manifest
читателя больше не соответствует файлу по тому же пути. Точные старые
байты пока не восстановлены, поэтому воспроизводимость среды этой
постобработки не принимается. Исходные2166 файлов Train и его нативных
артефактов уже сохранены и независимо проверены отдельно. На .12 поставлено
новое полное чтение этих сохранённых данных после закрытия сборки и тестов,
с захватом фактически загруженных библиотек; новый Train не запускается.

Новый контейнерный C++-кандидат собран на M40. Девять проверок типов,
четыре случая полного импорта Classic/Branch с двумя нормализациями
и ещё две проверки архивов прошли; один отрицательный тест ожидал
неверный тип исключения, хотя программа правильно отвергла архив.
Исправлен только контракт теста. Отдельные23 интеграционные регрессии
прошли полностью. Повторная сборка исправленного набора начата на .12;
исходный Windows→Linux перенос DATA2/DATA3 и сравнение полных реакций
по-прежнему обязательны. Кандидат в develop не принят.

После подтверждённого закрытия прежних процессов существующие деревья

   распознавания полного паттерна.
