# Fast N1: оценка остановленной модели после wall7200

Цель — измерить полный отклик terminal Fast3 Branch N4/N1 на все восемь исходных PhaseA паттернов. Успех классификации заранее не предполагается. Исходный Train s11-fast-bracket-wall7200-m40-a1 имеет native outcome budget_exhausted, общий certificate=null. Локальное попадание input2 в допуски не переносится на terminal graph или все входы. Начинать Test только после completed/valid wrapper DATA/physical audit и закрытия всех групп исходного Train.

Используется фактический полный train_stopped_state.json, source5ca731a696713a7787700e1fc553485ec5264a18, controls67a3a73367c70b6840ec0b9f81704bcfef9b79bd, runtime root7b495ebf753259ae8b78c6d0eadd561fb3d2c835/Pulse9e7653a400761d6c2f3ea68fddcd40a4307d85e7. Нейрон TLNativeFast3F2000_Neuron, C2.5e-10F/DissociationTC.002с/2000Гц, LTMembrane отсутствует. Полный импорт сохраняет storage definitions, реальный общий кабель, совпадающие точки подключения, Rs/Ns, все связи и порог. Никакого template fallback, нового обучения или изменения физики.

Восемь проб используют исходную PhaseA матрицу revision1c1464e248f8744e858bd66df0be99e39969fd65, reset_per_trial, полные2с окна и фактические времена стимулов. Identity conversion, все входы включены, threshold100 сохранён. Проверяются полная исходная модель source_solo, before/after identity и неизменность файлов источника. Используются production job_for/run_job/audit/scorer. Молчание при100 означает пропуск target;7/8 молчания не становится научным PASS.

Сценарий test_coupled_stopped_matrix_native ранее жёстко требовал invalid_observation. Для нового опыта declaration.json явно задаёт training_outcome=budget_exhausted. Сценарий принимает только два заявленных диагностических исхода и требует точного совпадения с фактическим execution; default invalid_observation сохраняет прежние постановки. Это исправление ограничения harness, без изменения алгоритма обучения, исходного outcome или критериев оценки.

Низкопороговый опыт, если он будет выполняться, объявляется отдельно по той же фиксированной Same-Matrix процедуре и подтверждается настоящим native прогоном. Frozen evaluation при другом порядке/ITI и independent evaluation остаются отдельными протоколами. Для каждого выполненного Test обязательны временные графики всех паттернов: Soma.SumPotential с входами, отдельно LTZone.Potential с порогом и событиями, полный overview и native zoom не менее8px/tick. Тяжёлые primary/галереи находятся во внешнем архиве M40; Git содержит код, декларации и компактные refs.
