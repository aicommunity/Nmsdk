# Продолжение исследований после текущего плана

Поручение пользователя27.11.2026: после достижения текущей цели TimeLearner
сформировать отдельный план продолжения исследований по историческим
паттернам другой длительности. Сейчас эту серию не запускать вместо
оставшихся работ рефакторинга; её отсутствие не добавляет критерий
приёмки текущего плана.

Исходный ориентир пользователя — **M=4 импульса** и общая длительность
**25,50,100,200 мс**. Значения приведены по памяти, поэтому это ещё не
подтверждённый исторический реестр или объявленный протокол эксперимента.

При подготовке будущего плана:

1. Найти исходные конфиги, отчёты и доступные первичные данные; записать
   repository, полные commits, пути и состояние доступности артефактов.
2. Сверить общую длительность, времена всех четырёх импульсов и частоту;
   отдельно указать задержку до первого импульса, ITI, окно наблюдения,
   reset policy, storage-физику и прежние правила выбора порога.
3. Разделить исторический replay, холодное обучение исходным протоколом
   и новые контролируемые изменения длительности для Classic и Branch.
   Не подменять эти задачи Test сжатого отвлекающего паттерна на модели,
   обученной цели480 мс.
4. На основе проверенного действующего контура определить матрицу,
   вопросы исследования, бюджеты, контрольные условия, измерения,
   временные графики и порядок публикации результатов.

Триггер начала подготовки — полное завершение утверждённого текущего
плана, а не отдельной серии расчётов или очередного отчёта. До этого
запись сохраняет задачу для передачи контекста; самостоятельная новая
активная цель и новые длительные задания здесь не создаются.
