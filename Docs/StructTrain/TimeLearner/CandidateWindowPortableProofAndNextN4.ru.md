## Один следующий научный case после этих implementations

Минимальный первый case — **Classic N4, N1 normalization, 2000 Hz,
CalculateMode0, StructureBuildMode1, C-trim Off, PostTune Off**. Исходный штатный
storage profile `NSPNeuronGen`, Ns1/Rs86MΩ и target ISI `[.01,.08,.16,.24]`
уже объявляет production `stock_phasea_preflight.py::make_stock_job`; его physical
profile не заменяется integration fixture. Этот builder даёт старую декларацию:
для нового run нужен reviewable cold7 envelope/common policy2/candidate policy1
над явно объявленным initial reference window и bounded growth. Готовым cold7
scientific job этот старый builder не является. Никакой post-hoc подгонки окон,
толерансов, порога или physics ради Exact.

Classic initial L1×4 и отдельный будущий Branch N4 `[4,3,2,1]` — разные явно
объявленные модели. Для Branch не использовать `prepare.py` простое размножение
N2 inputs: оно может дать shared attachments. Uniform physics задаётся через
storage образ; actual readback исходных банков/links/threshold/LT/Soma/source
сохраняется до Train. Уже проверенный readable Classic LT overview показывает
ненулевой LT.Potential: прежний визуально flat вид объяснялся масштабом оси при
threshold100; это не основание объявлять текущий LT source неработающим или
менять physics. Routing48, в свою очередь, не доказывает общего физического
causal соответствия либо успешной N4 классификации.

Новых управляющих циклов/команд не требуется. Существующие public операции:

