# Быстрые модели PulseLib для S50 и S100 при шаге интегрирования dt = 0.5 мс: ревизия и коррекции

Дата: 2026-10-24, 23:40 (МСК). Только чтение на хостах .11 и .17: ничего не правил, не коммитил, не запускал. Все расчёты сделаны на box в `/workspace/nmsdk/fastmodels/` (sim/, data/).
Маркировка: **[строго]** следует из кода, логов или точной математики; **[числ.]** — численная модель segsim при f=2000 (dt=0.5 мс); **[гипотеза]** — экстраполяция, не проверенная в Console.

Критерий взят из теории (SIGNAL_SHAPE_THEORY §1): цель детектируется, и $m=\min_f (P_0-P_f)/P_0\ge0.10$ для ложных паттернов, в которых внутренний спайк сдвинут на $\ge S/4$. Отдельно указан m8 (margin против 7 ложных паттернов MatrixData).

## 0. Вывод коротко
1. **[числ.]** Ни одна из существующих быстрых моделей при шаге интегрирования dt = 0.5 мс критерий не проходит. TauH0_S50 даёт m(S/4)=0.038, TauH0_S100 даёт 0.016, Sim2/Sim4 и legacy C1e9 дают отрицательные значения.
2. **[числ.]** **S100 достижим коррекцией параметров существующего класса TauH0_S100.** Нужны Capacity 7.5e-11 (τ=0.75 мс) и тормозная мембрана Rm 1e7 / Rs 8.6e7, а длины L ≈ 400/334/200/1. Получается m(S/4)=0.129 (Classic) и 0.112 (Branch). Без коррекции торможения 0.089/0.078. Значит MaxDendriteLength ≥ 450.
3. **[строго+числ.]** **S50 при dt=0.5 практически недостижим.** Граница дисперсии $\sigma/S\ge\sqrt{dt/S}=0.1$. Лучший вариант (τ=0.6, L≈500, торможение) даёт 0.10–0.11 только в Classic, на грани. Branch ≤ 0.08.
4. **[строго]** Прогоны H0b на TauH0 шли при Train **и** Test DefaultTimeStep 20000 (dt=0.05 мс), то есть с нарушением правила dt=0.5, и всё равно не сошлись. В линии br25/W1/W2 Train идёт при dt=0.05, а Test при dt=0.5. Для быстрых τ это расхождение недопустимо: модель обучается на одном ядре, а тестируется на другом.

## 2. Характеристики моделей при dt = 0.5 мс [числ., segsim f=2000]
Звено: τ = C·Rm (Rm 1e7), задержка на сегмент δ ≈ τ − dt. При τ = dt задержка нулевая (Gauss–Seidel), при τ < dt/2 схема неустойчива **[строго, подтверждено: Rmi 5e6 при C 7.5e-11 (τ_inh 0.375 мс) даёт разлёт до 1e56–1e117]**. τ_s и τ_m синапса: Dissoc/Secr 1 мс (у Sim ×k). c = τ/S. «L для S» = число сегментов, при котором задержка пика = S.

Форма PSP **[числ.]**: ядро каскада имеет гамма-форму (асимметричное, с длинным хвостом). Амплитуда падает с L: P_L1 0.044 (τ1) → 0.057 (τ0.75). Выравнивание амплитуд упирается в нижнюю границу Rs = 2e7, поэтому дистальные входы недокомпенсированы.
Гиперполяризация **[числ.]**: тормозная цепь с Rm 1e8 имеет τ_inh = 10τ, то есть медленный длинный хвост, и **ухудшает** выделение. Пример: S100 τ0.75, Rs_inh 8.6e7 при Rm_inh 1e8 даёт 0.090, а при Rm_inh 1e7 даёт 0.129. При Rm_inh 1e8 с Rs_inh 8.6e7 у S50 и TauH0 m(S/4) падает до −0.15…−0.20.

Верификация segsim против Console **[строго]**: C1e9, L1, td=5 мс, f=2000 дают пик 0.0157814416, это совпадает с W04 InitialSomaPotential (при f=20000 0.01362). Хвост торможения: теория −0.030 против Console −0.039 при 0.5 с. **Ограничение:** при быстрых τ (0.75–2.5 мс) и dt=0.5 сверку с Console я не делал. Это первое, что надо проверить (эксперимент E0).

Ложный №4 отличается от цели лишь на S/8 и поэтому критерием не охватывается. Для m8 ≥ 0.1 нужен нелинейный элемент (теория §6). Пассивной коррекцией это не решается.

## 3. Вердикт
* **[числ.]** Все текущие быстрые классы при dt=0.5 проваливают критерий S/4. TauH0_S25 (τ=0.5=dt) не даёт задержки вообще. AsymRm C25e12 (τ=0.25 < dt/2) неустойчив. Sim1/2/4/19_2 сохраняют c=0.4, так что это модели подобия для W1/W2, а не быстрые. Как контроль масштаба их оставить, для селективности они бесполезны.
* **[числ.]** **S100: проходит после коррекции** τ=0.75 мс и торможения Rm 1e7 / Rs 8.6e7 при L≈400 (Classic 0.129, Branch 0.112). Запаса мало: точная L и выравнивание Rs важны (при недостаточной L получается −0.26).
* **[строго+числ.]** **S50: при шаге интегрирования dt=0.5 критерий S/4 пассивно не достижим с запасом.** Предельный Classic даёт 0.11 при L≈500, Branch < 0.08. Варианты: (а) принять S50 как отрицательный результат; (б) изменить dt (это решение Тима, сейчас запрещено); (в) нелинейный элемент (новый код).

Обязательные контроли:
1. **Цель не первая** в обучающей и тестовой последовательности (рандомизировать позицию, проверить ≥ 2 позиции).
2. **Достаточный ITI.** Задержка ≈ S, FWHM дальнего ядра ≈ 20 мс, хвост торможения. ITI ≥ 300 мс для S100 и ≥ 200 мс для S50; проверить, что остаточный потенциал перед стимулом < 1% пика [гипотеза по fig6 теории].
3. **С торможением и без** (E3), иначе вклад K2/K3 не доказан.
4. **Параметр дошёл до тестовой модели.** Readback Capacity, Membrane/SynapseResistance (exc и inh), MaxDendriteLength, L и DefaultTimeStep из Train XML **и** Test XML, а для Branch ещё после PostTune Rebuild (fallback 1e-9). В TimeLearnerTrainingDynamics.log шаг «now» = 5e-4.
5. Отчёт m(S/4), m(S/8) и m8 раздельно. Критерий оценивается по S/4. m8 ≈ 0 ожидаем и не является регрессией.
