# План работ для агентов-исполнителей: TimeLearner, 20.10.2026

Этот пакет — исполняемая версия плана из аудита («TimeLearner: аудит алгоритмов обучения и план работ», раздел «Поэтапный план»). Он рассчитан на агентов без контекста аудита, работающих на Linux-серверах (`.17`, `.11` или аналогичных), и поэтому написан как набор карточек с точными командами, ожидаемыми результатами и условиями остановки.

**Главное правило для исполнителя.** Выполняй только то, что написано в карточке. Если фактический результат не совпадает с «Ожидаемым», не исправляй ничего сам: останови задачу, заполни отчёт (раздел «Отклонение») и переходи к следующей независимой задаче. Не придумывай обходных путей. Не меняй алгоритмы обучения скриптами.

## Как начать (для исполнителя)

1. Прочитай `00_RULES.md` целиком.
2. Выполни `01_A0_ENV_SETUP.md` на своём хосте. Без зелёного A0 ничего не запускай.
3. Возьми назначенную карточку из `cards/`, выполни шаги по порядку.
4. Для каждой карточки создай отчёт по `templates/REPORT_TEMPLATE.md` и `result.json` по `templates/result.schema.json` в `$REPORTS/<TASK>_<RUN_ID>/`.

## Новые находки при подготовке (кратко, для человека)

1. **Очередь на baseline не стартует** без refresh манифестов (A0 шаг 8). Вероятно, это объясняет часть «инфраструктурных» отказов после 19.10.
2. **SoftCold-проводка (H-A15b).** Старый `rewrite_links_to_tip1` порождает fan-out синапса кончика на все (удалённые) сегменты в каждой Train-копии с 27.09. Если C++ восстанавливает связи при наращивании, это возможная причина регрессии. Проверка — E2, S0↔S1.
3. **EstDelayPerSeg в Train W01 = 0.002 с/сегмент** при физическом ≈ 0.01 (τ = Rm·C). У Branch оценка вообще не задаётся из XML (константа 0.005). Проверка — D2.1 и D2b.6.
4. **A16 (кандидат).** Gate Classic переносит обученные `DendriteLength` в Test, не трогая отводы генератора в `<Links>`. Пересвязывает ли C++ отводы — A3.2.
5. Конфигурации с τ = 0.25 мс на пассивном кабеле (W13 ltz*_preinh, W37 PACKC) по модели недостижимы (L > 100); исторически все `not_converged_at_stop`.
