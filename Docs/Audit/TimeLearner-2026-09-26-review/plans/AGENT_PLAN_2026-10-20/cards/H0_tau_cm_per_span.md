# H0. Подбор τ через Cm по классу паттерна (фаза дендрита)

**Цель:** для каждого класса длины паттерна (Span) найти рабочую постоянную времени сегмента τ, меняя преимущественно **Cm** (чтобы не ломать отношение сопротивлений синапса и мембраны), зафиксировать NeuronModel и на нём измерить оба тренера × оба режима × mods.  
**Статус:** docs-ready стратегия 2026-10-23; cold — только по явному execute.  
**Канон:** [`../../../evidence/STRATEGY_TAU_PER_SPAN_THEN_AXON_2026-10-23.ru.md`](../../../evidence/STRATEGY_TAU_PER_SPAN_THEN_AXON_2026-10-23.ru.md).  
**Не путать с:** F1b / аксонным тренером (фаза A — **после** ворот этой карточки).

**Зависит от:** A0; C2 (офлайн-свип); желательно E1.0/E1.4 как якоря предсказателя.  
**Не блокирует и не отменяет:** F1a done; F1b остаётся в плане как фаза A; SPEC DRAFT дендритного v2; открытые долги D2 / CL-N1@480 / F5.

## Часть H0a. Офлайн: сетка Cm → τ × Span

1. Зафиксировать классы Span: 25, 50, 100, 200, 480 мс (как в матрице / этапе 5).
2. Варьировать Cm при фиксированных Rm (и базовой логике Rs/TipR), получить τ = Rm·Cm.
3. Для каждой пары (Span, τ) оценить по `cable_model` / C2 / E1.4: FWHM/span, `feasible` при MaxL, запас (oracle / predictor).
4. Отобрать **рабочие** τ per Span (максимальная разделимость при достижимом L); не требовать одной τ на все Span.
5. Записать кандидата NeuronModel (имя профиля / путь Train·Test шаблона) на каждую принятую пару.

**Ожидаемо:** таблица Span → τ(Cm) → NeuronModel → margin/feasible; явно пометить отвергнутые единой-τ конфигурации (в духе W13/W37 C25e12 на несогласованном спане).
