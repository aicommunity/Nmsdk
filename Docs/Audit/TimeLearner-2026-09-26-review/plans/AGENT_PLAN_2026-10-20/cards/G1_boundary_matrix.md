# G1. Сокращённая матрица границ (только после ревью человека)

> Исторический документ: указанные ниже shell-команды относятся к аудиту октября2026. Исполняемые файлы удалены из текущего дерева; источники доступны только по зафиксированным Git-ссылкам. Это не инструкция запуска текущего pipeline и не разрешение возобновить серию D.
> Источники: [run_series.sh](https://github.com/aicommunity/Nmsdk/blob/fa53680d62ce9dedbee464fc55418dd3f76a0ca6/Docs/Audit/TimeLearner-2026-09-26-review/plans/AGENT_PLAN_2026-10-20/tools/run_series.sh).


**Цель:** измерить границы работоспособности по осям «тренер × режим × длина паттерна × модель нейрона» с честной проводкой и известным шумом. Сравнить их с картой, которую предсказывает модель кабеля (C2).
**Уровень:** средний. **Хосты:** `.17` + `.11` (≤ 20 Console суммарно). **Время:** ~1 неделя.
**Зависит от:** A1 (MATCH), A3, B2 (часть 1), C1 (`MODEL_MATCH` хотя бы для τ = 10 мс), C2, E2 (S1↔S2 `EQUIVALENT`). **Старт — только по явному «да» человека** после ревью отчётов этих задач. Человек выбирает плечо: S1 (baseline Console) или S2 + флаги, давшие лучший результат в D2b.

## Отбор случаев

```bash
source "$HOME/tl-agent/env.sh"
python3 "$TOOLS/select_cases.py" "$ST" --psi off --exclude-tsv "$PLAN/cards/data/A2_expected_test_failures.tsv" > "$REPORTS/G1_candidates.tsv"
```

Правила (применять по порядку; результат — `G1_selected.tsv`, 24–32 случая):

1. Только PSI off. Только случаи с `excluded_A15=False`. Исключение: если B2-часть 2 показала эффект починки, бери починенную ветку и случаи `True` тоже.
2. Ячейки: trainer {Classic, Branch} × norm {0, 1} × span {25, 50, 100, 480}. В каждой ячейке не больше 2 случаев. Предпочтение — `template` с историческим PASS (`historical_*`), затем `current*`.
3. Модели нейрона: в каждой (trainer, span) должна быть хотя бы одна NSPNeuronGen/AsymRm (τ = 10 мс) и, где есть, FastSpan (τ = 2.5 мс). Класс нейрона — из `Train/Parameters_00.xml` → `NeuronClassName`.
4. 3 повтора на случай.

Запуск — сериями по волнам через `run_series.sh` (как в E2), одна полоса на волну, `--jobs` = число случаев волны в отборе. Распределение по хостам — по волнам, без пересечений. Распределение записать в `ASSIGNMENTS.tsv` **до** старта.

## Предсказание для каждого случая (до запуска)

Для каждого выбранного случая взять из `C2 sweep.jsonl` строку (τ, D, span) модели нейрона. Записать `m_oracle` (верхняя граница запаса для пассивного кабеля) и `feasible`. Ожидания:

- `feasible=false` → сходимость по длине невозможна; ожидаемо `not_converged_at_stop` или best-effort;
- `m_oracle ≤ 0` → даже при сходимости разделение — граничное; любой PASS будет с запасом ≤ 2–3% и хрупким.
