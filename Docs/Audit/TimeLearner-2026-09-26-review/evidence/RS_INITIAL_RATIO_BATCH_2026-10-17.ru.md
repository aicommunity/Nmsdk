# Проверка начального Rs/Rm: первые выборочные запуски

## Цель и границы

Сравнить влияние начального отношения `Rs/Rm` на структурно-параметрическую нормализацию (`NormalizationMode=1`) отдельно для Classic и Branch, PSI on/off. Проверяются сходимость C++-обучения и качество Test независимо. Это не полный перебор матрицы и не попытка оптимизировать классификатор.

Запуски первой части были выполнены до сборки PulseLib `97dd521`; в них фактический начальный `Rs` задавался runner-ом после SoftCold и подтверждён записью `kind=reset` в C++ TrainingAudit. Поэтому выявленная отдельно ошибка сериализованного `ResistanceMin` не подменила стартовое отношение в этих запусках.

## Исправление подтверждённой ошибки холодного старта

До вычисления per-input bounds индексный `ClampResistance()` в Classic и Branch переходил к legacy scalar `ResistanceMin`. При старом сериализованном `ResistanceMin=20 МОм` это могло заменить явно заданное значение из XML ещё до построения топологии. Исправление сохраняет конечное положительное входное `Rs` до появления per-input bounds, а после их построения оставляет обычное ограничение по derived диапазону. Структурный режим `NormalizationMode=0` не менялся.

Исправление отправлено в `origin/codex/historical_view`:

- PulseLib `97dd521` — обе независимые реализации Classic и Branch;
- root `d1d5ebc` — gitlink и regression-тесты для обоих тренеров.

`.17`, Linux Release (GCC 13.3), собрал `NeuroModelerConsole` и `Test_PulseLib_StorageComponents`. CTest `PulseLib_StorageComponents` прошёл `1/1`; отдельный фильтр запустил два новых regression-теста, оба прошли. Release Console SHA-256: `f76f90565eee8eefc241e7bf03b31e6504f2b998c6592a2cdf1c249a31f01d9e`. Сборка с `RDK_USE_LLM=OFF`; обучение на Windows не проводилось.
