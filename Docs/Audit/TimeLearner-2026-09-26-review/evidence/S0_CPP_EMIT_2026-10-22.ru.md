# S0 — C++ эмиссия Stage0 полей (DEBT-S0-cpp-fields)

Постановка: `summarize_run.py` уже читает колонки `delay_residue`, `amp_over_target`, `sync_exit`, `done_be` из `matrix_result.json`, но до этого прогона PulseLib не записывал согласованные скаляры в `TimeLearnerTrainingAudit.log`, а harness не переносил их в JSON. Цель — дать rollup G1 возможность отличать exact Done от Done_BE по полям C++, а не по эвристикам monitor.

## Что сделано

| компонент | изменение |
|---|---|
| PulseLib Classic | `AppendStage0ScalarFields` на каждой audit-строке; `AppendTrainingDoneAudit` (`kind=done`) после `Need=0` в `EndOfLearning` и `FinalizePostTuneMid` (Train) |
| PulseLib Branch | то же + `FinalizeAfterParallelCalibration` |
| Bin `posttune_verify.py` | `runtime_stage0_fields_from_audit` → поля верхнего уровня в `matrix_result.json` |

### Поля audit / matrix_result

| ключ | смысл |
|---|---|
| `delay_residue` | max `LastAbsDt` по обучаемым дендритам (без ref) |
| `amp_over_target` | max(`InitialAmp − PeakAmp`, 0) по тем же входам |
| `sync_exit` | 1, если любой `best_effort` в векторе `DendBestEffortSynced` |
| `done_best_effort`, `done_be` | 1, если `best_effort` или TipR@Rmin с `LastAbsDt` в полосе `(SyncTol, SyncTol×4]` |

Запись `kind=done` с `need=0` идёт **после** EOL-гейтов (исправляет timing из F2: iteration-строка до `EndOfLearning` не несёт финальный Done_BE).
