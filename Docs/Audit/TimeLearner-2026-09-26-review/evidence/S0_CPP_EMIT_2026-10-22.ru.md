# S0 — C++ эмиссия Stage0 полей (DEBT-S0-cpp-fields)

Постановка: `summarize_run.py` уже читает колонки `delay_residue`, `amp_over_target`, `sync_exit`, `done_be`, `sep_margin` из `matrix_result.json`, но до прогона PulseLib не записывал согласованные скаляры в `TimeLearnerTrainingAudit.log`, а harness не переносил их в JSON. Цель — дать rollup G1 / Controller v2 отличать exact Done от Done_BE и читать **Train** `sep_margin` без отдельного Test-gate, а также отличать sync-BE от amp-quantized BE.

## Что сделано

| компонент | изменение |
|---|---|
| PulseLib Classic | `AppendStage0ScalarFields` на каждой audit-строке; `AppendTrainingDoneAudit` (`kind=done`) после `Need=0` в `EndOfLearning` и `FinalizePostTuneMid` (Train); **`sep_*` в Finalize + flag**; **`amp_be` + OR в `done_be`** |
| PulseLib Branch | то же + `FinalizeAfterParallelCalibration` |
| Bin `posttune_verify.py` | `runtime_stage0_fields_from_audit` → поля верхнего уровня в `matrix_result.json` (вкл. `sep_*`, `amp_be`) |
| AGENT_PLAN `summarize_run.py` | предпочитает C++ Train `sep_margin` над gate selectivity; колонка `amp_be` |

### Поля audit / matrix_result

| ключ | смысл |
|---|---|
| `delay_residue` | max `LastAbsDt` по обучаемым дендритам (без ref) |
| `amp_over_target` | max(`InitialAmp − PeakAmp`, 0) по тем же входам |
| `sync_exit` | 1, если любой `best_effort` в векторе `DendBestEffortSynced` |
| `amp_be` | 1, если любой обучаемый дендрит принят tracker’ом как quantized under-target (`StructuralAmpTracker.IsAccepted` — тот же предикат, что вектор `amp_quantized_under_target`) |
| `done_best_effort`, `done_be` | 1, если **sync_be ∨ rmin_be ∨ amp_be**: `DendBestEffortSynced`, либо TipR@Rmin с `LastAbsDt` в полосе `(SyncTol, SyncTol×4]`, либо quantized amp under-target |
| `sep_tgt` | PostTune probe target LTZ (`PostTuneMetrics[0]`) |
| `sep_max_foil` | max foil peak (= `sep_tgt − sep_gap`) |
| `sep_gap` | абсолютный запас `tgt − max_foil` (тот же gap, что `ComputeMidThreshold`) |
| `sep_margin` | относительный запас `(tgt − max_foil) / tgt` при `metrics_ok && tgt>0`; иначе NaN |

Выбор семантики: отдельный явный флаг **`amp_be`**, при этом **`done_be` = OR(sync_be, rmin_be, amp_be)**. Rollup отличает amp-BE от sync-BE по `amp_be` vs `sync_exit` (sync_exit остаётся только sync-вектором; rmin_slack входит в `done_be`, но не в `sync_exit`).

Запись `kind=done` с `need=0` идёт **после** EOL-гейтов (исправляет timing из F2: iteration-строка до `EndOfLearning` не несёт финальный Done_BE). `sep_*` пишутся в snapshot `Stage0Sep*` внутри `FinalizePostTuneMid` **до** `AppendTrainingDoneAudit` и дублируются в `posttune_complete.flag` (первая строка key-values). Mid-политика / H3 / KeepDone **не** менялись — только emit.

Семантика NaN: `run_bad`, неfinite metrics или `tgt≤0` → ключи присутствуют со значением NaN (audit/`flag`), harness кладёт float NaN в JSON. Без PostTune mid-path (`Stage0SepHave=0`) ключи `sep_*` в audit не эмитятся.

Статическая сверка формулы на bundle Classic×N0 W01 (`G1.S1.W01-11-20261021T113257Z-15892`, Train/Test из `TimeLearnerMatrix/W01/inputs/W01_CL50_N0_PSIoff/{Train,Test}`): Test `posttune_complete.flag` имел `gap=-0.0008359…` при `metrics[0]=0.002512…` и `max_foil=0.003348…` — совпадает с `sep_gap = tgt − max_foil`; `sep_margin = gap/tgt ≈ −0.333`.
