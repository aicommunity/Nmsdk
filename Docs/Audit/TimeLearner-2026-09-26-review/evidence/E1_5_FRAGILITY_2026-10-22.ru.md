## Вердикт хрупкости

| Область | Статус | Комментарий |
|---|---|---|
| Baseline Test-only оба кейса | **PASS** | tiprmin Gold + nextseg E2-state воспроизведены на HEAD Console |
| tiprmin L-ось | **PARTIAL robust** | 5/7 L-вариантов strict PASS; ломают L1+1 / L2−1 / L3+1 |
| tiprmin TipR global ×0.8/×1.25 | **FRAGILE** | 0/2; amp↑ → FA, amp↓ (×1.25 R) → silent |
| br25_nextseg любое возмущение | **FRAGILE** | **0/9** strict; запас sep_ltz baseline лишь **~1.1%** |
| sep_ltz vs fires | **PARTIAL** | часто sep>0 при silent (`00000000`) — FixedLTZ не в середине tgt/foil после L-сдвига |
| Per-tip TipR / L3−1 / full 8×L без clamp | **PENDING** | scoped OK по плану |

**Итог E1.5: PARTIAL DONE — вердикт FRAGILE.** Остров Branch PASS держится на узком запасе (~1–2% по `ltz_potential_max`); `br25_nextseg` не переживает единичный сдвиг L или глобальный TipR±25%; `br480_tiprmin` терпимее к L0 и части L1/L2, но TipR-scale и дистальный/проксимальный tip L ломают selective. Согласуется с E1.4 (margin proxy ~7% ideal_inh vs ~1% Console peaks) и C2 `m_oracle≤0` для 480 tiprmin.
