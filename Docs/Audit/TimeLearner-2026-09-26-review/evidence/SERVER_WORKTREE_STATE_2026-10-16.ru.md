## Что содержат незакоммиченные варианты кода

### `.11`

Изменения PulseLib включают расчёт отдельных диапазонов Rs относительно каждого мембранного сегмента, preflight-проверку ограничений численной схемы и причины отказа для случая, когда конечной допустимой Rs не находится. Добавленные integration cases покрывают устойчивость, интервалы сопротивлений и структурные переходы Branch. Отдельный untracked header `NNeuronTimeLearnerResistanceBounds.h` содержит расчёт нижних границ. Это напрямую относится к гипотезе о пересечении знака потенциалом канала, но код пока не сверен построчно с текущим `codex/historical_view` и не запускался из чистого зафиксированного checkout в рамках текущей проверки. Сохраняем его как отдельный кандидат для анализа, не переносим автоматически.

### `.17`

В незакоммиченном PulseLib есть read-only диагностика состояния кабеля, синапса, dataset и Branch по итерациям; добавлены счётчики повторных invalid-peak/no-action, проверки восстановления порядка сегментов и выхода на `Rmax`. Метод `NPulseChannelCable::GetAuditVmSummary()` сейчас не имеет найденных вызывающих мест и просматривает не более 4096 равномерно выбранных ячеек `Vm`, поэтому его отсутствие пересечения знака не доказывает. Эти правки могут быть полезны как диагностическая ветка, но сначала требуют проверки полноты телеметрии и отличий от текущих commits. Изменённые runner-файлы и untracked `_repro` не изменялись.

Ни одна из серверных незакоммиченных версий пока не объединена с текущей веткой. Для экспериментов используется отдельный чистый worktree с root `b0b0399`, PulseLib `4d66db5` и Bin `cfc5bcf` на диске данных `.17`; это сохраняет воспроизводимость и изолирует запуски от старых каталогов.
