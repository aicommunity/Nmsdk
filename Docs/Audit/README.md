# Documentation Audit Hub

## RU

Центральная точка аудита документации Nmsdk. Отчёты генерируются скриптами из `Scripts/doc-audit/`.

### Быстрый старт

```bash
Scripts/doc-audit/run-all.sh
```

### Отчёты

| Отчёт | Описание |
|-------|----------|
| [Documentation-Inventory.json](Documentation-Inventory.json) | Все `.md` с метаданными |
| [Code-Inventory.json](Code-Inventory.json) | `UploadClass`, CMake targets/options |
| [Link-Health-Report.md](Link-Health-Report.md) | Битые относительные ссылки |
| [Bilingual-Parity-Report.md](Bilingual-Parity-Report.md) | Файлы без `## EN` |
| [Mermaid-Sanity-Report.md](Mermaid-Sanity-Report.md) | Проверка mermaid-блоков |
| [Component-Gap-Report.md](Component-Gap-Report.md) | Классы без docs / orphan docs |
| [Build-Gap-Report.md](Build-Gap-Report.md) | CMake targets/options vs Build-System.md |
| [Index-Count-Gap-Report.md](Index-Count-Gap-Report.md) | Счётчики в индексах |

### Матрица зон

| Зона | Субмодуль | Статус |
|------|-----------|--------|
| `Docs/` | nmsdk (root) | active |
| `Rdk/Docs/`, `Rdk/LLM/Docs/` | Rdk | active |
| `Bin/Docs/`, SpikeSamples README | Bin | active |
| `Libraries/*/Docs/` | per-library | active |
| `Reports/` | nmsdk | historical (archive only) |

### Шаблон находки

| ID | Severity | File | Code source | Action |
|----|----------|------|-------------|--------|
| AUD-001 | P0 | path | UploadClass in X.cpp | Update Component-Catalog |

### Коммиты

После каждой фазы:

```bash
Scripts/doc-audit/commit-phase.sh \
  --phase "phase-1-p0" \
  --scope nmsdk \
  --summary "sync root indexes after hardware audit"
```

Сообщения — **English**, формат `docs(<scope>): <summary>`.
