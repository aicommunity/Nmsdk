# Rdk-CvBasicLib

## RU

### Назначение

**Rdk-CvBasicLib** предоставляет компоненты компьютерного зрения на базе OpenCV. Библиотека включает компоненты для захвата видео, обработки изображений, детекции объектов, классификации и сегментации.

### Основные категории компонентов

- **Захват видео и изображений** - TCapture, TCaptureCamera, TCaptureCameraIp
- **Источники изображений** - UBASource, UBASourceFile
- **Обработка изображений** - UBAColorConvert, UBAResize, UBABackground
- **Детекторы объектов** - UDetectorBase, UBAObjectDetector
- **Классификаторы** - UCRClassifier, UCRPerseptron
- **Нейронные сети** - UCRConvolutionNetwork
- **Сегментация** - USegmentatorBase

### Зависимости

- OpenCV
- rdk.static.qt

## EN

### Purpose

**Rdk-CvBasicLib** provides computer vision components based on OpenCV. The library includes components for video capture, image processing, object detection, classification, and segmentation.

### Main Component Categories

- **Video and Image Capture** - TCapture, TCaptureCamera, TCaptureCameraIp
- **Image Sources** - UBASource, UBASourceFile
- **Image Processing** - UBAColorConvert, UBAResize, UBABackground
- **Object Detectors** - UDetectorBase, UBAObjectDetector
- **Classifiers** - UCRClassifier, UCRPerseptron
- **Neural Networks** - UCRConvolutionNetwork
- **Segmentation** - USegmentatorBase

### Dependencies

- OpenCV
- rdk.static.qt
