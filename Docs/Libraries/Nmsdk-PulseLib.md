# Nmsdk-PulseLib

## RU

### Назначение

**Nmsdk-PulseLib** предоставляет компоненты для моделирования импульсных нейронных сетей (Spiking Neural Networks, SNN). Библиотека включает различные модели нейронов, синапсов, каналов, механизмы обучения и классификации.

### Основные категории компонентов

- **Нейроны** - NPulseNeuron, NIntegrateAndFireNeuron, NPulseNeuronIzhikevich
- **Синапсы** - NPulseSynapse, NSynapseStdp
- **Каналы** - NPulseChannel, NPulseChannelIzhikevich
- **Генераторы импульсов** - NPulseGenerator
- **Классификаторы** - NClassifier, NSpikeClassifier
- **Обучение** - NNeuronTrainer, NSynapseTrainer

### Зависимости

- rdk.static.qt
- Rdk-BasicLib
- ODE Solver (опционально)

## EN

### Purpose

**Nmsdk-PulseLib** provides components for modeling Spiking Neural Networks (SNN). The library includes various neuron models, synapses, channels, learning mechanisms, and classification.

### Main Component Categories

- **Neurons** - NPulseNeuron, NIntegrateAndFireNeuron, NPulseNeuronIzhikevich
- **Synapses** - NPulseSynapse, NSynapseStdp
- **Channels** - NPulseChannel, NPulseChannelIzhikevich
- **Pulse Generators** - NPulseGenerator
- **Classifiers** - NClassifier, NSpikeClassifier
- **Training** - NNeuronTrainer, NSynapseTrainer

### Dependencies

- rdk.static.qt
- Rdk-BasicLib
- ODE Solver (optional)
