# Rdk-PyMachineLearningLib

## RU

### Назначение

**Rdk-PyMachineLearningLib** предоставляет интеграцию с Python библиотеками машинного обучения.

### Основные категории компонентов

- **Классификаторы** - TPyClassifierTrainer, TPyUBitmapClassifier
- **Детекторы объектов** - TPyObjectDetector, TPyObjectDetectorYolo
- **Сегментаторы** - TPySegmentator, TPySegmentatorUNet
- **Базовый компонент** - TPyComponent

### Зависимости

- Python3
- rdk.static.qt
- OpenCV (через Rdk-CvBasicLib)

## EN

### Purpose

**Rdk-PyMachineLearningLib** provides integration with Python machine learning libraries.

### Main Component Categories

- **Classifiers** - TPyClassifierTrainer, TPyUBitmapClassifier
- **Object Detectors** - TPyObjectDetector, TPyObjectDetectorYolo
- **Segmentators** - TPySegmentator, TPySegmentatorUNet
- **Base Component** - TPyComponent

### Dependencies

- Python3
- rdk.static.qt
- OpenCV (via Rdk-CvBasicLib)
